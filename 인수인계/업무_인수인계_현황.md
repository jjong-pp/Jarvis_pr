# 업무 인수인계 현황

> 상태: 업무 주제 수집 및 상세 절차 작성 중  
> 편집 방식: 모든 현황과 상세 내용은 이 Markdown 파일 한 곳에서 관리하고, 사용자가 최종 적용을 지시한 뒤에만 Excel 파일로 제작한다.  
> 참고 기준: 2026-10-01, `뉴트리시아&에비앙 인수인계.xlsx`의 내용과 정보 배치 방식. 기존 양식 자체는 복제하지 않는다.

## 1. 문서 목적

이 문서는 후임자가 업무의 이름만 아는 수준을 넘어 다음을 스스로 판단하고 실행할 수 있도록 만드는 실무 인수인계서다.

- 언제 업무를 시작해야 하는지 안다.
- 어떤 파일과 시스템을 사용해야 하는지 찾을 수 있다.
- 작업 순서와 단계별 완료 기준을 안다.
- 정상 상황과 예외 상황을 구분할 수 있다.
- 업무 완료 후 누구에게 무엇을 전달해야 하는지 안다.
- 오류가 발생했을 때 먼저 확인할 지점을 안다.

조직·사업·물류 구조를 설명하는 `뉴트리시아_비즈니스_구조.html`과 상세 실행 절차를 담는 이 문서는 역할을 구분한다. HTML은 전체 맥락을 이해하는 안내서, 이 문서는 실제 업무를 수행하는 절차서로 관리한다.

## 2. 현재 확정된 범위

대분류는 다음 네 가지다.

1. 입고
2. 출고
3. 정산
4. 재고 확인

세부업무가 독립된 시작 조건, 작업 과정, 결과물을 가지면 하나의 업무로 보고 최종 Excel에서 개별 시트로 만든다.

예시:

- 분류 경로: `입고 > 수입입고`
- Excel 시트명 후보: `입고_수입입고`

단, 목적과 완료 기준이 같고 물류사별 접속·조회 방법만 다른 업무는 하나의 시트에 묶는다.

예시:

- 분류 경로: `재고 확인 > 풀필먼트 재고 확인`
- 포함 대상: 품고, 디앤비 및 이후 추가되는 풀필먼트
- 구성 방식: 공통 확인 절차를 먼저 설명하고, 풀필먼트별 접속 경로와 조회 방법만 하위 구분으로 나눈다.

## 3. 시트 분리 원칙

### 개별 시트로 분리

다음 중 하나라도 다르면 별도 업무 시트로 분리한다.

- 업무의 목적 또는 최종 산출물이 다르다.
- 업무를 시작하는 조건이나 시점이 다르다.
- 처리 후 전달 대상 또는 승인 주체가 다르다.
- 정상 완료 여부를 판단하는 기준이 다르다.
- 예외 상황이 많아 한 시트에서 설명하면 혼동이 커진다.

### 하나의 시트로 통합

다음 조건을 모두 만족하면 하나의 시트 안에서 대상별 방법을 구분한다.

- 업무 목적이 같다.
- 최종적으로 확인하거나 기록하는 항목이 같다.
- 전체 작업 순서가 같다.
- 차이는 접속 시스템, 메뉴 경로, 파일 형식 정도다.

따라서 품고·디앤비 등 여러 풀필먼트의 재고 조회는 `재고 확인_풀필먼트` 한 시트로 통합하는 방향이 현재 기준에 맞다.

## 6. 참고 파일에서 확인한 업무 구성 패턴

참고 파일에는 9개 시트가 있으며, `산후조리원`, `뉴트리시아`, `재고`, `압타밀 정산`처럼 큰 주제의 한 시트 안에 여러 상세업무가 연속 배치되어 있다.

재사용할 정보 패턴은 다음과 같다.

- 파일/폴더 경로
- 주기
- 요일 또는 처리 시점
- 단계별 작업 내용
- 사용 파일·시스템
- 완료 확인 및 주의사항
- 예외 상황

새 문서에서는 위 항목은 유지하되 탐색성을 높이기 위해 상세업무 단위로 분리한다. 단순히 요일별 업무를 나열하는 일정표가 아니라, 한 업무를 실제로 끝낼 수 있는 실행 절차 중심으로 작성한다.

참고 파일에서 확인된 업무는 새 문서의 확정 목록이 아니다. 실제로 계속 수행할 업무인지, 담당 범위가 바뀌었는지 사용자의 설명을 기준으로 선별한다.

## 7. 확인이 필요한 원본 불일치

참고 파일에는 아래와 같이 표현이 충돌하는 부분이 있다. 새 문서로 옮기기 전에 실제 운영 기준을 확인한다.

| 위치 | 원본 표기 | 확인할 내용 |
|---|---|---|
| `재고` 시트의 기말재고 기입 업무 | 주기 `주간`, 시점 `월말` | 실제 주기가 월간인지, 주간 확인과 월말 확정이 함께 있는지 확인 필요 |
| `압타밀 정산` 시트의 산후조리원 정산 업무 | 제목은 `선출고 후입금`, 폴더명은 `선입금 후출고 입금내역` | 업무 유형과 폴더명이 다른 이유 및 현재 기준 확인 필요 |

## 8. 정보보안 및 유지관리 원칙

- 참고 파일에 포함된 계정, 비밀번호, 계좌정보, 개인 연락처는 새 인수인계서에 그대로 옮기지 않는다.
- 시스템 항목에는 접속 주소와 권한 요청 방법만 기록하고, 비밀번호는 회사가 정한 별도 보안 저장 위치를 안내한다.
- 담당자 이름보다 역할 또는 팀을 우선 기록한다. 담당자가 바뀌어도 절차가 유지되도록 한다.
- 날짜가 붙은 일회성 현황과 계속 유지될 업무 절차를 구분한다.
- 변경된 절차는 이전 내용을 조용히 삭제하지 않고 변경일, 종전 방식, 신규 방식을 기록한다.

## 9. 앞으로 업무를 추가할 때의 반영 방식

사용자는 형식을 맞추지 않고 업무 내용을 순서대로 설명해도 된다. 전달받은 내용은 다음 순서로 정리한다.

1. 입고·출고·정산·재고 확인 중 상위 분류 지정
2. 독립 업무인지 통합 업무인지 판정
3. 업무 목적, 시작 조건, 완료 기준 정리
4. 파일/폴더 경로, 주기, 시점, 사용 시스템 배치
5. 실행 순서대로 단계 분해
6. 단계별 완료 확인과 주의사항 연결
7. 확인되지 않은 내용은 `미확인`으로 표시
8. 최종 Excel의 시트 후보 목록 갱신

## 10. 현재 분류 판단

- 품고·디앤비·쿠팡 재고 확인은 목적이 같으므로 한 업무에서 시스템별 방법을 구분한다.
- 일반 식품이력추적 출고 등록과 디앤비 오프라인 마트별 등록은 한 업무 안에서 유형을 나눈다. 실제 시스템과 완료 기준이 크게 다르면 추후 분리한다.
- 품고·디앤비 재고이관과 쿠팡 사입출고는 목적과 완료 기준이 달라 별도 업무로 분리한다.
- 산후조리원 물품출고와 기저귀 출고는 우선 한 업무 안에서 출고 유형을 나눈다.
- 인구보건협회 일일 출고와 월정산은 별도 업무로 분리하고 서로 관련 업무로 연결한다.
- 상시 풀필먼트 재고 확인과 말일재고는 기준 시점과 산출물이 달라 별도 업무로 분리한다.
- `롯데면세점 사입`은 당사의 납품출고인지 매입입고인지 확인한 뒤 분류한다.
- `D·G 코드 입력`은 코드의 정의와 대상 시스템을 확인한 뒤 독립 업무 또는 다른 업무의 한 단계로 정한다.

## 11. 상세업무 작성 현황

## 12. 전체 업무 공통 유의사항

- 수량에는 낱개·박스·팔레트 등 단위를 함께 기록한다.
- 재고와 정산 자료에는 조회 기준일과 기준시각을 함께 기록한다.
- 예상일과 확정일, 요청수량과 확정수량, 출고수량과 입고수량을 구분한다.
- 전월 파일을 복사하는 업무는 파일명·기간·기준일·수식 범위·수신자 등 반드시 변경할 항목을 단계에 명시한다.
- 완료 기준은 `파일 작성`으로 끝내지 않고 누가 확인했고 어디에 최종본을 저장했는지까지 적는다.
- 시스템 간 수량 차이는 임의로 맞추지 않고 차이 사유와 확인 상태를 남긴다.
- 담당자의 개인 이름보다 담당 역할과 팀을 우선 기록한다.
- 계정의 권한 신청 방법과 보관 위치만 안내하고 비밀번호는 기록하지 않는다.
