| 최근 주문목록 버튼/컬럼 | 4시간 승인, 작업·배포 확인 대기 `ADD-04` |
| 분유 상품 구매 전 버튼 | 별도 요청이며 가능 여부·공수 미확정 `ADD-05` |
| 세금계산서 버튼 삭제 | 견적서 형식 전환 요청과 함께 검토됐으나 현재 확정 작업 아님 |

## 11. 갱신 규칙

1. 새 요청마다 `BASE`, `ADD`, `BUG`, `HOLD`, `OPS` ID를 붙인다.
2. 기본 기능의 오류·누락은 `BUG`로 먼저 등록하고 공수를 차감하지 않는다.
3. 추가 작업은 공수·승인 시각이 모두 있어야 `작업 예정`으로 바꾼다.
4. 개발자 반영 통보 후에는 `배포·QA 필요`, 운영 검증 후에만 `완료`로 바꾼다.
5. 운영시간은 `확정 차감`, `예약`, `견적 후보`로 나눠 계산한다.
6. 처리결과 HTML과 QA 증빙은 프로젝트 폴더에 저장하되 계정정보는 별도로 관리한다.
