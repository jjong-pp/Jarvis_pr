$ARGUMENTS 를 검토 대상으로 삼으세요. 대상이 불명확하면 실행 전에 한 번만 확인합니다.

1. 대상 파일과 관련 맥락(프로젝트 배경, 상대방, 금액 등)을 수집한다.
2. reviewer 서브에이전트를 호출해 전달한다.
3. 결과를 [리스크(심각도순) + 각각의 대응책 / 최종 판정: 진행 가능·조건부 진행·보류 권고] 구조로 보고한다.
4. 사용자가 대응책 반영을 요청하면 해당 문서를 수정한다 (원본 PDF/HWP는 수정 불가 — 별도 마크다운으로).
