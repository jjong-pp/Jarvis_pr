세션 마무리 절차를 실행하세요. $ARGUMENTS 에 특별 지시가 있으면 반영합니다.

1. **정리**: organizer 서브에이전트를 호출해 이번 세션 산출물을 PARA 볼트에 정리하고 `project_state.md`를 갱신하게 한다 (마지막 갱신일 = 오늘).
2. **커밋**: 변경 파일을 명시적 경로로 스테이징 (`git add -A` 금지, 시크릿 여부 확인) 후 한국어 요약 커밋.
3. **푸시**: 원격(origin)이 있으면 push. 실패(충돌) 시 우회하지 말고 상태를 보고한다.
4. **보고**: [정리된 파일 → 위치 / 현황판 변경 줄 / 커밋 해시 / 푸시 여부]를 표로 보고한다.
