## 한 줄 정의

마감·계약이 있고 여러 외부 이해관계자를 조율해 결과물을 확정하는 업무의 문서·표·보고 형식 기준. 사용자가 실제로 만들어온 문서(리스크 대장·확정사항 대장·질의 대장·40시간 장부)에서 역추출한 규칙이다. 적용 사례는 `관세청`·`산후조리원` 스킬.

## 절대 규칙

1. **판정을 강제한다.** 검토·분석의 끝에는 `[진행 가능 / 조건부 진행 / 보류 권고]` 한 줄을 붙인다. 유보하지 않는다. 조건부면 조건을 명시한다.
2. **상대의 회신을 액면가로 받지 않는다.** 협력사가 정상이라고 답해도 규격·실응답과 대조한다. 회신 내용과 검증 결과를 한 칸에 섞지 말고 나란히 둔다.
3. **상태를 바꿀 때는 날짜와 근거를 같이 바꾼다.** 상태값만 바꾸지 않는다.
4. **커밋은 `/정리` 절차 안에서만.** push는 항상 사용자가 직접 한다.

## 확정 사실

### 문서 머리에 기준을 박는다

첫 줄 형식: `기준일 YYYY-MM-DD · 근거: {원본 문서명·버전} · {마감이 있으면 D-n}`

마감이 걸린 프로젝트는 D-day를 계산해서 쓴다. 예: `오픈 D-17(2026-08-28 09:00)`
근거란에는 실제로 대조한 원본만 적는다. 안 본 문서를 나열하지 않는다.

### 목록은 대장으로

리스크·질의·결정·비용은 나열하지 말고 행마다 아래를 갖춘 표로 만든다.

| 열 | 내용 |
|---|---|
| 등급 | 아래 등급표 |
| 대상 | 누구·어느 시스템의 문제인가 |
| 내용 | 한 줄 요약 |
| 근거 | 문서명 + 조항·필드명. 없으면 `근거 없음`이라고 쓴다 |
| 제기 시점 | `YYYY-MM-DD 이름` — 누가 언제 꺼낸 말인지 |
| 상태 | 아래 상태 라벨 |
| 대응 방향 | 비판만 하고 끝내지 않는다. 리스크 하나에 대응책 하나 |

문서 상단에 등급별 건수를 센다. `P0 6 · P1 14 · P2 8`. **세면 빠진 것이 보인다.**

### 등급

| 등급 | 의미 |
|---|---|
| `P0` | 오픈·납품을 막는다. 지금 안 풀면 일정이 무너진다 |
| `P1` | 오픈 전 필수. 열리기는 하나 사고가 난다 |
| `P2` | 확인 권고. 문서와 근거의 불일치, 사후 리스크 |
| `P3` | 법무·계약·운영 정비 |

### 상태 라벨 (고정 세트 — 새로 만들지 않는다)

- 리스크: `해결 완료 YYYY-MM-DD` / `미해결` / `보류(대기)` / `확인 필요`
- 질의: `회신 대기` / `내부 확인 필요` / `추가 요청` / `확정 합의`
- 검수: `QA 대기` / `QA 실패` / `확인 불가` / `부분 완료` / `완료`

### 질의는 재정의해서 던진다

협력사·거래처 질의를 만들 때 받은 질문을 그대로 넘기지 않는다.

1. **전제 — 구현 기준안**: 현재 우리가 이해한 구조를 먼저 못박는다
2. **그래서 진짜 물어야 할 것**: 표면 질문 뒤의 실제 쟁점
3. **근거**: 왜 그것이 쟁점인지 규격을 인용한다
4. **우리 제안**: 답이 어느 쪽으로 오든 쓸 수 있는 기본안

### 숫자·날짜·금액

- 날짜는 절대 날짜 `YYYY-MM-DD`. 시각이 의미 있으면 `2026-08-28 09:00`까지.
- 제시값과 확정값을 구분한다. 채팅에서 나온 숫자는 제시값이다.
- 금액·시간·수량은 원본 문서에서 재확인하고, 확인 못 하면 `미확인`으로 둔다.

### 파일 형식

- 대외 공유·검토용은 HTML 단일 파일. 상단에 관련 문서 상호 링크를 둔다.
- 내부 기준·체크리스트는 마크다운.
- 중문판(`_cn.html`)이 있는 문서는 국문 정정과 같은 커밋에서 함께 고친다.

### 커밋 메시지

형식: `YYYYMMDD-간단 설명`. 한글, 한 줄. 무엇을 바꿨는지가 드러나야 한다.
`20260812-관세청 sellerName 규칙 추가 및 계약서 검토 정리`

- 날짜는 커밋 시점(오늘) 기준.
- 한 커밋에 여러 프로젝트가 섞이면 대표 변경 위주로 요약하고 나머지는 본문 줄에 나열한다.
- 이 형식은 커밋 게이트 훅이 강제한다 — **`2026-08-15 기준 미설치`. 설치 전까지는 스스로 지켜야 하며 자동으로 잡히지 않는다.**
