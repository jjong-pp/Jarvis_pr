## 한 줄 정의

아이베(EIBE) 채널별 매출·행사 ROI·포트폴리오를 보는 정적 웹 대시보드. 구글 시트를 데이터 소스로 쓰고 Chart.js로 시각화한다. 기본 브랜드는 "드리미"이지만 멀티 브랜드 지원 구조다 (`SALES_HUB_FEATURE_MULTI_BRAND`). 출처: `세일즈허브/index.html`, `.env.example` 직접 확인 (2026-08-12). 다루는 도메인 지식은 `scm-물류` 스킬.

## 절대 규칙

1. **계정 정보·API 키·시크릿은 `.env`에만.** `.env.example`은 키 목록만 담은 템플릿이고 실제 값은 들어있지 않다.
2. 시트 컬럼명·구조를 바꿀 때는 `domain/sheetSchema.js`부터 고친다 — 여기가 정본이고 나머지 코드는 이걸 참조한다.
3. `DEV_BYPASS_AUTH` 관련 코드는 실제 배포본에 남아있으면 안 되는 개발용 우회다 — 배포 전 반드시 끔 여부를 확인한다.
4. **이 폴더를 지우지 않는다.** 2026-08-14 커밋 84c7390이 20개 파일 8,129줄을 삭제했고 2026-08-15에 `84c7390^`에서 복원했다.

## 확정 사실

- 순수 프론트엔드(정적 HTML/JS/CSS), 전역 네임스페이스(IIFE) 모듈 패턴 — 별도 번들러 없음.
- 데이터 소스는 구글 시트 5종, 스키마는 `domain/sheetSchema.js`가 정본:
  `1 프로모션`(시작일·채널·제품명·가격·할인율 등) · `2 raw 통합`(주문 단위 원본) · `3 채널그룹맵핑` · `4 라인업매핑` · `5 채널설정`.
- `data/config.js`가 `SALES_HUB_*` 환경변수로 동작을 제어한다 — 데이터 백엔드(local/API), 인증 우회(`DEV_BYPASS_AUTH`), 시트 쓰기 배치 크기 등.
- 접근 제한: `vendor/workspace-mall-sso-gate.js`가 `@eibe.co.kr`·`@btmall.kr` 도메인 이메일만 허용하는 SSO 게이트. "워크스페이스 몰"이라는 상위 사내 플랫폼에 이 대시보드가 모듈로 얹히는 구조로 보인다 (`vendor/workspace-*` 파일들).
- 외부 의존성: Chart.js(CDN), SheetJS/xlsx(CDN), Pretendard 폰트.
- `[2026-08-15]` 2026-08-14 커밋 84c7390(메시지 없음)이 폴더 전체를 삭제. 사용자 확인 결과 **의도된 삭제가 아니라 실수**였고 `git checkout 84c7390^ -- 세일즈허브` 로 20개 파일 전량 복원.

## 함정

- **이 폴더는 한 번 통째로 지워진 적이 있다.** 2026-08-14 커밋 84c7390(메시지 없음)이 20파일 8,129줄을 삭제했고 하루 뒤에야 발견됐다. 룰은 그동안 이 폴더를 정본으로 계속 가리키고 있었다.
- `DEV_BYPASS_AUTH`는 배포본에 남으면 안 되는 개발용 인증 우회다. 코드에 남아 있어도 에러가 나지 않으므로 **배포 전에 명시적으로 확인해야만** 잡힌다.
- 시트 컬럼명을 바꾸면 `domain/sheetSchema.js` 밖의 코드가 조용히 빈 값을 읽는다. 예외가 안 난다.
