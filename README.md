# MyMain

박종혁 개인 작업공간. 기획 · 소규모 개발 · 사무업무(SCM·이커머스 MD) · 사업 기획을 Claude Code와 함께 한 저장소에서 처리한다.

이 저장소가 단일 정본이다. 기기가 바뀌거나 세션이 끊겨도 git으로 같은 규칙과 같은 사실을 유지한다.

## 구조 — 4계층

배치 판정 한 줄: **어기면 사고가 나면 L0, 항상 참이면 L1, 특정 일에만 참이면 L2, 다음 주에 바뀌면 L3.**

| 계층 | 위치 | 담는 것 | 로드 |
|---|---|---|---|
| **L0 강제** | `.claude/hooks/` | 어기면 사고가 나는 것 | 코드 실행 |
| **L1 헌법** | `AGENTS.md` (`CLAUDE.md`가 임포트) + `.claude/rules/90_학습로그.md` | 항상 참인 원칙 | 항상 |
| **L2 지식** | `.claude/skills/*/SKILL.md` | 프로젝트 사실 · 업무 공정 · 전문지식 | 설명만 상시, 본문 온디맨드 |
| **L3 상태** | `project_state.md` | 지금 상태와 다음 할 일 | SessionStart 훅이 주입 |

규격 전문은 `harness/SPEC.md`. 새 프로젝트는 `harness/templates/SKILL.md`를 복사해서 연다.

## 시작하는 법

새 세션은 `CLAUDE.md`(→`AGENTS.md` 임포트)와 `.claude/rules/*.md`가 자동 로드되고, `project_state.md`는 SessionStart 훅이 주입한다. 스킬은 설명만 로드되고 본문은 필요할 때 들어온다. 별도로 읽을 필요 없다.

세션 마무리는 `/정리` (정리 → 룰 승격 → 모순 점검 → 커밋), 확정 전 검토는 `/검토 <대상>`, L1 비대화 해소는 `/압축`.

## 새 기기에서 (1회)

Codex CLI도 쓴다면 스킬 탐색 경로가 달라 정션이 필요하다. git은 정션을 추적하지 않으므로 기기마다 한 번 만든다.

```cmd
mklink /J .agents\skills .claude\skills
```

## 자동 안전장치

`.claude/hooks/`가 파괴적 명령·시크릿·원본 문서 수정·하네스 자기 수정을 차단하고, 커밋 시 메시지 형식과 죽은 참조를 검사한다. **차단되면 우회하지 않는다** — 변경안을 diff로 제시하고 사람이 반영한다.
