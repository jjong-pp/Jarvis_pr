# MyMain

박종혁 개인 작업공간. 기획 · 소규모 개발 · 사무업무(SCM·이커머스 MD)를 Claude Code와 함께 한 저장소에서 처리한다.

이 저장소가 단일 정본이다. 기기가 바뀌거나 세션이 끊겨도 git으로 같은 규칙과 같은 사실을 유지한다.

## 구조

`CLAUDE.md`(헌법)는 **업무 모드 / 프로젝트 / 전문지식** 셋을 구분한다.

| 구분 | 위치 |
|---|---|
| 업무 모드 (공정 방식 — 기획/개발/사무/외부조사) | `CLAUDE.md` 4번 |
| PM성 프로젝트 방법론 | `.claude/rules/10_PM업무_방법론.md` |
| 프로젝트 사실 | `관세청/`+`11_관세청.md` · `산후조리원/`+`12_산후조리원.md` · `세일즈허브/`+`13_세일즈허브.md` |
| 개인 자산관리 | `resume/`+`30_이력서.md` · `blog/`+`31_블로그.md` |
| 전문지식 (도메인 지식, 프로젝트 아님) | `.claude/rules/40_SCM물류_전문지식.md` |
| 현재 상태 | `project_state.md` (세션 시작 시 자동 주입) |
| 자동 안전장치 | `.claude/hooks/` (파괴적 명령·보호 파일 차단) |

## 시작하는 법

새 세션은 `CLAUDE.md`와 `.claude/rules/*.md`가 자동으로 로드되고, `project_state.md`는 SessionStart 훅이 주입한다. 별도로 읽을 필요 없다.

세션 마무리는 `/정리` (정리 → 룰 승격 → 모순 점검 → 커밋), 확정 전 검토는 `/검토 <대상>` (reviewer 서브에이전트).

상세 원칙은 `CLAUDE.md`, 업무 유형별 규칙은 `.claude/rules/`를 참조.
