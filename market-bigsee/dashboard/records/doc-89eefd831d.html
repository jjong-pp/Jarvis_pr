마켓빅시 서비스·사업 현황

기준일: 2026-08-13 상태: 공개 페이지 기반 조사. 실제 코드·운영 대시보드·API 계약은 미확인.

1. 서비스 정의

마켓빅시 BIGSEE는 네이버, 유튜브, 구글, 인스타그램, 뉴스 데이터를 모아 키워드와 마케팅 기회를 조사하고 CSV·HTML·AI 결과물로 정리하는 한국형 멀티채널 마케팅 리서치 SaaS입니다.

현재 핵심 가치는 다음과 같습니다.

  • 여러 플랫폼을 각각 조사하는 작업 감소
  • 키워드·콘텐츠·트렌드 근거의 한 화면 비교
  • 캠페인·콘텐츠 기획을 위한 초기 조사
  • CSV·HTML·AI 요약 결과물 제공

공개 페이지:

  • 서비스 소개
  • 요금제
  • 환불
  • 개인정보
  • 이용약관

3. 추정 기술 구조

공개 개인정보 문서 등을 기준으로 추정되는 구성은 다음과 같습니다.

  • Google 로그인 기반 개인 계정
  • Netlify 및 Netlify Functions
  • Firebase Authentication·Firestore
  • Naver API
  • YouTube Data API
  • Google Ads 관련 API
  • Instagram·Meta API
  • 뉴스 데이터
  • BIGSEE AI 모델 또는 외부 AI API
  • 결제 및 고객지원 도구

이 내용은 코드 확인 전 추정입니다. 서버 측 권한 검사, 사용량 차감의 원자성, 중복 결제 방지, API별 호출 로그는 별도 검증이 필요합니다.

5. 판매 가능 수준

  • 개인·프리랜서 대상 유료 베타: 가능
  • 소규모 브랜드·대행사 지정 계정 판매: 조건부 가능
  • 정식 팀 좌석 판매: 팀·권한·공유 기능 구축 후 가능
  • 대기업 Enterprise 판매: SSO·감사 로그·SLA·보안·계약 체계 구축 전에는 이름에 비해 이름뿐인 상태

단순 API 연결은 경쟁사가 복제할 수 있습니다. 장기 방어력은 다음 데이터에서 만들어야 합니다.

  • 업종별 키워드·채널 벤치마크
  • 조사 결과와 실제 콘텐츠·캠페인의 연결 기록

  • 어떤 키워드와 콘텐츠가 어떤 상품에서 성과를 냈는지에 대한 학습 데이터
  • 고객의 프로젝트·템플릿·리포트·팀 이력
  • 주간 변화 알림과 반복 운영 습관
