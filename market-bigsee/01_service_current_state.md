## 1. 서비스 정의

마켓빅시 BIGSEE는 네이버, 유튜브, 구글, 인스타그램, 뉴스 데이터를 모아 키워드와 마케팅 기회를 조사하고 CSV·HTML·AI 결과물로 정리하는 한국형 멀티채널 마케팅 리서치 SaaS입니다.

현재 핵심 가치는 다음과 같습니다.

- 여러 플랫폼을 각각 조사하는 작업 감소
- 키워드·콘텐츠·트렌드 근거의 한 화면 비교
- 캠페인·콘텐츠 기획을 위한 초기 조사
- CSV·HTML·AI 요약 결과물 제공

## 6. 주요 비용과 병목

정확한 고객당 원가는 공개 페이지로 산출할 수 없습니다. 다음 계측이 선행되어야 합니다.

```text
고객당 월 직접원가
= Functions 실행·전송·요청
+ Firestore read/write/storage
+ 플랫폼별 실제 API 호출 비용
+ AI 입력·출력 토큰 비용
+ 결제 수수료
+ 고객지원 배부액
```

예상되는 첫 병목은 일반 서버 CPU보다 외부 API입니다.

1. YouTube 검색 쿼터
2. Naver 관련 호출 한도
3. Google Ads 접근 등급 및 Keyword Planning 속도 제한
4. AI 비용과 응답 지연
5. Firestore 쿼리·인덱스 구조
6. 고객지원 건수

## 7. 현재 방어력과 향후 자산

단순 API 연결은 경쟁사가 복제할 수 있습니다. 장기 방어력은 다음 데이터에서 만들어야 합니다.

- 업종별 키워드·채널 벤치마크
- 조사 결과와 실제 콘텐츠·캠페인의 연결 기록
- SKU별 콘텐츠·유입·구매 성과
- 어떤 키워드와 콘텐츠가 어떤 상품에서 성과를 냈는지에 대한 학습 데이터
- 고객의 프로젝트·템플릿·리포트·팀 이력
- 주간 변화 알림과 반복 운영 습관
