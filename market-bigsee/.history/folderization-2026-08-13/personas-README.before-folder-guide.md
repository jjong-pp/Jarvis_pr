# 마켓빅시 페르소나 작업 공간

이 폴더는 역할별 상황과 컨텍스트를 분리하고 표준 출력만 `dashboard.html`에 취합하기 위한 하네스입니다.

- 시작 안내: [START_HERE.md](START_HERE.md)
- 역할 등록부: [registry.md](registry.md)
- 전체 계약: [../system/12_persona_harness.md](../system/12_persona_harness.md)

각 역할 폴더는 다음 파일을 유지합니다.

```text
inbox.md     요청·과업 대장
research.md  탐색 경로·출처·증거·반증
state.md     현재 과업·차단·다음 행동
output.md    결론·근거·한계·제안·결정 요청·다음 전달
```

대시보드는 `state.md`와 `output.md`만 취합합니다. 파일명과 `## Harness State`, `## Dashboard Output` 표 제목은 빌드 계약이므로 바꾸지 않습니다.
