# 이커머스 마케팅·세일즈 흐름

기준일: 2026-08-13

## 1. 결론

이커머스 마케팅은 `홍보물을 많이 만드는 일`이 아니라 고객이 다음 다섯 단계를 이동하도록 만드는 일입니다.

> 발견 → 검토 → 구매 → 재구매 → 추천

고객은 검색, 블로그, 숏폼, 리뷰, 상품 상세페이지, 광고를 오가므로 실제 경로는 직선이 아닙니다. Shopify도 이커머스 퍼널을 인지·검토·전환·구매 이후 단계로 설명하고, 단계별 지표를 분리합니다. [Shopify 이커머스 퍼널](https://www.shopify.com/blog/ecommerce-funnel)

## 2. 단계별 채널과 지표

| 단계 | 고객 질문 | 주요 채널·콘텐츠 | 대표 행동 | 핵심 지표 |
|---|---|---|---|---|
| 발견 | 이 문제와 상품이 무엇인가 | 검색, 블로그, 숏폼·릴스, 유튜브, 인플루언서, 뉴스 | 콘텐츠 조회·검색·방문 | 도달, 신규 방문, 검색 유입, 콘텐츠 조회 |
| 검토 | 나에게 맞고 믿을 수 있는가 | 비교 글, 사용법, 상세페이지, 리뷰, UGC, FAQ | 상품 조회·재방문·찜 | `view_item`, 재방문, 리뷰 열람, 찜 |
| 구매 | 지금 사도 되는가 | 검색광고, 리타게팅, 쿠폰, 라이브, 장바구니 알림 | 장바구니·결제 시작·구매 | `add_to_cart`, `begin_checkout`, `purchase`, CVR, CAC |
| 재구매 | 다시 살 이유가 있는가 | 배송 안내, 사용 가이드, 재입고·소진 알림, CRM, 교차판매 | 재구매·상향구매 | 반복 구매율, LTV, 환불률, 재구매 주기 |
| 추천 | 남에게 권할 만큼 만족했는가 | 구매자 리뷰, 추천인, UGC, 커뮤니티 | 리뷰·공유·추천 구매 | 리뷰 전환율, 추천 매출, UGC 수 |

Mailchimp도 발견부터 구매 이후까지 여러 접점을 오가는 비선형 여정과, 구매 후 커뮤니케이션·리뷰·재구매의 중요성을 설명합니다. [Mailchimp 이커머스 고객 여정](https://mailchimp.com/resources/ecommerce-customer-journey/)

## 3. 채널별 실제 역할

### 블로그·검색 콘텐츠

주요 역할:

- 문제를 아직 제품명으로 검색하지 않는 잠재 고객 발견
- 제품 사용법·선택 기준·비교 정보를 제공
- 검색광고가 끝나도 남는 장기 유입 자산 생성
- 상품 상세페이지가 담지 못하는 맥락과 사례 제공

추천 형식:

- 문제 해결형: `여름철 민감성 피부가 건조해지는 이유`
- 선택 기준형: `저자극 세안제 고를 때 확인할 5가지`
- 비교형: `젤 타입과 폼 타입 세안제 차이`
- 사용법형: `세안 후 당김을 줄이는 순서`
- 데이터형: `최근 3개월 검색·콘텐츠 관심 변화`

모든 글은 한 개 이상의 SKU 또는 상품군, 한 개의 퍼널 단계, 한 개의 행동 유도와 연결해야 합니다.

### 리뷰와 UGC

리뷰의 역할은 검토 단계의 불확실성을 줄이는 것입니다. 따라서 브랜드가 가짜 후기를 자동 생성하면 안 됩니다.

가능한 자동화:

- 실제 구매자에게 배송 완료 후 리뷰 요청
- 만족도 설문과 후기 작성 링크 제공
- 리뷰의 장점·불만·반복 질문 요약
- 리뷰 답변 초안
- 사진·영상 UGC 사용 동의 관리
- 리뷰에서 발견된 FAQ와 콘텐츠 주제 추천

금지할 자동화:

- 존재하지 않는 고객 후기 생성
- 보상 관계를 숨긴 체험단 후기
- 부정 리뷰를 좋은 리뷰로 변조
- 고객 동의 없이 후기·사진 재사용

공정거래위원회의 최신 추천·보증 심사지침은 광고주와 추천인 사이 경제적 이해관계가 있는 추천·보증을 적용 대상으로 둡니다. [추천·보증 등에 관한 표시·광고 심사지침, 시행 2026-06-01](https://www.law.go.kr/LSW/admRulInfoP.do?admRulSeq=2100000280130&chrClsCd=010201)

플랫폼별 정책도 지켜야 합니다. 예를 들어 Google 비즈니스 프로필은 리뷰 작성·수정·삭제를 대가로 할인이나 무료 상품을 제공하는 행위를 금지합니다. [Google 리뷰 요청 정책](https://support.google.com/business/answer/3474122?hl=ko)

### 숏폼·릴스

초기에는 영상 렌더링까지 자동화하지 않아도 됩니다. 먼저 다음 산출물만 제공해도 조사 서비스와 자연스럽게 연결됩니다.

- 첫 3초 후크 5안
- 15초·30초 대본
- 장면별 스토리보드
- 촬영 목록과 B-roll 제안
- 자막·캡션·해시태그 초안
- 연결 SKU와 추적 링크
- 게시 후 조회·클릭·구매 기록

영상 자동 생성은 렌더링 비용, 저작권, 인물·음원·플랫폼 규격 문제가 추가되므로 후순위가 타당합니다.

### 광고·리타게팅

검색·콘텐츠 데이터에서 의도가 확인된 키워드와 상품을 광고로 전환합니다.

- 발견: 일반 문제·카테고리 키워드
- 검토: 비교·후기·추천 키워드
- 구매: 상품명·브랜드명·가격·쿠폰 키워드
- 재구매: 구매 SKU와 소진 주기 기반 메시지

마켓빅시는 광고 집행 도구 자체보다 `어떤 키워드와 SKU를 어떤 단계에서 광고할지`를 결정하고 결과를 수집하는 역할부터 시작하는 것이 좋습니다.

## 4. 표준 운영 흐름

한 상품을 판매하는 주간 운영 예시는 다음과 같습니다.

1. SKU 등록: 가격·원가·재고·상세페이지·타깃·금지 표현
2. 마켓빅시 조사: 검색량·채널 반응·경쟁 콘텐츠·뉴스 이슈
3. 기회 선택: 키워드와 고객 질문을 퍼널 단계로 분류
4. 콘텐츠 생성: 블로그 초안, 숏폼 대본, 상세페이지 FAQ
5. 사람 검수: 사실·브랜드 문체·광고 표시·법적 표현 확인
6. 배포: 채널별 게시, UTM·콘텐츠 ID·SKU 연결
7. 행동 수집: 콘텐츠 조회, 클릭, 상품 조회, 장바구니, 구매, 환불
8. 성과 평가: SKU·콘텐츠·채널별 매출과 이익 확인
9. 다음 실행: 잘 팔린 질문과 형식 확대, 실패 콘텐츠 중단

이 구조를 사용하면 마켓빅시는 조사 도구에서 `커머스 마케팅 운영 시스템`으로 확장할 수 있습니다.

## 5. 측정 표준

Google Analytics 4는 이커머스에서 다음 이벤트를 권장합니다.

- `view_item_list`
- `select_item`
- `view_item`
- `add_to_cart`
- `view_cart`
- `begin_checkout`
- `add_shipping_info`
- `add_payment_info`
- `purchase`
- `refund`

각 상품은 `item_id`로 연결하며 Google 문서도 `SKU_12345` 같은 값을 예로 듭니다. [GA4 권장 이벤트](https://support.google.com/analytics/answer/9267735?hl=ko), [GA4 이커머스 구매 보고서](https://support.google.com/analytics/answer/12924131?hl=ko)

마켓빅시 내부에서는 다음 자체 이벤트를 추가합니다.

- `research_completed`
- `content_brief_created`
- `content_draft_created`
- `content_approved`
- `content_published`
- `content_view`
- `cta_click`
- `review_requested`
- `review_submitted`
- `repeat_purchase`

## 6. 블로그 자동 작성에 대한 평가

### 단독 기능으로 만들 때

평가: 5/10

- 범용 생성형 AI와 직접 경쟁
- 글을 만든 이후 판매 성과를 증명하기 어려움
- 대량 생성 시 검색 품질·스팸 위험
- 브랜드 사실과 상품 정보의 환각 위험

### 마켓빅시 조사·SKU·성과와 결합할 때

평가: 9/10

- 실제 검색·채널 조사 결과가 글의 근거가 됨
- 상품 사실과 금지 표현을 SKU에 저장 가능
- 콘텐츠별 추적 링크로 구매 연결 가능
- 성과가 좋은 키워드·구조를 다음 글에 재활용 가능
- 장기적으로 `조사→실행→성과` 데이터가 방어력으로 축적됨

Google은 생성형 AI가 조사와 구조화에는 유용하지만 사용자 가치 없이 많은 페이지를 만드는 경우 scaled content abuse 정책을 위반할 수 있다고 안내합니다. [Google 생성형 AI 콘텐츠 가이드](https://developers.google.com/search/docs/fundamentals/using-gen-ai-content?hl=ko)

네이버도 홍보 또는 검색 품질 저하를 목적으로 게시물을 기계적으로 대량 생산한 경우 검색 노출을 제한할 수 있다고 밝히고 있습니다. [네이버 블로그 검색 제한 기준](https://help.naver.com/service/5626/contents/22928?lang=ko) 또한 경험·전문성·출처·일관된 주제·최신 정보와 균형 잡힌 설명을 권장합니다. [네이버 콘텐츠 작성 권장 사항](https://searchadvisor.naver.com/guide/content-basic)

따라서 제품은 `자동 게시기`가 아니라 `근거가 있는 초안·검수·성과 학습 시스템`이어야 합니다.

## 7. 마켓빅시에 맞는 최종 구조

```text
시장·키워드 조사
  → 상품과 고객 질문 선택
  → 블로그·숏폼 대본·FAQ 초안
  → 사람 검수와 승인
  → 콘텐츠·캠페인·SKU 추적
  → 조회·장바구니·구매·환불
  → SKU별 매출·이익·반복 구매
  → 다음 조사와 콘텐츠 추천
```

이 중 첫 번째 MVP는 `블로그 초안 + SKU + 캠페인 추적 링크 + 주문 CSV + 기본 성과판`이 적합합니다.
