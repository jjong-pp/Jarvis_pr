# BIGSEE 마케팅 자문 현재 질문지

기준일: 2026-08-15  
상태: 발송 전 초안  
목적: 광고 운영 대행 견적보다 첫 고객군·제안·커뮤니티·Meta·후속 판매를 14일 검증으로 설계할 자문가인지 확인한다.

기존 `18_marketing_advisor_questions.md`는 상세 질문 은행이다. 이 문서는 현재 전략에 맞춘 실제 발송·미팅용 정본 초안이다.

## 자문가에게 먼저 보낼 배경

```text
BIGSEE는 네이버·Google·YouTube·Instagram·뉴스의 키워드와 마케팅 자료를 모아 리포트로 만드는 초기 SaaS입니다.
등록 사용자가 약 20명이라는 정보는 있으나 실제 활성·반복·유료·역할·원가는 아직 확인하지 못했습니다.
현재 1순위 가설은 광고대행사 실무자·팀장이고, 인하우스 마케터와 이미 상품·광고비가 있는 다채널 셀러를 비교군으로 둡니다.
아이보스·셀러오션과 Meta에서 같은 세 고객군·샘플·제안을 같은 14일 동안 검증하려 합니다.
원하는 것은 노출 확대가 아니라 유효 상담→첫 리포트→실제 결제→4주 반복으로 이어지는 시장진입 설계입니다.
```

## 필수 질문 12개

### 고객·제안

1. 현재 증거 수준에서 세 고객군의 우선순위를 무엇으로 판단하고, 기존 약 20명을 어떻게 분류·인터뷰해야 하는가?
2. 각 고객군이 BIGSEE를 켜는 최근 실제 업무와 구매 상황을 어떤 질문으로 찾아야 하는가?
3. 대행사·인하우스·셀러별로 기능이 아니라 어떤 첫 결과를 팔아야 하며, 한 문장 제안은 어떻게 달라져야 하는가?
4. 무료 데모, 유료 진단, 유료 파일럿, 셀프서비스 구독의 경계를 어떻게 두고 실제 결제 의사를 검증할 것인가?

### 커뮤니티·Meta

5. 2026년 현재 아이보스·셀러오션에서 각 고객군이 활동하는 게시판·형식·홍보 규정·공식 광고 상품을 어떤 1차 출처로 확인할 것인가?
6. 위장 홍보 없이 저장·공유·상담을 만드는 교육형 자료와 샘플을 고객군별로 무엇부터 만들 것인가?
7. 전환량이 거의 없는 Meta 계정에서 Leads·Instagram Direct·웹사이트 중 무엇을 택하고, 캠페인·광고 세트·소재를 최소 구조로 어떻게 둘 것인가?
8. Meta 관심사 타기팅이 확장될 때 광고 문구·샘플·폼 질문으로 대행사·인하우스·셀러·구경꾼을 어떻게 구분할 것인가?

### 후속·측정·비용

9. 커뮤니티와 Meta 리드를 같은 CRM 단계와 UTM으로 어떻게 연결하고 24시간 이내 누가 어떤 순서로 후속해야 하는가?
10. 클릭률·CPL이 아니라 유효 상담·첫 리포트·결제·4주 반복·팀 신호로 중단·수정·확대를 판정할 기준은 무엇인가?
11. 광고비, 공식 커뮤니티 집행비, 콘텐츠·도구·상담·개발 공수를 포함한 완전 CAC와 14일 학습 예산을 어떻게 계산할 것인가?
12. 유사한 초기 IT/SaaS에서 직접 수행한 사례의 당시 사용자 수, 선행 수정, 실패 실험, 실제 유료 CAC·회수, 자문 범위와 원자료를 보여줄 수 있는가?

## 자문 조건 질문

1. 광고 계정·Pixel·소재·랜딩·CRM·원자료·분석 산출물의 소유권은 BIGSEE에 남는가?
2. 광고비와 자문료, 제작비, 도구비, 개발비를 분리해 제시하는가?
3. 매주 원자료와 변경 이유를 공유하고 실패한 실험도 기록하는가?
4. 커뮤니티 게시·광고 집행·외부 발송은 BIGSEE 승인 후 실행하는가?

## 받아야 할 산출물

1. 세 고객군 비교표와 1순위 가설·탈락 기준
2. 고객군별 한 문장 제안, 실제 결과 샘플, 유료 파일럿안
3. 기존 사용자 10명 접촉·인터뷰·분류 계획
4. 아이보스·셀러오션 14일 활동표와 2026 규정·공식 견적 출처
5. Meta 최소 캠페인 구조, 소재 3개, 폼 질문 6개 이하, 예산·중단 기준
6. `source/persona/creative → 상담 → 첫 리포트 → 결제 → 4주 반복` 측정표
7. 리드 24시간 후속과 거절·무효·중단 사유 코드
8. 계정·데이터·소재 소유권과 주간 보고 범위가 포함된 자문 견적

## 경계해야 할 답

- 실제 업무·결제·반복 기준 없이 노출·팔로워·가입자를 먼저 늘리자는 답
- 세 고객군과 여러 채널을 각각 잘게 쪼개 예산을 분산하는 답
- 오래된 커뮤니티 가격이나 규정을 현재값으로 단정하는 답
- 초기 전환량에서 ROAS나 알고리즘 최적화를 보장하는 답
- 광고 계정·Pixel·CRM·소재를 자문사 소유로 두는 조건
- 위장 홍보·자동 댓글·무단 수집·가짜 후기를 권하는 답
- 실패 기준·예산 상한·후속 담당이 없는 집행안

## 발송 문안

```text
BIGSEE에 필요한 것은 광고 대행 견적보다 14일 시장진입 설계입니다.
광고대행사 실무자, 인하우스 마케터, 활성 다채널 셀러의 같은 제안과 샘플을 아이보스·셀러오션과 Meta에서 동시에 검증하려 합니다.

기존 약 20명의 분류·인터뷰, 고객군별 첫 결과와 유료 파일럿, 커뮤니티의 2026년 규정과 실행 방식, Meta 최소 캠페인·소재·폼, 24시간 후속, 중단·수정·확대 기준을 제안해 주세요.
가입·클릭·CPL만이 아니라 유효 상담, 첫 리포트, 실제 결제, 4주 반복, 팀 신호까지 이어지는 구조가 필요합니다.
광고 계정·Pixel·소재·랜딩·CRM·원자료는 BIGSEE 소유를 전제로 검토하고 싶습니다.
```
