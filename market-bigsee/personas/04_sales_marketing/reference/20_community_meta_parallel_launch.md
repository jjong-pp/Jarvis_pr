# 대형 커뮤니티·Meta 동시 시장진입 계획

기준일: 2026-08-14  
목표: 단순 노출이 아니라 어떤 구매상황의 고객이 첫 가치를 얻고 결제하는지 14일 안에 비교한다.

## 운영 원칙

커뮤니티는 신뢰와 고객 언어를 얻는 채널이고 Meta는 같은 제안을 더 넓게 검증하는 채널이다. 둘을 순차로 기다리지 않고 최소 측정 구조를 갖춘 같은 주에 시작한다.

- 페르소나별 제안은 다르게, 제품의 핵심 결과는 일관되게 유지
- 커뮤니티 글과 Meta 광고를 동일 랜딩·동일 샘플에 연결
- 커뮤니티/게시물/소재마다 별도 UTM
- 리드 수가 아니라 유효 상담·첫 리포트·결제·반복으로 비교
- 위장 후기, 무단 홍보, 자동 대량 게시, 성과 과장은 금지

## 채널 역할

| 채널 | 주 대상 | 배포물 | 강점 | 주의 |
|---|---|---|---|---|
| 아이보스 | 대행사·인하우스 마케터 | 실제 키워드 분석, 제안서 체크리스트, 웨비나, 공식 네이티브/뉴스레터 문의 | 마케팅 업무 맥락이 명확 | 오래된 광고 제안서의 가격을 현재가로 사용하지 말고 2026 견적 확인 |
| 셀러오션 | 활성 이커머스 셀러 | SKU 출시 진단, 경쟁 콘텐츠 분석, 상품별 홍보 초안 사례 | 실제 쇼핑몰 운영 주제와 접근성 | 후기 조작·순위 조작 수요와 분리, 규정 확인 |
| 아프니까 사장이다 | 검증된 소상공인 하위군 | 업종별 시장·홍보 진단 | 도달 범위 | 핵심 타깃이 너무 넓어 초기 주력 제외 |
| Meta/Instagram | 세 페르소나의 확장·재접촉 | 결과 화면, 전후 시간, 샘플 신청, DM 상담 | 발견형 수요와 메시지 전환 | 관심사만 믿지 말고 소재·폼으로 자격 확인 |

## 페르소나별 캠페인 세트

| 페르소나 | 커뮤니티 제목 예시 | Meta 후크 | 제공할 샘플 | CTA |
|---|---|---|---|---|
| 대행사 | `신규 광고주 제안 전 5개 채널 조사, 실제로 어디서 시간이 새나` | `내일 제안인데 경쟁사 탭을 다시 열고 있나요?` | 제안서용 멀티채널 조사 1부 | 실제 고객 키워드 진단 신청 |
| 인하우스 | `신제품 SKU 하나에서 콘텐츠 브리프까지 만든 과정` | `신제품 조사와 광고 문구를 한 흐름으로` | SKU 경쟁·콘텐츠 브리프 1부 | 다음 출시 SKU 진단 |
| 활성 셀러 | `판매 URL 하나로 키워드·경쟁 글·추적 링크 묶기` | `상품은 있는데 이번 주 홍보 소재가 없다면` | 상품 1개 홍보 실행팩 | 판매 URL로 샘플 받기 |

커뮤니티 글은 제품 소개부터 시작하지 않는다. 실제 업무 문제, 조사 과정, 샘플 일부, 한계, 다운로드/진단 순으로 작성하고 운영자·광고 규정을 따른다.

## Meta 구성

### 권장 구조

- 목표: Leads 또는 Instagram Direct
- 캠페인: 작은 예산에서는 1개, 필요해도 광고 세트 1~2개
- 소재: 페르소나별 3개 후크와 결과 화면
- 랜딩: 페르소나별 URL 또는 한 랜딩 안의 역할 선택
- 기간: 최소 14일, 일별 성급한 중단 금지
- 후속: 영업일 기준 24시간 이내

Meta Advantage+ audience는 입력한 관심사 밖으로 확장할 수 있으므로 `마케터 관심사`만으로 타깃 정확도를 주장하지 않는다. 광고 문구, 결과 샘플, 폼 질문으로 업무 자격을 확인하고 위치·언어·연령 최소 범위와 기존 고객 제외 같은 통제만 사용한다.

### 폼 질문

Meta는 메시지 리드 질문을 6개 이하로 유지하는 것을 권장한다. 다음 6개면 충분하다.

1. 현재 역할: 대행사 / 인하우스 / 셀러 / 기타
2. 최근 조사한 실제 상품·업종
3. 대행사는 담당 고객 수, 브랜드/셀러는 활성 SKU 수
4. 현재 조사·콘텐츠 도구
5. 다음 조사·출시·제안 날짜
6. 샘플 전달 및 상담 연락처

개인정보 동의와 다음 연락 방식을 명확히 표시한다.

## 측정 규격

### 이벤트

`landing_view → sample_request → qualified_lead → demo_booked → report_started → report_completed → pilot_paid → week4_active → team_invite`

### 필수 속성

`persona`, `company_type`, `client_count`, `active_sku_count`, `trigger`, `source`, `medium`, `campaign`, `content`, `term`, `community_post_id`, `ad_id`, `creative_id`, `lead_id`, `workspace_id`, `cost`

### 보는 숫자

| 단계 | 숫자 | 판단 |
|---|---|---|
| 노출 | CPM·도달·빈도 | 과도한 반복과 소재 소진만 확인 |
| 반응 | CTR·랜딩 도착률 | 메시지와 페이지 불일치 탐지 |
| 상담 | 유효 리드율·유효 상담 비용 | 실제 업무가 있는 사람인지 판단 |
| 제품 | 첫 리포트 완료율·완료 시간 | 광고 약속을 제품이 전달하는지 판단 |
| 매출 | 유료 전환·완전 CAC·회수기간 | 채널을 유지할 수 있는지 판단 |
| 유지 | 4주 활성·팀 초대 | B2B 확장 가능성 판단 |

완전 CAC에는 광고비뿐 아니라 커뮤니티 집행비, 소재·랜딩 제작, 인터뷰 보상, 영업 후속 시간을 포함한다.

## 14일 일정

| 시점 | 실행 |
|---|---|
| D-3~D0 | 제안 3개, 결과 샘플 3개, 랜딩 3개, UTM, 폼, CRM, 이벤트 점검 |
| D1 | 아이보스·셀러오션 규정에 맞는 게시/공식 집행 시작, Meta 3소재 동시 시작 |
| D2~D7 | 24시간 후속, 유효/무효 이유 기록, 크리에이티브의 명백한 오류만 수정 |
| D7 | 채널별이 아니라 페르소나별 상담·첫 가치 중간 점검, 무효 리드가 압도적인 소재만 중단 |
| D8~D14 | 유효 소재에 예산 이동, 리타게팅은 충분한 모수가 있을 때만 추가 |
| D15 | 결제·첫 가치·반복 의도·지원 공수로 타깃/제안/기능 결정 |

## 예산 가설과 게이트

| 항목 | 14일 가설 | 집행 게이트 |
|---|---:|---|
| Meta | 700,000~1,200,000원 | 픽셀/UTM/폼/24시간 후속/결제 기록 |
| 커뮤니티 공식 집행·협찬 | 500,000~1,000,000원 | 2026 공식 견적과 규정 확인 |
| 랜딩·소재·샘플·인터뷰 보상·측정 | 300,000~800,000원 | 담당자·산출물·소유권 확정 |
| 합계 | 1,500,000~3,000,000원 + VAT 가능 | 개발자와 사업개발비 상한 승인 |

이는 시장 평균을 단정한 견적이 아니라 첫 실험을 멈출 수 있게 만든 지출 상한 가설이다. 특히 검색으로 확인되는 과거 아이보스 광고 제안서는 2018년 자료이므로 현재 가격 근거로 쓰지 않는다.

## 중단·확대 조건

- 중단/수정: 30만원 지출 후 유효 상담 0건, 폼 리드의 70% 이상이 제외 대상, 랜딩 약속과 제품 결과가 다름
- 메시지 수정: 클릭은 있으나 유효 상담이 없음
- 제품 수정: 유효 상담은 있으나 첫 리포트 완료가 절반 미만
- 영업 수정: 데모·첫 가치는 있으나 견적·결제에서 모두 이탈
- 확대: 같은 페르소나·제안에서 유료 2건 이상, 첫 가치 재현, 4주 반복 날짜가 구체적
