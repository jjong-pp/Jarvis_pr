# 기술·데이터 탐색 기록

## 코드 확보 후 확인 순서

1. 인증 모델: 사용자·조직·멤버십·역할·좌석
2. 사용 이벤트: 요청 횟수·플랫폼·데이터량·AI 토큰·처리시간·저장량
3. 권한과 기능 플래그: 요금제·조직·사용자별 잠금 가능성
4. 비동기 작업과 쿼터: 외부 API 재시도·캐시·큐·속도 제한
5. 인프라: 애플리케이션·DB·스토리지·동시성·모니터링·백업
6. 확장 테스트: 1,000명 등록이 아니라 피크 동시 사용자와 작업량 기준 병목

## 현재 판단 제한

기획 문서만으로 구현 가능성이나 3단계 요금제 공수, 1,000명 수용량을 확정하지 않습니다.

## 2026-08-15 · 개발자 사업·기술 질문 통합

- 종전 질문은 제품 재기획·기존 사용자 계측·사업회의 문서에 흩어져 있어 실제 회의 입력과 산출물이 분명하지 않았습니다.
- 고객·판매 가능 범위, 코드·데이터·원가, 운영·개발 이력, 30일 우선순위와 읽기 권한을 15개 핵심 질문으로 묶었습니다.
- 답변은 구두 추정이 아니라 비식별 사용자 집계, 로그, 청구, 코드 위치, 백로그·배포 이력과 함께 받습니다.
