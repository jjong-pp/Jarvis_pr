# 마켓빅시 페르소나 작업 공간

역할별 상황과 컨텍스트를 분리하고 표준 출력만 대시보드에 취합합니다.

- 시작 안내: [START_HERE.md](START_HERE.md)
- 역할 등록부: [registry.md](registry.md)
- 전체 계약: [../system/12_persona_harness.md](../system/12_persona_harness.md)

각 역할 폴더의 계약:

```text
inbox.md     요청·과업·완료 기준
research.md  탐색 경로·출처·증거·반증
state.md     현재 과업·차단·다음 행동
output.md    최신 결론·한계·제안·결정 요청
reference/   해당 역할이 책임지는 상세 분석 정본
```

대시보드는 `state.md`와 `output.md`만 취합합니다. `reference/`는 근거가 필요할 때만 선택해서 읽습니다.
