# 마켓빅시 판매·경영 전략

기준일: 2026-08-13

## 1. 전략 결론

마켓빅시를 넓은 의미의 `키워드 분석 도구`로 판매하지 않습니다.

> 2~20인 광고·마케팅 대행사가 신규 고객 제안서와 캠페인 조사를 빠르게 완성하는 한국형 멀티채널 리서치 도구

첫 목표는 가입자 1,000명이 아니라 반복적으로 돈을 내는 대행사 10곳입니다.

## 2. 우선 고객

| 우선순위 | 고객 | 구매 상황 | 적합도 |
|---|---|---|---:|
| 1 | 2~20인 광고·마케팅 대행사 | 신규 광고주 제안서, 캠페인 기획 | 9/10 |
| 2 | D2C·이커머스 브랜드 마케팅팀 | 신제품 출시, 시즌 캠페인 | 8/10 |
| 3 | 프리랜서 마케터·컨설턴트 | 고객 진단·리포트 제작 | 7/10 |
| 후순위 | 일반 자영업자·블로거 | 단발성 키워드 조회 | 4/10 |
| 후순위 | 대기업·공공기관 | 조직·보안·SLA·계약 요구 | 3/10 |

대행사는 여러 광고주를 반복 조사하므로 사용 빈도와 지불의사가 높습니다. 리포트가 광고주에게 전달되므로 결과물 자체가 유통 채널도 됩니다.

## 3. 기존 시장 진입법

### 무료 공식 도구

네이버 데이터랩과 Google Trends 같은 무료 도구와 데이터 조회 자체로 경쟁하지 않습니다.

- 여러 플랫폼을 오가는 시간을 줄임
- 결과를 한 문서로 정리
- CSV·HTML·AI 초안 제공
- 광고주에게 전달할 결과물 생성

### 블랙키위

초기에는 대체재가 아니라 보완재로 진입합니다.

> 블랙키위가 네이버·콘텐츠 키워드 심층 분석이라면, 마켓빅시는 여러 채널을 빠르게 훑고 캠페인 방향과 제안서 근거를 만드는 도구입니다.

### Semrush·Ahrefs

기능 수로 경쟁하지 않습니다. 글로벌 SEO는 기존 제품을 인정하고, 마켓빅시는 네이버를 포함한 한국형 멀티채널 캠페인 조사와 낮은 도입 부담에 집중합니다.

- [Ahrefs 가격](https://ahrefs.com/pricing/)
- [Semrush 가격](https://www.semrush.com/pricing/seo-ai-search/)

## 4. 판매 문구

핵심 문구:

> 클라이언트 키워드 하나로 네이버·유튜브·구글·인스타그램·뉴스 근거가 포함된 마케팅 조사 리포트를 만드세요.

보조 문구:

> 플랫폼별 검색과 자료 정리에 쓰던 시간을 줄이고, 신규 광고주 제안서와 캠페인 방향을 한곳에서 준비합니다.

고객이 구매하는 결과는 다음과 같습니다.

- 제안서를 더 빨리 제출
- 광고주에게 보여줄 근거 확보
- 신제품 출시 실패 가능성 감소
- 마케터의 반복 조사 감소

## 5. 상품 전략

| 상품 | 역할 | 판매 방식 |
|---|---|---|
| 무료 | 체험 | 조회보다 샘플 리포트 완성을 유도 |
| Pro 29,900원 | 개인 실무자 | 셀프서비스 |
| Premium 59,900원 | 리포트 제작자 | AI·내보내기 중심 |
| 199,900원 플랜 | 대행사 파워유저 | 고사용량·온보딩·운영 지원 |
| 향후 Team | 조직 | 공유 워크스페이스·좌석·권한 |

유료 파일럿 제안:

> 14일 대행사 파일럿 99,000원. 실제 고객 프로젝트 3건 적용, 1회 온보딩, 리포트 템플릿 제공. 정식 199,900원 플랜 전환 시 파일럿 금액 차감.

파일럿 가격은 고객당 실제 지원 공수와 원가 측정 후 확정합니다.

## 6. 창업자 직접 영업

대상 조건:

- 직원 2~20명
- 검색광고·콘텐츠·SNS 광고를 함께 제공
- 최근 3개월 내 신규 고객 사례가 있음
- 이커머스·병원·교육·프랜차이즈 중 하나를 전문으로 함

초기 이메일:

```text
제목: [회사명] 제안서용 [업종] 키워드 샘플

안녕하세요. 신규 광고주 제안서를 준비할 때
네이버·유튜브·인스타그램·뉴스 데이터를 각각 확인하고 계신가요?

귀사에서 주로 다루시는 [업종] 키워드로 멀티채널 조사 샘플을 만들었습니다.
기존 도구를 교체하기보다 초기 조사와 제안서 자료 정리를 줄이는 도구입니다.

실제 사용 중인 키워드 하나로 20분간 같이 테스트하고
조사 시간이 얼마나 줄어드는지 확인하실 수 있습니다.
```

20분 데모:

1. 5분: 현재 조사 방식과 시간 확인
2. 8분: 실제 고객 키워드 분석
3. 5분: CSV·HTML·AI 결과 생성
4. 2분: 14일 파일럿 제안

## 7. 영업 반론 대응

| 반론 | 답변 방향 |
|---|---|
| 무료로 볼 수 있음 | 데이터보다 도구 이동과 결과 정리 시간을 절감 |
| 블랙키위를 사용 중 | 대체가 아니라 멀티채널 초기 조사와 제안서 보완 |
| Semrush가 강력함 | 글로벌 SEO는 Semrush, 한국 캠페인 조사는 마켓빅시 |
| 정확한가 | 출처·수집 시점·한계를 표시한 의사결정 참고자료 |
| 자주 안 씀 | 구독 대신 토큰·프로젝트형 상품 |
| 팀이 같이 써야 함 | 현재 지정 계정, 이후 팀 워크스페이스 개발 |

## 8. 콘텐츠·파트너 판매

먼저 제작할 고의도 콘텐츠:

- 마케팅 대행사용 키워드 조사 리포트
- 신제품 출시 전 검색 수요 확인 방법
- 네이버 데이터랩·블랙키위·마켓빅시 비교
- 유튜브·인스타그램 콘텐츠 주제 찾는 방법
- 광고주 제안서용 시장조사 템플릿

파트너 후보:

- 마케팅 교육 강사
- 광고대행사 컨설턴트
- 쇼핑몰 창업 교육 업체
- 스타트업 액셀러레이터
- 소상공인 온라인 판로 교육기관
- 프리랜서 마케터 커뮤니티

성과형 수수료는 고객당 원가가 확인된 후 첫 12개월 매출의 15~20% 범위에서 검토합니다.

## 9. 핵심 경영 지표

북극성 지표는 `주간 완성 의사결정 리포트 수`입니다.

| 영역 | 지표 |
|---|---|
| 획득 | 접촉→답변→데모→파일럿→유료 전환율 |
| 활성화 | 가입 24시간 내 2개 플랫폼 조회＋내보내기 완료율 |
| 사용 | 고객당 주간 완성 리포트 수 |
| 유지 | 4주차 유료 활성률, 월간 해지율 |
| 수익 | 고객당 월매출, 직접원가, 매출총이익률 |
| 인프라 | API 성공률, 분석 1건당 비용, 응답시간 |
| 영업 | CAC, 회수기간, LTV/CAC |

SaaS 원칙 참고: [Stripe SaaS CAC 가이드](https://stripe.com/resources/more/cac-in-saas)

## 10. 손익분기 예시

가정: 매출총이익률 75%, 월 고정비 10,000,000원.

| 평균 고객 매출 | 고객당 공헌이익 | 손익분기 고객 수 |
|---:|---:|---:|
| 29,900원 | 22,425원 | 약 446명 |
| 59,900원 | 44,925원 | 약 223명 |
| 199,900원 | 149,925원 | 약 67명 |

```text
손익분기 고객 수 = 월 고정비 ÷ 고객당 월매출 ÷ 매출총이익률
```

이는 가정치이며 실제 원가 계측 후 교체합니다. 저가 개인 고객만 모으기보다 대행사 고객을 먼저 확보해야 하는 이유를 보여주는 예시입니다.

## 11. 90일 계획

### 1~2주

- 대행사 제안서·캠페인 조사 중심 메시지로 변경
- 샘플 리포트 3종 제작
- 활성화·API·AI 원가 계측
- 파일럿 조건·환불 정책 정리
- 이커머스 전문 대행사 100곳 목록화

### 3~6주

- 총 300곳 개인화 연락
- 20회 이상 데모
- 8~15개 유료 파일럿
- 기존 조사시간과 도입 후 시간 기록

### 7~10주

- 고객 사례 3건
- 반응이 좋은 업종 하나에 집중
- 업종별 템플릿
- 저장·알림·공유 기능 우선 개발

### 11~13주

- 파일럿 전환율·4주 유지율 평가
- 재현 가능한 채널만 반복
- 교육·컨설턴트 파트너 2~3곳
- 퍼널 확인 후에만 소액 광고

90일 통과 기준:

- 유료 대행사 8~10곳
- 파일럿→유료 전환 50% 이상
- 4주차 유료 활성률 60% 이상
- 고객당 월 4건 이상 유효 리포트
- 직접원가가 매출의 25% 이하
- 재현 가능한 영업 채널 1개 이상

## 12. 운영 원칙

- 첫 30개 고객은 대표가 직접 판매
- 같은 설명으로 10번 이상 계약되기 전에 영업사원 채용 금지
- 광고보다 고객 인터뷰와 샘플 리포트에 우선 투자
- 유지율 확인 전 플랫폼과 기능의 무분별한 확장 금지
- 실제 팀 기능 전에는 Enterprise로 과장하지 않음
- 가격 할인보다 온보딩·템플릿·리포트 품질 강화
