# 경쟁사 조사 기반 마켓빅시 실행 전략

기준일: 2026-08-13  
연결 문서: [06_competitor_benchmark.md](06_competitor_benchmark.md)

## 1. 90일 안에 모방할 구조

| 구조 | 참고 서비스 | 마켓빅시 적용 |
|---|---|---|
| 저장 조사·추적·알림 | 판다랭크, 아이템스카우트, Semrush | `고객 프로젝트의 주제·경쟁사·SKU` 저장과 주간 변화 알림 |
| 한 문장 판단 지표 | 블랙키위, 블로그매트릭스 | 원시 수치 옆에 기회·위험·추천 행동과 데이터 시점·산식 표시 |
| 고객용 납품물 | Semrush | 출처 포함 제안서용 HTML/PDF, 브랜드 리포트, 공유 링크 |
| 조사→브리프 | 판다랭크, 리스닝마인드 | 검색 의도·채널 근거·경쟁 빈틈을 콘텐츠 브리프로 전환 |
| SKU·캠페인 연결 | 경쟁 공백 | 콘텐츠에 SKU와 추적 링크를 붙이고 주문 CSV로 매출 연결 |
| 안전한 데이터 보존 | 판다랭크의 반대 경험 | 다운그레이드 시 읽기 전용 보관·내보내기 유예 |

유료 파일럿 이후에는 대행사 고객 폴더, 역할·승인, 3~5명 좌석, 화이트라벨 리포트, AI 검색 브랜드 언급 추적, 스마트스토어 또는 카페24 주문 연결, 대행사 파트너 정책을 검토한다.

지금 모방하지 않을 항목:

- 모든 상품 소싱·구매대행 기능
- 네이버 블로그 무인 대량 게시
- 기능마다 다른 일일 횟수와 크레딧을 쌓은 복잡한 가격표
- 예상 매출을 실제 매출처럼 보여주는 지표
- 사용 빈도 검증 전 영상 자동 렌더링

## 2. 우선 해결할 고객 페인포인트

### 1순위: 대행사 제안서 조사 반복

현재 도구는 키워드·상품·블로그 단위로 나뉜다. 대행사는 네이버, 구글, 유튜브, 인스타그램, 뉴스, 경쟁 콘텐츠를 각각 조회하고 다시 조립한다.

> 광고주 URL·브랜드·상품 입력 → 멀티채널 조사 → 기회·위험 요약 → 출처 포함 제안서 → 저장 프로젝트

### 2순위: 조사 후 실행 단절

> 조사 결과 선택 → SKU 기반 브리프 → 사람 승인 초안 → 추적 링크·내보내기

### 3순위: 성과 증명 불가

검색량·예상 판매량·순위는 실제 고객 매출이 아니다.

> 콘텐츠 ID + SKU + 캠페인 링크 + 주문 CSV/API → 클릭·구매·환불·순매출 리포트

### 4순위: 숫자의 정의와 신뢰

- 모든 숫자에 출처, 수집 시각, 기간, 표본, 추정 여부 표시
- 실측·외부 API·모델 추정을 시각적으로 분리
- 최초·최종·보조 전환 규칙 공개
- API 오류와 데이터 지연 상태 표시

## 3. 가격 전략 가설

경쟁 가격대는 개인·입문 월 1.3만~4만원, 고사용량 개인·소규모 운영 월 4만~15만원, 대행사·기업 월 60만원 이상으로 갈린다. 마켓빅시는 그 사이의 공백을 시험할 수 있다.

| 가설 플랜 | 월 가격 가설 | 핵심 과금 단위 |
|---|---:|---|
| Pro Research | 현 29,900원 유지 | 개인 1명, 제한된 저장 조사·내보내기 |
| Agency Starter | 99,000~149,000원 | 고객 3개, 좌석 3명, 추적·리포트·AI 초안 |
| Agency Growth | 249,000~399,000원 | 고객 10개, 좌석 5명, 화이트라벨·승인·주문 연결 |
| Enterprise | 별도 견적 | SSO, 감사 로그, SLA, API, 장기 보존 |

가격은 기능 수보다 `활성 고객 워크스페이스`, `추적 주제·SKU`, `좌석`, `월 승인 콘텐츠`, `연결 스토어`, `이벤트 처리량`, `데이터 보존`에 연결한다. AI와 외부 API 초과 사용은 별도 사용량으로 분리한다.

## 4. 경쟁사 동일 과제 테스트

공개 조사만으로는 정확성·속도·결과물을 알 수 없으므로 같은 과제를 5개 서비스에서 수행한다.

1. 브랜드 1개, SKU 3개, 경쟁사 3개 등록
2. 동일한 핵심 키워드 20개 조사
3. 네이버 블로그·쇼핑·구글·유튜브 기회 도출
4. 콘텐츠 브리프 또는 초안 생성
5. 일주일 순위·변화 추적
6. 고객용 결과물 내보내기
7. 실제 주문 CSV 연결 가능 여부 확인

| 평가 항목 | 배점 |
|---|---:|
| 첫 가치 도달 시간 | 10 |
| 데이터 출처·시점·산식 | 15 |
| 국내 채널 범위 | 15 |
| 저장·추적·알림 | 15 |
| 콘텐츠·실행 연결 | 15 |
| 팀·고객 관리 | 10 |
| 보고서 품질 | 10 |
| 실제 매출 측정 | 10 |

핵심 질문은 “누가 지표를 가장 많이 보여주는가”가 아니라 “대행사 마케터가 광고주 제안과 월간 성과 보고를 가장 적은 수작업으로 끝내는가”이다.

## 6. 제품 결정

마켓빅시는 블랙키위의 `쉬운 기회 판단`, 판다랭크의 `추적·알림과 실행`, 아이템스카우트의 `객체 기반 반복 관리`, 리스닝마인드의 `소비자 의도`, Semrush의 `프로젝트·보고서·API`를 조합해야 한다.

제품의 중심 객체는 `키워드`가 아니라 다음 연결이어야 한다.

> 고객 워크스페이스 → 브랜드·경쟁사 → 주제·키워드 → SKU → 콘텐츠 → 캠페인 → 주문·순매출

이 연결이 만들어지면 경쟁사보다 지표가 적어도 대행사가 더 높은 가격을 지불할 이유가 생기며, `어떤 조사와 콘텐츠가 어떤 SKU 매출을 만들었는가`라는 방어 가능한 데이터가 축적된다.
