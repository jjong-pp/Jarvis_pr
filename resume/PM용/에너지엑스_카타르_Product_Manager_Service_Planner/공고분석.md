# EnergyX 카타르 PM / 서비스 기획 공고 분석

초판 확인일 2026-10-06, 사용자 방향 정정 2026-10-07. [공고원본](공고원본.png)·[부분 전사본](공고원문.txt)과 [스냅샷](jd_snapshot.md)을 입력으로 삼았다. 외부 자료는 각 문장에 연결한 링크의 확인 범위까지만 사용한다. 전용 [이력서](이력서.md)와 [포트폴리오 수정계획](포트폴리오_수정계획.md)은 2026-10-07 초안이다.

## 배경과 채용 의도

- 대상 포지션은 `Product Manager / Service Planner`다. AEC 기술 기획자·AI 엔지니어·개발자 요구를 이 포지션의 필수 조건으로 합치지 않는다.
- 공고는 신규 디지털 제품 기획, 현업 요구 구조화, 로드맵·우선순위, 개발·디자인·사업 협업, 출시 후 개선을 한 자리에서 요구한다(공고: 모집 포지션 및 주요 업무).
- [Invest Qatar의 2026-02-02 발표](https://www.invest.qa/en/media-centre/news-and-articles/invest-qatar-and-energyx-announce-strategic-partnership-to-establish-global-command-centre-in-qatar)는 EnergyX의 카타르 글로벌 거점 설립 계획과 응용 AI 활동을 확인한다. [회사 제품 설명](https://energyx.ai/intelligence.html)은 에너지 시스템의 입력·대안·운영 측정을 연결한다. **추론:** 이 채용은 기술·사업·현업의 요구를 검증 가능한 제품 범위와 명세로 묶을 사람이 필요한 상황일 수 있다. 배치 제품과 팀의 실제 상태는 미확인이다.
- 트랙은 제품형(P)으로 본다. 공고가 출시 후 운영을 요구하므로 실제 가동 증거를 우선한다. [2026-10-07 사용자 지시] 첫 증거는 SCM 대시보드, 이어서 B2B 주문몰과 관세청 연동이며 마켓빅시는 이번 지원본에서 제외한다.

## 이전 방향과 이번 공고의 연결

- 기존 지원 방향은 PM·SCM 교차 지원, PM은 이력서와 포트폴리오, 광범위 PM은 B2B 주문몰, 제품·AI 공고는 BIGSEE 우선 검토다([AGENTS.md](../../AGENTS.md) `지원 방향`·`문서별 책임`). 장기 목표는 SCM 실무와 컴퓨터공학을 AX 프로젝트 PM으로 연결하고 B2B 솔루션 사업 또는 내부 핵심 인력으로 성장하는 것이다([이전현황.md](../../이전현황.md) 2026-10-04 판단 요약).
- [2026-10-07 정정] 종전 제안 `B2B 첫 증거·마켓빅시 보조` → 사용자 지정 `SCM 대시보드 → B2B 주문몰 → 관세청 연동`, 마켓빅시 완전 제외. 사용자가 제공한 [SCM 플랫폼본](../../SCM용/source/2026-10-03_사용자_SCM기본_플랫폼본.md)의 일하는 관점과 어투를 이번 전용본에 적용한다. 제품·AI 공고에서 마켓빅시를 우선하는 일반 원칙보다 이번 명시 지시가 우선한다.
- 지원본 첫 화면은 `SCM 현업의 반복 확인 → 본인 직접 도구 구축·병행 검증 → B2B 제품 정책·가동 → 통관 연동의 기준 조율`로 연결한다. SCM팀 소속과 사내 프로젝트 PM 역할, 본인 개발과 외부 개발사 구현을 각각 분리한다.
- 포트폴리오는 [24장 기본틀](../../공통자료/포트폴리오_베이스.md)에서 마켓빅시 7장을 빼고 대시보드 4장을 추가한 21장 [수정계획](포트폴리오_수정계획.md)으로 작성한다. PPTX 반영은 사용자의 별도 지시가 필요하다.

## 리스크와 다음 행동

1. **자격 게이트 미확인:** 해외 근무와 영어 학습 의지는 2026-10-07 확인됐다. 실제 2026년 중 도하 상주 가능 시점은 미확인이다. 불가능하면 보류. 영어 업무 경험 부재만으로 미충족이라고 쓰지 않는다.
2. **서류 경쟁력:** 공식 PM 직함·사내 개발/디자인 협업·에너지 도메인·장기 제품 지표가 없다. B2B 운영 전환의 직접 증거로 보완할 수 있으나 공백은 숨기지 않는다.
3. **공고 충돌:** 접수 마감은 2026-10-15/16, 학력은 4년제 이상/무관으로 플랫폼마다 다르다. 사람인은 도하 상주 가능 시점을 `2026년 9월부터`로 적어 이미지의 `2026년 중`·10월 30일 시작 예정과도 충돌한다. 공식 접수 링크·시작 시점·졸업 예정자 인정·담당 제품·현지 고용 조건을 확인한다([jd_snapshot.md](jd_snapshot.md)).
4. **문안 정정:** [PM 기본틀](../기본틀_PM_이력서.md)의 `자동·수기 테스트 약 100건`은 자동 검증 테스트로 읽힐 수 있다. SCM N-030b대로 자동 생성한 시험 주문과 수기 주문을 사용한 기능 QA로 풀어 써야 한다. 관세청 `운영 환경 30건`도 `운영 환경 테스트 30건`으로 적는다. 이 문안을 그대로 제출하지 않는다.

판정과 독립 평가 기록은 [적합도_3관점.md](적합도_3관점.md)에 둔다. 사용자가 2026-10-07 전용 초안 작성을 지시해 [이력서](이력서.md)와 [포트폴리오 수정계획](포트폴리오_수정계획.md)을 만들었다. 지원·외부 제출 여부는 별도 결정이다.
