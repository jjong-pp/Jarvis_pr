# EnergyX 카타르 Product Manager / Service Planner 공고 스냅샷

- 확인일: 2026-10-06
- [2026-10-07 재확인] [잡코리아 개별 공고](https://www.jobkorea.co.kr/Recruit/GI_Read/50002546)는 2026-10-16 마감·학력무관, [사람인 개별 공고](https://m.saramin.co.kr/job-search/view?cn=location-job&cns=recently-list&rec_idx=55039049&referNonce=&t_category=oversea&t_content=generic)는 2026-10-15 23:59 마감·4년제 이상·`2026년 9월부터 도하 상주 가능` 표기가 그대로다. 플랫폼 표시 간 충돌은 계속 미해결이다.
- 원본: [사용자 첨부 이미지](공고원본.png). [부분 전사본](공고원문.txt)은 사용자 제공 텍스트와 이미지를 바탕으로 채용 조건 중심으로 옮겼다.
- 대상: `Product Manager / Service Planner` 실무담당자. 같은 이미지의 AEC·AI·개발 직무는 별도 포지션이다.
- 상태: [잡코리아 개별 공고](https://www.jobkorea.co.kr/Recruit/GI_Read/50002546)와 [사람인 개별 공고](https://m.saramin.co.kr/job-search/view?cn=location-job&cns=recently-list&rec_idx=55039049&referNonce=&t_category=oversea&t_content=generic) 확인. [EnergyX 공식 Careers](https://energyx.ai/careers.html)에는 이 직무의 개별 공고·접수 링크가 보이지 않는다.
- 마감: 잡코리아 2026-10-16, 사람인 개별 공고 2026-10-15 23:59. 서로 달라 공식 마감은 미확인. 일정 계획에는 이른 날짜인 2026-10-15를 사용하되 확정값으로 쓰지 않는다.
- 접수: 이미지에는 포지션 링크를 통한 홈페이지 접수, 이력서·자기소개서 제출이라고 적혀 있다. 사람인 개별 공고는 홈페이지 지원·자유양식으로 표시한다. 회사 공식 접수 링크와 제출 언어·파일 형식은 미확인.
- 근무: 이미지 기준 도하 상주, 시작 예정 2026-10-30 전후 협의 가능. 사람인 개별 공고의 자격요건은 `2026년 9월부터 도하 상주 가능`으로 표기해 이미지와 충돌하며, 2026-10-06 현재 이미 지난 시점이다. 잡코리아는 정규직, 주5일 09:00~18:00로 표시한다. 현지 계약 주체·비자·근무 제도는 미확인.
