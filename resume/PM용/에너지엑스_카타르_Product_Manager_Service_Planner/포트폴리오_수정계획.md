## 반영 전 자료 확인

- 대시보드 공개 저장소는 데모 DB가 4개 SKU다(SCM C-125). 슬라이드의 실무 범위 약 40개 SKU와 **같은 데이터 화면처럼 섞지 않는다**. 실제 운영 화면의 비식별 제출 가능 여부가 확인되지 않으면 공개 코드 또는 재구성 도식을 사용하고 `데모 데이터 4개 SKU`를 붙인다.
- B2B와 관세청의 `실제 운영 화면 / 외부 개발사 처리결과 / 재구성 화면 / 가상 예시`를 장마다 구분한다. `../증거/submission_safe/`의 제출 가능 자료만 후보로 보고 원본을 확인한다. `raw_private/`는 원본 사용 금지다.
- 고객·수하인·공급사 정보, 주문번호, 절대 단가와 마진은 가린다. 공급사 수를 쓰지 않는다. 시스템 구현과 정책·검수의 역할도 매 장 분리한다.
- 기존 마켓빅시 이미지·문장·링크를 모두 삭제한다. 첫 장과 목차, 마지막 장, 슬라이드 번호 `NN / 21`을 함께 고친다. 이력서의 날짜·학력·수치·역할 표현과 교차 대조한다.
- 실제 PPTX 수정은 사용자가 `PPT 반영`을 지시할 때 진행한다. 그때 기본틀 복사본에서 텍스트와 장 순서를 반영하고 텍스트 넘침과 화면 라벨을 확인한다.
