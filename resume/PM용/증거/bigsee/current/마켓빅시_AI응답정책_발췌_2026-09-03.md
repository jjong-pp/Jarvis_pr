# AI 생성물의 근거·검사·승인 정책

마켓빅시(BIGSEE) 서비스 정책 정의서 발췌 · 2026-09-03

> 작성자 박종혁 · 제품·사업 기획 담당 (개발 구현은 동료 개발자 전담)
> 원 문서는 회원·워크스페이스·요금·조사·결제·콘텐츠 승인 6개 영역의 정책 정의서이며, 이 발췌는 **AI 생성물의 품질과 책임**에 해당하는 부분만 옮긴 것입니다.

---

## 이 정책을 만든 이유

BIGSEE는 네이버·유튜브·구글·인스타·뉴스에서 모은 조사 결과로 **광고 문구와 콘텐츠 초안을 생성**합니다. 생성물이 그대로 게시되면 고객사의 광고 심의 문제가 됩니다. 틀린 숫자 하나가 그렇습니다.

그래서 기준을 "AI가 잘 쓰게"가 아니라 **"사람이 책임질 수 있게"**로 잡았습니다. 아래 세 층으로 나눠 설계했습니다.

```
입력 자격          →  출력 검사          →  승인과 이력
무엇을 근거로          무엇을 막는가          누가 책임지는가
쓸 수 있는가
```

---

## 1. 입력 자격 — 무엇을 근거로 쓸 수 있는가

| 규칙 | 내용 |
|---|---|
| 출처 기록 | 모든 조사 결과에 **출처 · 수집일 · 호출 비용**을 함께 기록한다 |
| 입력 자격 | **출처가 기록되지 않은 값은 초안 생성 입력으로 사용할 수 없다** |
| 미확인 표기 | 확인되지 않은 값은 공백이 아니라 `UNKNOWN`으로 표기한다 |
| 추정 금지 | 추정값·보정값은 표기하지 않는다. 플랫폼이 제공하지 않는 지표는 **항목 자체를 노출하지 않는다** |

공백으로 두면 나중에 누가 채워 넣습니다. `UNKNOWN`으로 두면 채우려면 근거를 가져와야 합니다. 이 차이 때문에 표기 규칙을 명시했습니다.

---

## 2. 출력 검사 — 무엇을 막는가

생성된 초안은 승인 단계로 넘어가기 전에 네 가지를 자동 검사합니다.

| 검사 항목 | 판정 기준 |
|---|---|
| 출처 없는 수치 | 인용 근거가 연결되지 않은 숫자 |
| 효능 · 효과 단정 | 치료 · 개선 · 효과를 단정하는 표현 |
| 최상급 표현 | 최고 · 1위 · 유일 등 객관적 근거 없는 표현 |
| 후기 위장 문장 | 사용자 후기 형식을 모방한 생성 문장 |

**검사를 통과하지 못하면 승인 단계로 이동할 수 없습니다.** 경고 후 통과가 아니라 차단입니다.

---

## 3. 승인과 이력 — 누가 책임지는가

| 규칙 | 내용 |
|---|---|
| 승인 권한 | Owner · Admin 만 보유 |
| 생성 차단 | **승인 없이는 캠페인 · 추적 링크를 만들 수 없다** |
| 이력 보관 | 초안 버전 이력을 보관하고 **승인자와 승인 시각을 기록** |
| 재승인 | 승인 후 수정하면 새 버전으로 저장하고 다시 승인받는다 |
| 게시 책임 | 생성된 콘텐츠의 게시 책임은 **승인한 회원**에게 있다 |

## 4. 운영에서 하지 않기로 한 것

| 제외 | 이유 |
|---|---|
| 자동 대량 게시 기능 | 저가치 대량 콘텐츠 위험. 사람 승인 원칙과 충돌 |
| 허위 리뷰 · 순위 조작 목적의 생성 | 차단 대상으로 명시 |
| 수집 원본 데이터의 재판매 · 재배포 | 외부 플랫폼 데이터는 각 플랫폼 약관이 허용하는 범위에서만 수집 |
| 타인의 지식재산권을 침해하는 콘텐츠 | 서비스 이용 제한 대상 |

## 5. 초안 생성의 전체 흐름

```
조사 브리프        목적 · 대상 · 기간 지정
      ↓
근거 선택          조사 결과에서 인용할 지표 선택 (최대 10개)
      ↓
SKU 연결           관련 상품 연결 (최대 5개)
      ↓
초안 생성          블로그 · Meta · 커뮤니티 · 이메일
      ↓
금지 표현 검사      자동 검사 후 위반 항목 표시 · 미통과 시 진행 불가
      ↓
승인               Owner · Admin 승인 후에만 캠페인 연결
```
