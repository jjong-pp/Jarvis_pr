# PM 이력서와 포트폴리오 구성

기본 묶음은 이력서 1개와 포트폴리오 1개다. 현재 PDF는 보존하며 본문 업데이트는 기술영업 다음 단계다.

| 문서·순서 | 담을 내용 | 쓰는 방식 |
|---|---|---|
| 이력서 1 | 간략 소개 | SCM 현장에서 문제를 발견하고 정책·요구사항·운영 검수로 연결한 주니어 PM 지원 방향 |
| 이력서 2 | 경력과 역할 | 공식 SCM팀 사원과 프로젝트 PM 역할을 분리 |
| 이력서 3 | B2B 주문몰 | 문제·선택·제외 범위, 계정·혼합주문 정책, 검수와 초기 결과 |
| 이력서 4 | 관세청 연동 | 데이터 흐름·처리 단위·예외 조율과 검증 |
| 이력서 5 | 기술·학력 | 확인된 사용 경험, 재학·졸업 구분 |
| 포트폴리오 | 대표 프로젝트의 구체 근거 | 문제 근거 → 대안·판단 → 정책·흐름 → QA·배포 → 결과·한계 |

범용은 B2B부터, 규제·SI·연동 공고는 관세청부터 배치한다. 제품 정의·AI 공고에는 마켓빅시 포함 대안을 선택한다. 기본본과 대안을 한 지원에 함께 첨부하지 않는다. 디자인은 기존 편집 원본을 유지한다.

다음 본문 작업에서는 정산 시간·BIGSEE 시작월·미확인 도구와 기능 완료 표현을 정정하고, 공급사 수 공개 제한을 적용한다. 구체 근거는 공통 경력 원장과 2026-09-17 검수 기록을 따른다. 면접 자료는 추가하지 않는다.
