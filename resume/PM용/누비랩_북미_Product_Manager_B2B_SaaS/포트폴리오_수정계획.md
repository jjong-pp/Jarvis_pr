## 수정 방향

### 표지와 소개

- 핵심 문장: `고객 가설과 제품 기준을 세우고, 운영에서 확인된 결과까지 연결합니다.`
- SCM 직무 소개보다 AI B2B 제품 정의, 실제 B2B 출시, API 정책 설계의 연결을 먼저 보여준다.

### 마켓빅시

- 고객군 비교와 광고대행사 AE 첫 가설
- 판매 MVP 범위와 제외 대상
- 가설 14건의 시험 방법·통과 기준·증거 등급
- H-011 폐기와 H-012 수정 이력
- AI 응답의 출처·미확인값·금지 표현·사람 승인 정책
- 유료 전환·반복 사용·PMF·CAC·리텐션은 미확인으로 명시한다.
- 시작월은 경력 원장의 충돌이 해결되기 전까지 표기하지 않는다.

### B2B 주문몰

- 대안 비교와 오픈 범위 선택
- 회원 등급×상품 카테고리 정책과 혼합주문 예외
- 외부 개발사 협업, 운영 서버 QA와 최종 검수
- 오출고 지표에는 직전 6개월 전체 이력 대비 가동 후 약 1개월이라는 측정 범위를 붙인다.

### 관세청 연동

- 주문번호·포장번호·운송장 관계
- API 접수·대기·병합·오류 수정·재제출 상태
- 관계사별 데이터와 책임 조율
- 테스트 목적 30건의 정상 접수·의도 오류·수정 재제출 검증

## 공고 대응상 보완이 필요한 내용

- 북미 고객과의 영어 커뮤니케이션 경험은 확인 전까지 넣지 않는다.
- 실제 고객 인터뷰, 주 단위 시장 실험, North Star Metric, ARR·MRR·Churn·LTV/CAC, PLG·GTM 성과는 현재 증거가 없으므로 넣지 않는다.
- Python·FastAPI·SQLite·pandas는 대시보드 부록에서 기술 이해의 근거로만 사용한다. 제품 행동 분석이나 AI 예측 성과로 확대하지 않는다.
