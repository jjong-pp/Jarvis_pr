## 7. 에세이 구조

### 1번 — 왜 데이원 Business Owner인가

`Business Owner의 정의 → 왜 성인 직무전환 교육인가 → B2B몰의 E2E 증거 → BIGSEE의 자발성 → 데이원에서 책임질 고객 결과`.

핵심 공백은 `왜 교육인가`다. 회사 소개나 “압축 성장”을 복사하지 않고 본인의 실제 교육·직무전환 경험으로 채운다.

### 2번 — 가장 큰 실패

`기대 결과 → 실제 실패와 영향 → 본인의 잘못된 판단 → 복구 → 실패 전/후 행동 비교 → 이후 재적용 증거`.

관세 프로젝트 일정 지연은 후보일 뿐이다. 현행 정본에는 실패 사실이 없어 사용자 재확정 전에는 제출문을 쓰지 않는다.

### 3번 — 제로에서 성취

두 후보를 사용자 답변 후 결정한다.

- BIGSEE: 제로에서의 자발성은 강함. 다만 활성·유료·반복 사용은 미확인이다.
- B2B몰: 기존 사업은 있었지만 통합 상품·정책은 없었다. 출시 후 측정 결과가 강하다.

성취 기준을 결과 뒤에 끼워 맞추지 않고, 당시 세웠던 기준과 현재의 냉정한 판정을 구분한다.

### 4번 — 0원 옆 400만원 노트북

`모두에게 팔지 않음 → 무료 제품으로 부족한 고객군 선택 → 그 고객의 비싼 실패 정의 → 핵심 기능 하나 → 실제 작업 시연 → 가격 대비 얻는 가치·피하는 손실 → 체험·보증 → 구매·사용 데이터로 검증`.

기능 후보는 `고가치 업무의 중단을 막고 빠르게 복구해 결과를 보장하는 기능`이다. 사용자 관점 확인 후 구체화한다.
