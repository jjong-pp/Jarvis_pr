# 비나우 자기소개서

## 1. 본인이 어떤 사람인지 소개하고 비나우에 지원한 동기를 설명해주세요.

업무를 더 효율적으로 처리할 방법을 찾고, 같은 오류가 반복되지 않도록 절차를 고칩니다. 여러 Excel 자료의 취합 오류를 줄이기 위해 기존 양식을 유지하는 자동취합 대시보드를 제작했습니다. 주문몰과 관세청 연동 업무에서도 주문·출고·정산 기준을 정리하고 검수와 운영을 맡았습니다.

회사를 선택할 때는 신제품 출시·프로모션 계획과 발주·공급 운영이 연결된 업무를 할 수 있는지 봅니다. 현재는 수입 브랜드의 발주부터 입고·채널 재고까지 관리하고 있으며, 다음 단계에서는 자체 브랜드의 상품과 판매 계획을 더 이른 단계부터 다루고 싶습니다. 넘버즈인·퓌·노크를 운영하는 비나우의 구매 수요예측 공고는 기준 데이터 구축, S&OP 운영, 채널별 판매 추이와 프로모션을 반영한 발주 검토를 함께 맡는다는 점에서 이 기준에 맞았습니다.

리테일·이커머스 채널의 식품을 운영하며 같은 SKU도 창고·로트·유통기한별로 구분해 관리했습니다. 6개월 이상 리드타임과 목표재고, 행사 수량을 함께 검토한 경험을 바탕으로 비나우의 브랜드·채널별 판매와 출고 자료를 정리하고 발주 협의에 활용하겠습니다. 장기적으로는 해외 채널 공급과 수출 운영까지 경험을 넓히고 싶습니다.

## 2. 가장 치열하게 노력했던 성공 또는 실패 경험과 그 과정에서 배운 점을 소개해주세요.

약 40개 SKU의 발주 검토에 필요한 자료를 자동 취합하는 대시보드를 제작했습니다. 여러 Excel 자료를 취합하는 데 한 사람이 3~4일 동안 하루 2~3시간을 썼고, 취합할 때마다 데이터 값 오류도 보통 2~3건 발생했습니다. 컴퓨터소프트웨어 전공 지식과 AI 코딩 도구를 활용해 기획·개발·배포를 맡았습니다.

팀원들이 기존 시트에서 어떤 값을 먼저 확인하고 어느 항목을 직접 조정하는지 확인했습니다. 입력 방식은 바꾸지 않고 기존 Excel 양식을 그대로 업로드하면 판매·출고·재고·입고계획 자료가 취합되도록 구성했습니다. 교환 출고와 영업용 사용처럼 판매 없이 재고가 줄어드는 항목을 구분하기 위해 판매실적과 출고량을 분리했고, 창고별 유통기한 재고도 조회할 수 있게 했습니다. 취합한 자료를 바탕으로 담당자가 세일즈 전망과 재고 소진 상황을 검토하고 발주안을 협의했습니다.

월간 발주 검토 자료를 준비하는 방식을 바꾸는 작업이어서 4월 배포 직후 기존 시트를 없애지 않았습니다. 약 두 달간 기존 시트와 업로드 결과를 대조하고 팀원들의 확인 순서와 사용 의견을 반영한 뒤, 6월부터 대시보드로 취합한 자료를 월간 검토의 기준으로 사용했습니다. 시범·병행 기간을 포함해 2026년 4~8월 월간 공급사 발주 검토 5회에 활용했습니다. 취합에 약 6~12시간이 들던 작업을 업로드와 결과 검토까지 1시간 이내로 바꿨고, 도입 후 약 3개월간 대시보드 취합 과정에서 오류가 확인되지 않았습니다.

이 경험에서 팀원이 기존에 자료를 확인하고 조정하던 순서를 유지하는 것이 도구 도입에 중요하다는 점을 배웠습니다. 지금도 매월 데이터를 갱신하고 사용 의견을 반영하며 운영하고 있습니다. 비나우에서도 판매·출고·재고 자료를 같은 기준으로 정리해, 세일즈와 SCM이 자료를 모으는 부담을 줄이고 발주 검토에 활용할 수 있도록 하겠습니다.
