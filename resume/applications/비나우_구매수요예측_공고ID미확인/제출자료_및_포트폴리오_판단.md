# 비나우 제출 자료 및 포트폴리오 판단

확인일: 2026-09-03

## 결론

- 현재 즉시 제출 가능한 자료는 `output/pdf/박종혁_비나우_구매수요예측_SOP_지원서.pdf` 1개다.
- 기존 22장 PM 포트폴리오는 비나우 구매 수요예측 직무와 핵심 메시지가 어긋나므로 제출하지 않는다.
- 포트폴리오는 필수가 아니다. 다만 아래 구성의 비나우 전용 SCM 사례집을 5~6쪽으로 새로 만들 수 있다면 직무 증거가 강화되므로 별도 제출할 가치가 있다.
- 전용 사례집을 만들지 않는다면 불리한 기존 포트폴리오를 덧붙이지 않고 통합 지원서 PDF만 제출한다.

## 비나우 전용 SCM 포트폴리오 권장 구성

1. 표지와 핵심 메시지: 40개 SKU, 24주 발주 계획, 월간 S&OP 운영
2. 문제와 범위: 수작업 8~9시간, 6개월 리드타임, 3개월 목표 재고, MOQ·현금흐름·프로모션 제약
3. 기준 데이터와 산식: 판매·출고·재고·입고 예정·프로모션 데이터를 어떻게 구조화하고 사람이 어떤 보정을 했는지 구분
4. 발주 계획 화면: `C:/MyMain/Eibe/SCM-Dashboard/portfolio/05_order_plan.png` 중심. `데모 데이터 기반 재구성 화면`으로 표시하고 회사명·상품명·금액 마스킹
5. 월간 회의 운영: 세일즈 포캐스트 취합 → 리드타임·목표 재고·현금흐름·MOQ 검토 → 판매 제한·결품·과재고 위험 조정
6. 결과와 한계: 월 8~9시간 작업 자동화, 위험 SKU 4개 식별, 실제 사용이 2개월에 그친 한계와 현업 공동 설계의 학습

## 사용하지 않을 화면과 표현

- `02_dashboard.png`: `undefined`와 빈 차트가 있어 전체 화면 사용 금지
- `03_inventory.png`: 빈 화면이어서 제외
- 프로모션·현금흐름이 자동 반영된다고 표현하지 않음. 실제 운영자가 판단·보정한 영역으로 구분
- `무한 확장`, `모든 데이터 자동화`, `AX 도입 완료` 표현 금지
- 프로젝트 기간은 현재 서로 다른 기록이 있어 확정 전 포트폴리오에 기재하지 않음
