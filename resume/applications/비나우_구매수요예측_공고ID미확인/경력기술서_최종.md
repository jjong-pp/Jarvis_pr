# 박종혁 경력기술서

지원 분야: 비나우 구매 수요예측(S&OP)

아이베(EIBE) | SCM팀 · 사원 · 정규직  
2025.09.08~재직 중 · 총 경력 1년

글로벌 영유아 영양 브랜드의 직구·내수 합계 약 40개 SKU를 담당. 자사몰·쿠팡·네이버·컬리·오프라인·면세점·B2B의 판매·출고·재고 데이터를 분석하고, 공급사 발주·납기부터 수입·입고와 메인 창고·3PL의 로트·유통기한별 재고까지 관리.

## 핵심 업무

- SCM·세일즈팀이 참여하는 월간 S&OP의 자료 취합·회의 운영(팀장급 2명·팀원 2명). 판매 전망과 비판매 출고를 포함한 출고량 차이를 주·월간 분석하고 실무자 가중치를 반영해 발주 협의안 작성
- 6개월 이상 리드타임·목표재고·유통기한·MOQ·현금흐름을 검토해 SKU별 발주 수량 산출. SCM·세일즈 팀장 협의·승인 후 공급사 발주와 생산·선적·납기 조율
- 해상·항공 운송, 수입 서류·식약처 절차·통관·입고·정산 관리. 채널별 행사 수량·사입·재고 배분·이관과 결품·과재고 위험 검토
- 창고·로트별 선기한선출(FEFO) 재고, 식품이력추적, 유통기한 임박 주차·폐기 예상량·판매 촉진 필요 SKU 관리
- 2026.07 이후 내수 판매 증가에 따른 공급 위험을 식별해 긴급 항공 운송 전략과 향후 발주량 조정안을 검토

### 발주 판단 사례: 2027.01~02 공급 대응 발주 확대

- 배경: 내수 판매 증가와 매입가 인상에 대응하면서 기존 월별 구매 한도를 고려해 공급 계획 검토
- 판단: 별도 Excel 시뮬레이션에서 기존안·1월 입고 대안·2월 안의 SKU별 수량과 월별 구매금액, 예상 잔여재고 및 출고량 대비 재고수준 비교
- 협의·결과: 경영지원팀과 발주 확대안을 협의해 수량 증량에 합의하고 PO 발행. 향후 공급을 위한 발주 결정이며 실제 입고·결품 예방 효과는 후속 확인 대상

## 주요 프로젝트

1. 발주 검토 자료 자동취합 대시보드 구축·운영

- 기간: 2026.04 시범 배포~현재 · 약 2개월 병행 검증 후 2026.06 월간 발주 검토의 기준 자료로 사용
- 배경: 취합 1회에 담당자 1명이 약 6~12시간을 사용하고 데이터 값 오류가 보통 2~3건 발생
- 역할: 컴퓨터 지식과 AI 코딩 도구를 활용한 기획·데이터 설계·개발·배포·운영 개선
- 수행: Excel 업로드로 판매·출고·현재고·입고계획 자료를 자동 취합. 판매실적과 교환·영업용 사용을 포함한 출고량을 구분하고 창고·유통기한별 재고 조회 구성
- 사용자 대응: 업로드한 데이터와 각 항목의 의미를 설명하며 사용법 안내. Excel 업로드 외에 직접 입력·수정·삭제와 사용자 가중치에 따른 재고 흐름 확인 기능 제공
- 실무 적용: 취합 자료를 2026.04~08 월간 공급사 발주 검토 5회에 활용. 담당자가 세일즈 전망과 리드타임·목표재고·MOQ·현금흐름을 검토해 발주안을 작성하고 팀장 협의·승인 진행
- 검증·협업: 약 2개월간 기존 시트와 업로드 결과를 대조하고, 팀원들의 자료 확인 순서와 사용 의견을 반영해 개선. 가중치 시나리오는 담당자가 설정한 가정에 따른 재고 검토에 활용
- 운영 효율: 기존 취합 약 6~12시간을 Excel 업로드·결과 검토 1시간 이내로 개선
- 원천 자료 정비: 생산발주·입고 자료의 PO 번호·생산월 컬럼 차이로 입고 예정 SKU가 누락되거나 다른 월에 반영되는 문제에 대응해 새 양식과 컬럼 형식 도입. 한글 연·월 표기를 YYYY-MM-01로 통일해 월별 비교 기준 정비. 일자는 월을 나타내기 위한 고정값이며 실제 생산일을 의미하지 않음
- 취합 검증: 도입 후 약 3개월간 대시보드 취합 과정 오류 0건 확인. 원천 자료의 양식·내용 오류와 구분한 관찰값

2. 신규 ERP 기획 참여 및 관세청 통관 연동

- 기간: 관세청 연동 2026.02~현재 · 2026.08.28 운영 전환
- 역할·목적: 신규 ERP의 상품·주문·교환·반품 기능 기획·테스트에 참여. 관세청 연동은 PM 역할로 자사몰·외부 채널 주문과 ERP·WMS·통관 시스템의 연결을 기획하고 관계사 조율·검수·운영 주도
- 수행: ERP의 주문·상품 정보와 창고 출고, 통관·택배 배송 지식에 컴퓨터 지식을 결합해 채널별 주문 수집, WMS 출고·송장 연계, 통관정보 전달과 오류 수정·재처리 요건 정의
- 운영·검증: 신규 연동과 기존 통관 방식을 병행하며 오류 주문의 출고 보류·보완·재처리 관리. 운영환경 시나리오 30건에서 정상 접수·의도한 오류 반환·수정 재제출을 기대 결과대로 확인
- 운영 결과: 2026.08.28~2026.09.15 집계 일평균 약 300건(자사몰 약 230건·외부 채널 약 70건), 집계 대상 주문 전체 통관 완료
- 후속 과제: 일회용 통관부호 관련 보완에 필요한 정보를 고객에게 수집하는 웹서비스 기획 중

3. 리콜·폐기 및 공급사 보상 대응

- 기간: 2026.06~2026.07
- 역할·수행: 리콜 대상의 출고 제한과 창고·SKU·로트·유통기한별 재고를 확인하고, 공급사·국내외 창고·감사기관 일정과 폐기 증빙·보상 자료 조율
- 결과: 국내외 창고 폐기·감사 결과보고 완성 및 공급사 보상 절차 완료

4. B2B 주문몰 도입 및 공급사 운영 관리

- 기간: 2026.06~2026.08 · 2026.07.16 핵심 서비스 가동 · 2026.08.31 최종 검수
- 역할·수행: 고객사 주문부터 공급사별 출고·정산까지 수기로 처리하던 업무를 개선하기 위해 주문몰 도입을 제안하고, 고객사·운영자·공급사별 상품·단가·권한과 주문·결제·정산 정책을 설계해 개발사 검수·운영 적용
- 결과: 핵심 주문·입금·정산 업무를 시스템으로 전환. 직전 6개월 전체 출고·CS 이력의 오출고 월평균 2~3건 대비 2026.07.16 가동 후 약 1개월간 0건 확인
