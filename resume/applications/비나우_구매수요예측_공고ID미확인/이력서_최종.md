# 박종혁

지원 분야: 비나우 구매 수요예측(S&OP)

## 간략 소개

저는 발주와 물류 운영에서 문제가 생기면 데이터와 현장을 함께 확인하는 SCM 담당자입니다. 익숙하지 않은 일이 주어졌을 때도 필요한 지식을 찾아 익히고, 관계자들과 실제로 실행할 수 있는 방법을 만들어왔습니다.

글로벌 영유아 영양 브랜드의 직구·내수 약 40개 SKU를 맡아 리테일·이커머스 채널의 판매와 재고를 살피고, 해외 공급사 발주부터 수입·입고까지 관리했습니다. 리드타임이 6개월 이상인 식품을 다루면서 판매계획, 도착 시점, 유통기한을 함께 놓고 발주량을 검토했습니다. 매달 반복되던 자료 취합은 대시보드를 직접 기획·개발해 줄였고, 운영 중 발견한 양식 차이는 입력 기준을 정비하며 개선했습니다.

관세청 통관 연동에서는 PM 역할로 기획과 검증을 주도하며 개발사·물류사·통관대행사와 업무를 조율했습니다. ERP, 창고 현장, 통관, 택배 배송 지식에 컴퓨터 지식을 더해 주문 오류의 출고 보류·보완·재처리 기준을 정하고 검증했습니다. 시스템이 가동된 뒤에도 남은 오류를 관리하고 후속 개선을 기획했습니다.

제가 이어가고 싶은 일은 판매계획이 생산·입고·채널별 공급으로 이어지도록 각 단계의 데이터를 맞추고 운영을 개선하는 것입니다. 자체 브랜드의 신제품과 프로모션, 해외 수출까지 다양한 상황을 다루며 판매와 공급을 하나의 프로세스로 연결하고 싶습니다. 판매 변화가 발주와 재고 운영에 제때 반영되도록 현업이 함께 사용할 수 있는 데이터와 업무 기준을 만들겠습니다.

## 핵심 역량

다채널 데이터 분석 / 판매 전망 검토·S&OP / 발주·공급사 관리 / 유통기한 재고 관리 / 자료 취합 자동화

- SCM·세일즈 월간 S&OP의 자료 취합·회의 운영. 판매 전망과 비판매 출고를 포함한 출고량 차이를 분석하고 실무자 가중치를 반영해 발주 협의안 작성
- 리드타임·목표재고·유통기한·최소발주수량(MOQ)·현금흐름을 고려한 SKU별 발주량 산출. 경영지원팀과 2027.01~02 공급 대응 발주 확대 합의·PO 발행. 해외 공급사 생산·선적·납기 조율 및 해상·항공 수입·통관·입고·정산 관리
- Excel 자료 자동취합·재고 조회 대시보드 기획·개발·운영. 입력 양식·생산월 형식 정비, 직접 입력·수정·삭제와 사용자 가중치 기반 재고 시뮬레이션 제공. 2026.04~08 월간 발주 검토 5회에 취합 자료 활용
- 창고·로트·유통기한별 선기한선출(FEFO) 재고 및 식품이력추적 관리. 주간 폐기 예상량과 판매 촉진 필요 SKU 검토
- 채널별 행사 수량·사입·재고 배분·이관 조정. 3PL 입출고 일정·입고예정정보(ASN)·배차·물류비 정산과 교환·반품 기준 관리
- 신규 ERP의 SKU·교환·반품 기준과 채널 주문·WMS·통관정보 연계 기획·테스트 참여. 관세청 연동은 PM 역할로 기획·관계사 조율·검수·운영 주도
- B2B 고객사·공급사의 주문·납기·출고·정산 조율, 주문몰 도입 제안·정책 설계·검수·운영
- 리콜 대상 재고 확인, 국내외 창고 폐기·감사 증빙·결과보고 및 공급사 보상 절차 관리
