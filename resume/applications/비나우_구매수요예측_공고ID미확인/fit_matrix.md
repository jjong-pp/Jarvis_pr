# 비나우 구매 수요예측(S&OP) 적합도 및 지원 전략

기준: 2026-09-15, 사용자가 마지막으로 제시한 경력 1~3년·4년제 학사 요건 공고. 종전 전임직 공고와 혼용하지 않는다.

## 지원 판정

**조건부 지원.** 사용자가 자격 리스크를 인지하고 지원을 확정했으므로 제출본 작성을 진행한다.

| 자격 게이트 | 판정 | 근거·대응 |
|---|---|---|
| 4년제 학사 취득 | 미충족 | C-003·C-003a. 고려사이버대학교 재학 중이며 별도 학사 학위가 없다. 취득으로 오기하지 않는다. |
| 1~3년 또는 준하는 경험 | 충족 | C-010a·C-012a. 2025-09-08 입사, 2026-09-08에 1년 도달. |
| 화장품 또는 리테일·이커머스 SCM·수요예측 | 이커머스 경력으로 대응 | C-070~085·C-098·C-108의 다채널 데이터 분석·발주·재고 운영. 화장품 직접 경력은 없음. |

## 요구사항-증거 매트릭스

| 공고 요구 | 대응 증거 | 강도 | 제출문 방향 |
|---|---|---:|---|
| 수요예측 기준 데이터 구축 | C-077~C-080, C-086 | 강 | 40개 SKU·24주 전망, 취합 약 6~12시간→업로드·결과 검토 1시간 이내, 도입 후 약 3개월 취합 오류 0건(C-104). 예측정확도 개선과 구분한다. |
| S&OP 회의체 운영 | C-082~083·C-105·C-090 | 강 | 주·월간 세일즈 예측과 출고량 차이 분석, 가중치 조정 후 발주안 협의. 수량 산출·팀장 협의·승인 후 공급사 발주 역할을 구분한다. |
| 채널별 판매·프로모션 반영 | C-083~084·C-098·C-108 | 강 | 자사몰·쿠팡·네이버·컬리·오프라인·면세점·B2B 판매·출고·재고 데이터 분석과 행사 수량·재고 배분 조정. 올리브영 경험은 주장하지 않으며 3PL은 물류 거점으로 구분한다. |
| 결품·과재고 관리 | C-080·C-083 | 강 | 주간 유통기한 임박 주차·폐기 예상량·판촉 필요 SKU 검토(C-106), 행사 수량 제한과 재고 이관 경험을 쓴다. 과거 12개월 재현에서 위험 4개 SKU를 식별한 결과는 계산 검증으로 구분한다. 실제 결품 예방이나 예측 정확도 향상으로 확대하지 않는다. |
| 더존 ERP | 미충족 | C-085 | 사내 개발 ERP의 초기 SKU·업무 기능 설정과 API 연결 경험으로 보완하되 더존 경험으로 표현하지 않는다. |
| AI 업무 적용 | C-078·C-086 | 강 | 컴퓨터 전공 지식과 평소 활용하는 AI 도구로 대시보드를 제작·개선(C-111), 업무 규칙·결과값을 직접 검증하고 취합 시간·오류를 개선한 결과를 쓴다. |
| 어학 성적 기재 | C-007 | 확인 | 공인 어학 성적 미보유로 명시 |
| 협업·수치 검증 | C-070·C-072·C-082~C-085 + 업무표 | 강 | 세일즈·SCM·물류팀·3PL 역할을 분리하고 재고·입고예정·유통기한·MOQ·현금흐름 검토를 앞세운다. C-090의 수량 산출·팀장 협의·승인 후 공급사 전달 역할을 명시한다. B2B 공급사별 주문·납기·출고·정산 조율(C-109)도 포함한다. |

## 핵심 메시지

> 다채널 판매·출고·재고 데이터를 분석해 발주안과 유통기한 재고 운영을 맡고, AI 도구와 컴퓨터 전공을 활용해 취합·검토 업무를 개선한 SCM 실무자

배치 순서는 다음과 같다.

1. 중국 전진창고 직구와 국내 직수입 내수의 이중 공급망 운영
2. 6개월 이상 리드타임·목표재고·MOQ·현금흐름·프로모션을 반영한 월간 S&OP와 발주 검토
3. 가격·행사·입고예정을 반영한 판매 제한·채널 사입·재고 이관
4. 40개 SKU·24주 수요예측 및 재고 대시보드
5. 생산중단·수입자 변경·유통기한·리콜 등 공급 예외 관리
6. 고객사 주문몰과 관세청 연동의 전체 기획·QA·운영 전환

## 제외·축소

- BIGSEE와 PM 전환 서사
- 관세청은 핵심 사례로 유지하되 법령·본인인증의 내부 필드와 대외비만 제외. C-100~102의 집계기간·일평균 300건·대상 전체 통관 완료는 사용
- B2B몰은 공급사 관리·주문·출고·정산 개선 중심으로 기술하고 과도한 제품 정책 상세만 제외
- 더존 사용 경험, 화장품 구매 경험
- `SKU 무한 확장`, `모든 데이터 자동 반영`, `AX 도입 완료`
- 대시보드가 프로모션·현금흐름·안전재고·ROP를 자동 계산한다는 표현

## 예상 탈락 사유와 대응

1. **4년제 학사 미취득**: 문구로 해소할 수 없는 필수요건 리스크다. 학력은 재학 중으로 정확히 표기한다.
2. **지원 공고 구분**: 경력 공고와 전환형 인턴/전임직 공고의 요건을 혼용하지 않는다. 경력 1년은 현재 충족.
3. **화장품 도메인 공백**: 빠른 행사·채널 변동을 다룬 수입상품·이커머스 경험의 전이 가능성을 보여준다.
4. **예측 정확도 지표 부재**: 정확도 개선을 주장하지 않는다. 취합 약 6~12시간→업로드·결과 검토 1시간 이내, 약 3개월 취합 오류 0건과 과거 위험 구간 재현 결과를 각각 구분해 사용한다.

## 지원동기·사례 배치 보완 — 2026-09-15

- C-107: 자체 브랜드의 신제품·프로모션에 따른 수요 변화와 공급 계획을 다루려는 방향. 장기적으로 해외 채널 공급·수출 운영 경험 확대. 이미 수행한 화장품·BM 경력으로 쓰지 않는다.
- 경력기술서 프로젝트 순서: 대시보드 → 관세청·ERP → 리콜 → B2B 주문몰·공급사 관리. 일상 발주·수입 업무는 이력서 담당업무에 두며 별도 프로젝트로 늘리지 않는다.
- [정정 이력] 종전 취합 전 시간 미확인과 만 1년 미만 경고는 최신 사용자 답변·기준일에 따라 해소. 학사 미취득은 남으며 실무 성과가 필수 학위를 대체한다고 주장하지 않는다.
