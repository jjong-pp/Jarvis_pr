# 비나우 구매 수요예측(S&OP) 적합도 및 지원 전략

## 지원 판정

**조건부 지원.** 사용자가 자격 리스크를 인지하고 지원을 확정했으므로 제출본 작성을 진행한다.

| 자격 게이트 | 판정 | 근거·대응 |
|---|---|---|
| 4년제 학사 취득 | 미충족 | C-003·C-003a. 고려사이버대학교 재학 중이며 별도 학사 학위가 없다. 취득으로 오기하지 않는다. |
| 1~3년 또는 준하는 경험 | 조건부 | C-010a·C-012a. 입사일은 2025-09-08이며 2026-09-02 기준 359일이다. 정확한 1년은 2026-09-08이나 업무 범위로 유관 경험을 증명한다. |
| 화장품 또는 리테일·이커머스 SCM·수요예측 | 부분 충족 | 화장품 경력은 없지만 C-070~C-085의 수입상품 구매, 다채널 이커머스, 수요예측·재고 운영 경험이 있다. |

## 요구사항-증거 매트릭스

| 공고 요구 | 대응 증거 | 강도 | 제출문 방향 |
|---|---|---:|---|
| 수요예측 기준 데이터 구축 | C-077~C-080, C-086 | 강 | 40개 SKU 실무 범위, 최근 12주 판매·출고, 최신 재고, 도착월 발주계획, 24주 예상 재고를 제시한다. 예측 정확도 향상률은 미계측이므로 쓰지 않는다. |
| S&OP 회의체 운영 | C-082~C-083 | 강 | 월간 SCM·세일즈 회의의 자료 취합과 운영, 6개월 리드타임·3개월 목표재고·현금흐름·MOQ 검토 역할을 쓴다. |
| 채널별 판매·프로모션 반영 | C-083~C-084 | 강 | 세일즈 전망과 행사 수량을 발주안에 반영하고 쿠팡·네이버 사입·재고 이관을 관리한 경험을 쓴다. |
| 결품·과재고 관리 | C-080·C-083 | 강 | 품절 위험 4개 SKU 사전 파악과 행사 수량 제한을 쓴다. 실제 결품 방지율이나 예측 정확도는 만들지 않는다. |
| 더존 ERP | 미충족 | C-085 | 사내 개발 ERP의 초기 SKU·업무 기능 설정과 API 연결 경험으로 보완하되 더존 경험으로 표현하지 않는다. |
| AI 업무 적용 | C-078·C-086 | 강 | 컴퓨터 전공 지식과 생성형 AI 코딩 도구로 대시보드를 구현하고 업무 규칙·결과값을 직접 검증한 경험을 쓴다. |
| 어학 성적 기재 | C-007 | 확인 | 공인 어학 성적 미보유로 명시 |
| 협업·수치 검증 | C-070·C-072·C-082~C-085 | 강 | 세일즈·SCM·물류팀·3PL 역할을 분리하고 PO-인보이스, 재고, MOQ, 현금흐름 검토를 앞세운다. |

## 핵심 메시지

> 판매·재고 데이터를 발주 기준으로 바꾸고 월간 S&OP까지 운영한 수요예측 실무자

배치 순서는 다음과 같다.

1. 40개 SKU·24주 수요예측 및 재고 대시보드
2. 월간 SCM·세일즈 S&OP 운영
3. 6개월 리드타임·3개월 목표재고·MOQ·현금흐름·프로모션을 반영한 발주 검토
4. 쿠팡·네이버·3PL 사입·이관·ASN·배차 운영
5. 내부 ERP와 채널·WMS·통관사 데이터 흐름 초기 설정

## 제외·축소

- BIGSEE와 PM 전환 서사
- 관세청 법령·본인인증·오류 복구 상세
- B2B몰의 제품 정책 상세
- 더존 사용 경험, 화장품 구매 경험
- `SKU 무한 확장`, `모든 데이터 자동 반영`, `AX 도입 완료`
- 대시보드가 프로모션·현금흐름·안전재고·ROP를 자동 계산한다는 표현

## 예상 탈락 사유와 대응

1. **4년제 학사 미취득**: 문구로 해소할 수 없는 필수요건 리스크다. 학력은 재학 중으로 정확히 표기한다.
2. **2026-09-02 기준 만 1년 미만**: 입사일을 정확히 표기하고 수요예측·S&OP·구매·재고 업무 범위로 보완한다.
3. **화장품 도메인 공백**: 빠른 행사·채널 변동을 다룬 수입상품·이커머스 경험의 전이 가능성을 보여준다.
4. **예측 정확도 지표 부재**: 정확도 개선을 주장하지 않고, 의사결정 시간 절감·위험 SKU 발견·회의 안착 결과를 사용한다.
