# 박종혁

지원 직무: 비나우 구매 수요예측(S&OP)

## 간략 소개

6개월 이상 리드타임의 수입 상품을 대상으로 월간 S&OP와 발주·재고 운영을 담당해 왔습니다. 세일즈팀의 판매 전망을 정해진 양식으로 취합하고 현재고, 입고계획, 3개월 수준의 목표재고, 현금흐름, MOQ, 행사 수량을 함께 검토해 발주안을 준비했습니다.

반복되는 수기 취합을 줄이기 위해 실제 업무 대상 40개 SKU의 24주 수요예측·재고 대시보드를 기획하고, 생성형 AI 코딩 도구를 활용해 데이터 구조 설계부터 구현과 배포까지 수행했습니다. 최근 12주 판매·출고 실적, 최신 재고, 발주계획 도착월, 실무자 가중치를 이용해 예상 재고와 발주 제안량을 확인하도록 구성하고 업무 규칙과 결과값은 직접 검증했습니다. 초기 버전이 현업에서 사용되지 않았던 문제는 담당자와 화면·로직을 함께 수정해 월간 발주 검토 기준으로 안착시켰습니다.

수요예측 운영 경험과 컴퓨터소프트웨어 전공 역량을 결합해, 현장에서 반복되는 판단을 신뢰할 수 있는 데이터 기준과 운영 시스템으로 발전시키는 것이 목표입니다.

- 세일즈 전망과 판매·출고·현재고·입고계획을 취합하고, 6개월 이상 리드타임·3개월 수준의 목표재고·현금흐름·공급사 MOQ를 검토해 월간 S&OP 발주안 준비
- 채널별 판매 추이와 프로모션 사전 물동량을 검토하고, 판매 제한·채널 배분·발주량 조정을 통해 결품·과재고 위험 관리
- 쿠팡·네이버 풀필먼트 사입·재고 이관, 3PL ASN, 물류팀 현장 작업 전달과 배차를 포함한 재고 운영
- Nutricia 상품의 FEFO·수입통관·컴플라이언스 제약을 관리하고, 리콜 시 한국·중국 창고의 감사 입회·폐기 증빙·결과보고 절차 정리
- 주문·입금·출고·정산·통관의 현행 업무와 데이터 흐름을 분석하고, 반복 오류와 담당자 의존 업무의 시스템 전환 범위·우선순위 정의
- 고객사·운영자·공급사별 화면·권한·주문 상태와 자사몰·외부 판매채널·사내 ERP·WMS·통관 관련 시스템 간 API 필드·오류 재처리·QA·운영 정책 정의
