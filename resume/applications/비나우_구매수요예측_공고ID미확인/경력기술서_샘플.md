## 경력기술서

### 사내 업무 및 프로젝트

1. 40개 SKU 수요예측·재고 대시보드 구축

- 기간: 2026.04 ~ 현재
- 목적: 매월 약 3~4일이 걸리던 데이터 취합과 Excel 양식 작업을 줄이고, 34개 롤링 탭의 재고 판단 기준을 팀이 함께 사용하는 구조로 전환
- 역할: 요구사항 정의, 데이터 구조와 계산 규칙 설계, 생성형 AI 코딩 도구를 활용한 개발, 배포와 운영 개선까지 직접 수행
- 구현: 최근 최대 12주 출고 평균, 판매·출고 차이, 최신 현재고, 도착월별 입고계획, 실무자 가중치를 연결해 24주 예상재고와 포장입수량 단위의 발주 제안량 산출. 프로모션·목표재고·현금흐름·MOQ는 S&OP에서 담당자가 최종 판단하도록 분리
- 협업: 2026.04 시범 배포 후 약 2개월간 기존 시트와 병행 사용. 세일즈팀의 전망·프로모션 확인 순서와 SCM팀의 현재고·입고·리드타임 검토 방식을 관찰하고 화면 순서와 수동 조정 항목을 수정
- 성과: 2026.06부터 월간 발주 검토 기준으로 이관해 매월 갱신·운영. 전년도 12개월 데이터와 당시 입고계획을 넣은 재현 검증에서 2026.05~06 재고 부족 위험 4개 SKU를 식별. 과거 위험 재현 결과이며 실제 결품 예방률과 예측 정확도 개선률은 미계측

2. 전자상거래 법령 개정 대응 시스템 구축

- 기간: 2026.02 ~ 현재 · 개발비 약 4,000만원
- 목적: 관세청의 전자상거래 거래정보 사전제출 제도에 맞춰 자사몰·외부 판매채널의 통관 데이터를 자동 제출하고 오류 주문을 운영 중 복구할 수 있는 체계 마련
- 역할: 국내 데이터베이스 중심 연동 구조와 두 가지 본인인증 경로, 제출 상태, 오류 수정·재제출 정책 설계. 자사몰·외부 채널·ERP·WMS·통관사 사이의 API 필드와 5개 관계사의 연동 요건 조율
- 실행: 기획서·과업범위서·데이터 매핑·사용자 흐름·QA 시나리오를 작성하고 외부 개발사와 일정·이슈·배포 관리. 운영 담당자의 수정·재제출 절차와 시스템 중단 시 대응 기준 정립
- 성과: 운영환경 시나리오 30건에서 정상 접수, 의도한 오류 반환과 수정 재제출을 확인한 뒤 2026.08.28 운영 전환. 초기 운영 피드백을 반영해 안정화 진행

3. 고객사 전용 회원제 커머스 구축

- 기간: 2026.06 ~ 2026.08 · 계약 고객사 약 140곳 · 공급사 5곳
- 목적: 설문과 Excel로 처리하던 주문·입금 확인·출고 요청·월말 정산의 반복 오류와 담당자 의존도를 줄이기 위한 시스템 전환
- 역할: 현행 프로세스와 오류 유형을 분석해 도입안을 제안하고 개발 예산 확보. 고객사·운영자·공급사별 화면과 권한, 4개 계정 유형별 상품·단가·결제·포인트, 주문 상태와 공급사별 출고 정책 설계
- 실행: 요구사항 대장, 권한표, 사용자 흐름, QA 시나리오와 운영 매뉴얼을 작성하고 외부 개발사의 개발·배포·회귀 테스트 및 운영 적용 관리
- 성과: 2026.07.16 핵심 주문·입금·정산 흐름 전체 가동. 직전 6개월 월평균 2~3건이던 오출고가 가동 후 약 1개월간 0건으로 감소했으며, 운영 문의와 예외를 반영해 2026.08.31 최종 검수 완료

4. 대규모 리콜·폐기 및 재고 회복 대응

- 기간: 2026.06 ~ 2026.07
- 범위: 영유아용 분유 105,000캔, 한국·중국 물류창고
- 목적: 리콜 대상 재고의 판매·출고를 차단하고 SGS 기준에 맞는 폐기 증빙을 확보한 뒤 보상과 정상 재고 운영까지 연결
- 역할: 국가·창고·SKU·로트별 대상 수량과 유통기한을 대조해 격리 재고 확정. 공급사 본사·한국 및 중국 물류창고·SGS 감사기관의 역할과 일정 조율
- 실행: 판매 제한과 출고 차단, 현장 입회, 폐기 방식, 수량 증빙과 결과보고서 요건을 정리하고 창고별 진행 현황 관리. 폐기 수량과 보상 대상 금액을 대조하고 잔여 재고·입고예정 물량을 기준으로 채널별 재고 회복 계획 수립
- 성과: 105,000캔의 폐기 증빙과 최종 결과보고를 완료하고 관계사 조율을 통해 공급사 본사 보상액 100% 회수
