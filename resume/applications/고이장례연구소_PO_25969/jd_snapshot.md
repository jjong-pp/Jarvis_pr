## 조직 구조

**두 개 사업 스쿼드. 합류 후 하나에 배치.** 각 스쿼드에 세일즈·오퍼레이션·마케팅·프로덕트가 함께 있다.

- **선불제 스쿼드** — 미리 준비하는 고객의 가입·결제·유지 전 과정. 100원 상조 누적 10만 건.
- **전환 스쿼드** — 실제 장례 발생 시 문의 확보부터 집행까지. SEO로 월 10만 방문.

## 주요업무 (원문 요지)

- 고객이 장례를 준비하는 과정의 문제를 발굴·해결
- **고객과 직접 대화**하며 불안과 니즈를 파악, 상품 가입과 유지로 연결하는 전 과정 설계·운영
- 고객의 목소리와 데이터로 가설 수립 → 빠른 검증 → 운영 프로세스와 고객 경험 개선
- 스쿼드 내 다직군 협업, 스쿼드 리드와 목표 달성
- **상담과 세일즈에서 시작해** 운영 체계 구축·마케팅·프로덕트·비즈니스 개발까지 영역 확장

### 주요 업무 예시 (원문 그대로)

1. 상담 중 '100원 상조' 가격 보장 조건 반복 문의 발견 → 상담 스크립트 재설계 → 가입 전환율 개선
2. 해지 고객 상담 데이터 분석 → 해지 사유 TOP 3 정의 → 방지 프로세스 신규 설계 및 실행
3. 미납 고객 상담 플로우 재설계 → 계약 활성화율 개선

## 자격요건

1. 새로운 도메인과 업무를 빠르게 학습하고 본인의 것으로 만들 수 있는 분
2. 직접 손으로 일하면서도, 반복되는 문제를 구조화하고 개선하려는 태도
3. 데이터에 기반해 문제를 정의하고, 해결 대안을 직접 실행해본 분

## 공고 해석 — 직함과 실질의 차이

**직함은 PO지만 자격요건 3개 어디에도 요구사항 정의·개발 협업·프로덕트 기획이 없다.**

| 신호 | 근거 (원문) |
|---|---|
| 실질은 세일즈·운영 | "상담과 세일즈에서 시작해" |
| 업무 예시 3개가 전부 상담 파생 | 스크립트 재설계 / 해지방어 / 미납관리 |
| 우대사항이 세일즈·운영·그로스 | "고관여 … 세일즈/운영/그로스 경험" |
| 상담을 직접 수행 | "상담을 직접 수행하며 … 체득합니다" |
| 제품 중심 PO와 명시적으로 구분 | "시장의 PO는 보통 제품에서 출발합니다. 반면 고이의 PO는 고객에서 출발합니다" |

선불 상조는 법적으로 **선불식 할부거래**(할부거래법)에 해당하는 금융 유사 상품이다. 해지방어·미납관리·활성화율은 그 업계의 표준 운영 지표다.
