# 비나우 수요예측·SCM 시스템 기획 포트폴리오 스토리보드

## 방향

기존 22쪽 PM 포트폴리오를 그대로 제출하지 않는다. 수요예측 업무를 데이터 구조와 운영 시스템으로 전환한 하나의 사례에 집중한다. PM 역량은 별도 프로젝트를 늘리지 않고 문제 정의, 데이터 기준, 사용자 판단 흐름, QA, 운영 정착에서 보여준다.

## 구성

### 1. 표지

- 제목: 수요예측·재고 운영 포트폴리오
- 부제: 판매·출고·재고 데이터를 월간 발주 판단으로 연결한 경험
- 핵심 범위: 40개 SKU 실무 판단 범위, 24주 예상 재고, 월간 S&OP
- 주의: 약 400억 원은 범위 확인 후 반영

### 2. 운영 맥락과 문제

- 6개월 이상 리드타임의 수입 소비재
- 판매·출고·현재고·입고계획이 여러 파일로 분산
- 월 8~9시간의 취합·Excel 양식 작업
- 발주 판단에는 3개월 목표재고, 현금흐름, MOQ, 프로모션 제약이 함께 작용
- 목적: 숫자 집계보다 위험 SKU와 발주 선택지를 먼저 확인

### 3. 기준 데이터와 판단 경계

- 자동 계산: 최근 최대 12주 출고 평균, 출고·판매 차이 버퍼, 최신 현재고, 도착월 발주계획, 24주 예상 재고
- 실무자 판단: 세일즈 전망, 프로모션 가중치, 3개월 목표재고, 현금흐름, 공급사 MOQ, 최종 발주 수량
- 포인트: 시스템이 결정을 대신하지 않고 같은 기준으로 비교하게 함

### 4. 24주 예상 재고와 발주 검토 화면

- 핵심 화면: `portfolio/assets/05_order_plan_demo.png`
- 강조: 시스템 제안, 실무자 입력, 차이, 가중치, 재고주수 히트맵, 24주 재고 추이
- 화면 라벨: 업무 검증용 재구성 화면·샘플 데이터
- 실제 업무 범위 40개 SKU와 화면의 4개 샘플 SKU를 분리 표기

### 5. 월간 S&OP와 채널 실행

- 세일즈 전망 취합
- 현재고·입고계획 연결
- 리드타임·목표재고·현금흐름·MOQ 검토
- 프로모션 사전 물동량과 판매 제한 수량 조정
- 쿠팡·네이버 풀필먼트 사입·이관
- 3PL ASN과 물류팀 배차·현장 작업 연결
- 본인 제안과 최종 승인권자를 답변 후 구분

### 6. 최초 실패와 운영 정착

- 첫 버전은 2개월 동안 현업 미사용
- 원인: 계산 결과에 집중해 회의 판단 순서를 반영하지 못함
- 개선: 세일즈·SCM 담당자와 화면·로직을 재구성
- 결과: 월 8~9시간 취합 자동화, 품절 위험 4개 SKU 사전 파악, 월간 발주 검토 기준으로 사용
- 한계: WMAPE·Bias와 실제 결품·과재고 개선률은 미계측

### 7. 선택 부록: 공급망 위험과 시스템 확장

- 105,000캔·약 30억 원 리콜 대응과 한국·중국 창고 폐기·감사 증빙
- FEFO·폐기 예상금액 화면
- 내부 ERP 기능 제안·테스트와 채널 API↔ERP↔WMS↔통관 시스템 정책
- 관세청 연동은 진행 중이며 외부 개발사 구현, 본인은 필드·상태·오류·재처리·QA 기준 담당
- 장기 방향: 수요예측 운영 정확도를 먼저 높인 뒤 반복 판단을 AX로 전환
