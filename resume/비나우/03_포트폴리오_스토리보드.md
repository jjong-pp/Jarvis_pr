# 비나우 수요예측·SCM 시스템 기획 포트폴리오 스토리보드

## 방향

기존 22쪽 PM 포트폴리오를 그대로 제출하지 않는다. 실제 수요·발주·재고 운영을 중심에 두고, 시스템 기획은 현장 문제를 해결한 방식으로 배치한다. 첫인상은 `개발 가능한 PM`이 아니라 `이중 공급망을 운영하고 개선한 수요·공급 실무자`여야 한다.

## 구성

### 1. 표지

- 제목: 수요예측·재고·발주 운영
- 부제: 직구·내수 40개 SKU의 월별 계획을 발주·수입·채널 실행으로 연결
- 핵심 범위: 2025년 소비자 매출 약 400억원 사업, 40개 SKU 실무 판단 범위, 24주 재고 전망
- 비공개: 실제 월 발주 검토금액 약 40.7억원과 SKU·공급사별 수량·단가

### 2. 직구·내수 이중 공급망

- 직구: 국내 주문 → 중국 전진창고 → 전자상거래 통관 → 고객 배송
- 내수: 판매 전망 → 발주·선적·수입통관 → 국내 입고 → 풀필먼트·오프라인·B2B·메디컬 배분
- 공통 제약: 6개월 이상 리드타임, 유통기한, MOQ, 수입자·규제, 다거점 재고
- 역할 범위: 수요·발주 검토부터 통관·재고·채널 실행·정산·CS·예외 대응까지

### 3. 월간 S&OP와 발주 판단

- 세일즈 전망, 판매·출고, 현재고, 입고예정의 기준 데이터 통합
- 6개월 이상 리드타임, 3개월 목표재고, 현금흐름, MOQ 검토
- 가격 인상·프로모션을 반영한 품절 시뮬레이션과 판매 제한
- 수입예정 물량을 포함한 채널 사입 허용·창고 이관 계획
- 본인 분석·제안과 최종 승인권자의 결정 분리

### 4. 24주 수요예측·재고 대시보드

- 자동 계산: 최근 최대 12주 출고 평균, 출고·판매 차이 버퍼, 최신 현재고, 도착월 발주계획, 24주 예상 재고
- 실무자 판단: 세일즈 전망, 프로모션 가중치, 3개월 목표재고, 현금흐름, 공급사 MOQ, 최종 발주 수량
- 포인트: 시스템이 결정을 대신하지 않고 같은 기준으로 비교하게 함
- 핵심 화면: `portfolio/assets/05_order_plan_demo.png`
- 강조: 시스템 제안, 실무자 입력, 차이, 가중치, 재고주수 히트맵, 24주 재고 추이
- 화면 라벨: 업무 검증용 재구성 화면·샘플 데이터
- 실제 업무 범위 40개 SKU와 화면의 4개 샘플 SKU를 분리 표기

### 5. 2026년 5~6월 재고 쇼트 위험 재현

- 전년도 판매·출고·재고와 당시 입고계획 12개월치를 재입력
- 운영 계산 로직으로 24주 예상재고 롤포워드 재현
- 2026년 5~6월 재고 부족 위험 4개 SKU 식별
- 발주안·판매 제한·채널 배분 재검토 의제로 전환
- 제한: 재고 소진 시점·계산 로직 재현 검증이며 WMAPE·Bias 개선이나 실제 결품 예방으로 확대하지 않음
- 보조 범위: 생산중단·입고지연, 유통기한·파손, 풀필먼트 사입·이관, 105,000캔 리콜

### 6. 현업 이관과 월별 운영 정착

- 기존: 월별 롤링 방식의 34개 탭과 매월 약 3~4일의 취합·양식 작업
- 2026.04: 40개 SKU·24주 계산 구조 시범 배포
- 약 2개월: 기존 Excel과 값 대조, 화면·산식 개선
- 2026.06: 월간 발주 검토 기준을 대시보드로 이관하고 매월 운영
- 구현 경계: SCM 계산 기준·데이터 구조는 본인이 정의하고 생성형 AI 코딩 도구로 직접 구현, 기존 Excel 실제 수치로 검증

### 7. 비나우 수요예측 업무에 적용할 운영 원칙

- 월별 롤링 S&OP, 장기 리드타임·MOQ·유통기한·입고예정 기반 발주, 공급사·수입·채널 실행 경험 연결
- 입사 후 SKU·채널별 WMAPE·Bias 기준선과 결품·과재고 결과 계측
- 프로모션 기본 수요와 증가분을 분리해 발주 판단 근거 축적
- 화장품 운영 특성과 더존 ERP를 익히고 반복 취합·검증을 단계적으로 자동화
- 반복 계산은 시스템으로 표준화하되 최종 발주안은 세일즈 전망과 공급 제약을 함께 검토
