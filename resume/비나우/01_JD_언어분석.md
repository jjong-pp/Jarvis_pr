# 비나우 수요예측파트 공고 언어 분석

## 한 줄 해석

비나우가 찾는 사람은 예측 모델만 만드는 분석가보다 판매·출고·재고·프로모션 데이터를 같은 기준으로 묶고, 세일즈·구매·SCM이 실행할 발주안을 반복 운영하는 수요계획 실무자에 가깝다.

## 공고에서 반복되는 언어

| 공고 표현 | 채용 의도 | 지원서에서 보여줄 증거 |
|---|---|---|
| 단순 집계·발주량 산정을 넘어 | 숫자를 받아 적는 사람이 아니라 변동 원인을 해석하는 사람 | 전망 수치에 이견을 제기하거나 발주·배분·판매 제한을 조정한 사례 |
| 성장 흐름·수요 변화·빠르게 변동 | 과거 평균만으로 설명되지 않는 신제품·프로모션·채널 변동 대응 | 기본 수요와 행사 영향을 구분하고 가중치를 조정한 기준 |
| 기준 데이터 구축 | 예측 모델보다 먼저 SKU·채널·기간·원천 정의와 정합성 확보 | 판매·출고·현재고·입고계획·품목 마스터 구조와 검증 규칙 |
| 정기적으로 관리·구조화 | 일회성 프로젝트가 아니라 반복 운영 | 월간 S&OP 회차, 마감 일정, 자료 취합과 오류 확인 방식 |
| 실행 가능한 공급 계획 | 분석 결과가 발주·이관·판매 제한으로 이어져야 함 | 발주안, 채널 배분, 풀필먼트 사입·이관, ASN·배차 |
| S&OP 회의체 운영 | 세일즈 전망과 공급 제약을 조율하는 능력 | 6개월 리드타임·3개월 목표재고·현금흐름·MOQ 검토와 후속조치 |
| 결품·과재고 사전 관리 | 서비스 수준과 현금을 함께 보는 판단 | 위험 SKU 선정 기준, 유효기간·폐기 위험, 실제 조치 결과 |
| 정확도·검토·수치 검증 | 숫자의 출처와 오차에 책임지는 태도 | 예측 대비 실제, 데이터 대사, 사용자 수정과 버전 관리 |
| 함께 만들어갈 | 이미 완성된 체계보다 성장기 운영체계를 개선할 사람 | 첫 버전 미사용 후 현업 판단 순서에 맞춰 재설계한 사례 |

## 중요도 순서

1. 판매·출고·재고·프로모션 기준 데이터
2. 월간 S&OP와 유관부서 합의
3. 채널별 수요와 프로모션을 반영한 발주 검토
4. 결품·과재고·현금흐름의 균형
5. 반복 운영을 줄이는 AI·시스템 활용

AI는 핵심 직무가 아니라 운영 체계를 더 빠르고 정확하게 만드는 가점이다. 지원동기에서 AX가 앞서면 수요예측을 시스템 개발의 발판으로만 보는 인상을 줄 수 있다.

## 실제로 사용할 언어

- 기준 데이터 구축
- 판매·출고·재고·프로모션 데이터 구조화
- 채널별 판매 추이
- 월간 S&OP 회의체 운영
- 수요·공급 정합성
- 실행 가능한 공급 계획
- 6개월 이상 리드타임
- 3개월 목표재고
- MOQ·현금흐름 반영
- 프로모션 사전 물동량
- 재고 발주량 검토
- 결품 위험 사전 관리
- 과재고·유효기간 위험 관리
- ERP·WMS·판매채널 데이터 연계
- AI를 활용한 반복 업무 자동화와 수치 검증

## 피해야 할 언어

- 엄청난 인정을 받았다
- 늘 문제를 해결했다
- 모든 재고를 관리했다
- 전문 유통회사의 중심이었다
- 무한 확장 가능하다
- 수요예측 정확도를 크게 높였다
- ERP를 도입했다
- 관세청 API 연동을 완료했다
- AX 체계를 구축했다
- 화장품 SCM과 동일한 경험이다

위 표현은 범위·행동·상태·결과로 바꾼다. 예를 들어 `모든 재고관리`는 `수입 입고부터 3PL·풀필먼트 사입·재고이관·ASN·FEFO까지 재고 운영을 담당`으로 구체화한다.

## 회사 언어와 맞는 인물상

비나우 공식 자료는 고객 관점, 핵심과 목적, 열린 소통, 공동 목표, 주도성, 업무 몰입을 강조한다. 지원서에서는 개인의 기술력보다 문제를 먼저 발견하고 유관부서가 실제로 사용할 때까지 정착시킨 장면을 보여줘야 한다.
