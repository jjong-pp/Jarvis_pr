# 비나우 지원 포털 입력 준비표

> PARTIAL STALE — 2026-09-15. 포털 필수 입력 항목은 참고할 수 있으나, 제출 파일명과 상태는 `README.md`를 따른다. `경력기술서_샘플.md`와 기존 v1.3 포트폴리오는 제출 금지다.

기준일: 2026-09-07

## 제출 판단

- 이력서·경력기술서: 국문 PDF 필수
- 포트폴리오: 선택이지만 제출 권고. 화장품·더존 공백을 실제 S&OP·채널 재고·시스템 개선 증거로 보완할 수 있다.
- 자기소개서: 웹 입력 2문항, 각 1,500자 이내
- 외부 제출·최종 지원은 사용자 승인 전 실행하지 않는다.

## 지원 분야 선택값

| 항목 | 입력값 |
|---|---|
| 지원명 | `[전환형 인턴/경력] 수요예측(S&OP) 지원_전임직` |
| 부문 | 전임직 |
| 직군 | SCM |
| 직무 | Purchase |
| 경력사항 | 경력 |
| 고용형태 | 정규직 경력 지원 기준. 포털 선택지 최종 확인 |
| 근무지 | 비나우 본사 |

## 입력 항목

| 구분 | 항목 | 현재 상태 | 다음 조치 |
|---|---|---|---|
| 기본정보 | 이름·영문이름·사진·성별·생년월일·국적·이메일·연락처 | 일부 이력서 확인, 포털용 영문이름·국적 재확인 필요 | 제출 직전 원본 대조 |
| 주소 | 우편번호·주소·상세주소 | 이력서에는 도로명 일부만 있음 | 포털에 정확한 상세주소 입력 |
| 병역·우대 | 병역·장애·보훈 | 미확인 | 포털 입력값 확인 |
| 고등학교 | 학교명·계열·기간·졸업구분 | 미확인 | 필수 입력용 확인 |
| 대학교 | 학교·학위·기간·입학·졸업·주야간·학점·전공 | 부천대 졸업, 고려사이버대 재학 정보 보유 | 포털 검색 결과와 대조 |
| 경력 | 고용형태·회사·기간·부서·직급·담당업무 | 아이베 SCM팀 사원, 2025-09-08~ | 증빙 가능한 범위로 입력 |
| 어학 | 시험·취득일·등급 | 공인 성적 미보유 | 포털 안내에 따라 임의 입력 후 `없음` 기재 |
| 자격·수상 | 자격증, 수상 | 자격증 미확인, 졸업작품전 우수상 보유 | 증빙 자료 확인 후 입력 |
| 활동·봉사·교육 | 기관·기간·역할·내용 | 현재 제출 우선순위 낮음 | 증빙 가능한 항목만 선택 입력 |
| 공고 경로 | 최초 확인 경로 | 미확인 | 실제 경로 선택 |

## 파일 업로드 권고

1. 필수: `경력기술서_샘플.md` 확정 후 만들 국문 경력기술서 PDF
2. 선택 제출: `박종혁_비나우_구매수요예측_SCM_포트폴리오_최종_v1.3.pdf`

이번 갱신에서는 PDF를 새로 만들지 않았다. 기존 통합 지원서 PDF는 보관하고, 새 공식 지원명과 확정한 경력기술서 문안을 반영한 PDF는 다음 단계에서 제작한다. 기존 범용 PM 포트폴리오는 제출하지 않는다.
