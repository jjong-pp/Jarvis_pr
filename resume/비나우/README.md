## 제출 전 확인

1. 최신 MD 3종의 문안을 사용자 확인한다.
2. 이력서·경력기술서의 `리콜 후 재고 회복 관리` 표현을 확인한다. C-060a~062는 폐기·감사 결과보고와 공급사 보상은 뒷받침하지만 대체 물량·정상 판매 재개 등 재고 회복의 구체 조치는 확정하지 않는다.
3. 이력서 PDF와 경력기술서 PDF를 새로 제작하고 전수 렌더링 검수한다.
4. 포트폴리오 v1.3을 최신 사실에 맞춰 갱신해 제출하거나, 선택 서류이므로 제출하지 않는다.
5. 포털 필수값인 영문 이름·국적·상세주소·병역·고등학교·자격증·최초 공고 확인 경로를 확인한다.
6. 제출 직전 개별 공고 URL·공고 상태·직무명·지원 구분을 재확인한다.
7. 실제 월 발주 검토금액 약 40.7억원과 SKU·공급사별 수량·단가·송장번호는 제출하지 않는다.
8. 대시보드 화면은 `재구성 화면·상품명·수량 익명화·4개 샘플 SKU` 라벨을 유지한다.
9. 사용자 최종 승인 전 외부 제출하지 않는다.

현재 원고를 막지 않는 열린 사실 질문은 `../career_facts.md` 8절을 따른다. 가중치 계수 기준, 판매 촉진·출고 가능 잔여 유통기한 기준, 24주 이후 장기 발주 검토 자료, B2B 정산시간 비교 범위는 답을 얻기 전 수치화하지 않는다.
