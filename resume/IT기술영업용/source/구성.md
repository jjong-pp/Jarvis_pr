# 기술영업 이력서 구성

현재 방향은 사내 도입·현업 업무 이해 경험을 바탕으로 한 업무용 솔루션 기술영업 지원이다. 경력의 공식 소속은 SCM팀으로 유지한다.

| 순서 | 내용 | 쓰는 방식 |
|---|---|---|
| 1 | 이름·지원 직무·연락처 | 연락처는 공통 profile에서 출력 시 입력 |
| 2 | 간략 소개 | 현업 문제를 도입 조건·기술 요건으로 구체화한 경험과 지원 방향, 세 문장 |
| 3 | 경력과 핵심 업무 | 회사·소속·입사일 뒤 요구사항·조율·검수 경험을 구체적 동사로 작성 |
| 4 | B2B 솔루션 도입 | 업무 문제 → 대안 비교 → 도입 범위 → 운영 검수 → 초기 결과 |
| 5 | 관세청 연동 | 업무 흐름 → 시스템 제약 → 관계사 요건 조율 → 검증·운영 범위 |
| 6 | 기술 활용·학력·수상 | 실제 사용한 기술과 용도, 재학·졸업 상태를 정확하게 표기 |

편집 정본은 `이력서.md`다. 자동화 결과인 DOCX·PDF에서 문장만 따로 고치지 않는다. 신규 고객 수·수주액·매출·PoC 같은 미확인 영업 성과는 넣지 않는다. 면접 질문이나 별도 시뮬레이션은 작성하지 않는다.
