# SCM 기본 1안

**2026-09-18 현재:** 이력서의 내용 순서는 [source/구성.md](source/구성.md)에 정리했다. 이번에는 기술영업을 먼저 수정하므로 아래 기존 PDF는 보존한다. 이후 `source/이력서.md`에서 내용을 관리하고 새 출력은 `output/`, 교체 전 출력은 `versions/`에 둔다. 공통 경력 사실은 [공통자료 원장](../공통자료/career_facts.md)을 따른다.

기준일: 2026-09-17. SCM은 [박종혁_SCM_이력서_1안.pdf](output/박종혁_SCM_이력서_1안.pdf) 한 개를 기본 제출 파일로 선택했다. 경력기술이 PDF 안에 포함돼 있어 별도 포트폴리오는 기본 묶음에 넣지 않는다. 실제 공고가 추가 서류를 요구할 때만 해당 요구를 따른다.

이 PDF는 기존 `SCM 이력서.pdf`를 이름·위치만 정리한 3쪽 동일 파일이다. **학점·리콜 수행기간 등 필수 정정 전에는 제출 보류**다. 본문은 아직 수정하지 않았다.

보완 순서: 정본 기준 학점과 주요 수행기간을 맞추고, 의미가 빠진 가동일에 라벨을 붙인다. 발주·공급 운영을 먼저 설명하고, 자료 취합 대시보드는 실제 발주 검토를 돕는 개선 사례로 둔다. 학력·수상만 남은 마지막 쪽은 기존 섹션을 유지하면서 앞쪽으로 당겨 2쪽 구성을 검토한다.

`참고문안_비나우/`의 세 Markdown 파일은 기존 비나우 맞춤 문안이며 범용 SCM 제출본이 아니다. 원래 내용을 보존했고 공용 1안과 분리했다.
