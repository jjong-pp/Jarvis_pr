# SCM 이력서 구성

기본 제출물은 경력기술이 포함된 이력서 한 개다. 현재 PDF는 보존하며 본문 업데이트는 기술영업 다음 단계다.

| 순서 | 담을 내용 | 쓰는 방식 |
|---|---|---|
| 1 | 간략 소개 | 발주·해외 공급사·수입·재고 운영과 공급 판단을 연결 |
| 2 | 경력과 핵심 업무 | 발주안 작성·협의·승인, 생산·선적·통관·입고, 다채널 재고 운영 |
| 3 | 취합 개선 사례 | 반복 자료 취합의 문제, 대시보드 적용, 취합 시간·오류 관찰 범위 |
| 4 | 발주 협의 사례 | 공급 대응 검토, 구매 한도 제약, 경영지원팀 협의, PO 발행 |
| 5 | 보조 사례 | 통관 연동·B2B·리콜에서 SCM 운영에 기여한 역할을 짧게 작성 |
| 6 | 기술·학력·수상 | 실제 사용 도구와 상태를 정확히 표기하고 마지막 쪽의 과도한 공백 정리 |

공급운영 경험을 먼저 설명하고 도구 개발은 업무 개선의 근거로 쓴다. 자료 취합 자동화를 수요예측 성능·자동 발주·재고비용 절감으로 확대하지 않는다. 학점·리콜 주요 수행기간은 공통 원장의 최신 값으로 정정한다.

비나우 참고 문안은 해당 회사의 지원동기와 별도 비공개 제한을 포함하므로 범용본으로 그대로 복사하지 않는다. 면접 자료는 추가하지 않는다.
