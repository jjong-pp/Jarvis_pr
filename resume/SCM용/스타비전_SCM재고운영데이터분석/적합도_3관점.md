# 스타비전 SCM 재고운영·데이터 분석 적합도

## 종합 판정

- 판정: 조건부 지원 권고
- 평가 점수: 20/25점. 합격 확률이 아니라 아래 5개 항목의 증거 적합도 합계다.
- 가장 큰 강점: 판매·출고·재고 데이터 운영, ERP 요건·QA, 반복 집계의 시간·오류 개선
- 가장 큰 변수: 스타비전 고유의 가맹점·PB상품 운영 규칙을 얼마나 빠르게 익힐 수 있는지
- 전면에 둘 증거: 약 40개 SKU 운영, 월 5~6건 B/L 입고와 다채널 출고, 34개 탭 취합 6~12시간→1시간 이내, 취합 1회당 데이터 값 오류 2~3건→약 3개월 0건
- 인정할 공백: 판매상품 월 정산 경험은 있으나 가맹점·PB상품 고유 정산 경험은 없음. 데이터 관련 자격증 없음

| 평가 항목 | 점수 | 판단 |
|---|---:|---|
| 자격요건 | 3/5 | 관련 경력 1년 이상 충족. 전문학사 졸업·학사 졸업 예정이나 공고의 학력 인정 범위는 미확인 |
| 핵심 업무 | 5/5 | 판매량·입출고·재고 데이터 업무와 직접 연결 |
| 우대사항 | 4/5 | ERP와 데이터 정확성, 협업 증거 보유. 자격증은 없음 |
| 도메인 전이 | 4/5 | 소비재·다채널 재고와 판매상품 월 정산 경험 보유. 가맹점·PB 고유 규칙은 학습 필요 |
| 첫 90일 기여 | 4/5 | 정기 집계, 재고·정산 대사, 예외 관리와 리포트 개선 수행 가능 |

## 평가 A — 채용 의도

협력사와 가맹점 사이의 물동, PB상품 재고, 정산·시스템 데이터를 한 기준으로 관리할 실무자를 찾는 공고다. 후보자는 반복 물동과 ERP·대시보드 운영 경험으로 데이터 정합성 안정화에 기여할 수 있다. 다만 수입·3PL 프로젝트보다 판매·입출고·재고 운영 증거가 첫 화면에서 먼저 보여야 한다.

## 평가 B — 요구사항과 증거

| 공고 요구 | 보유 증거 | 강도 |
|---|---|---|
| 판매량 집계·분석 | 판매 전망과 실제 출고량 주·월간 검토 | E3 |
| 제품 입·출고량 관리 | 월 5~6건 B/L 입고, 다채널 출고 운영 | E4 |
| 재고 데이터 분석·관리 | 약 40개 SKU, 로트·유통기한·가용재고·DOS 관리 | E3 |
| ERP 사용 | 업무 요건 정리와 자동·수동 테스트 약 100건, 추적 중 | E3 |
| 정확한 데이터 관리 | 취합 1회당 데이터 값 오류 2~3건→약 3개월 0건 | E3 |
| 판매상품 정산 | 인구보건복지협회 특수분유·산후조리원 판매상품 월 정산 | E3 |
| 가맹점·PB 고유 규칙 | 직접 증거 없음 | E0 |

## 평가 C — 탈락 위험과 과장 방지

1. 공고가 `대졸 이상`을 4년제 학사 취득자로만 해석하면 현재 졸업 예정 상태가 변수가 될 수 있다.
2. 판매상품 월 정산 경험은 있으나 가맹점·PB상품 고유 규칙의 즉시 독립 운영은 검증이 필요하다.
3. `취합 오류 0건`을 재고 오류 0건이나 정확도 100%로 확대하지 않는다.
4. ERP는 요건 정의와 QA 경험이며 전체 구축 완료로 표현하지 않는다.

## 이력서 전략

판매·출고·재고 분석 → 데이터 정확성 개선 → ERP 요건·QA 순서로 제시한다. 긴급 항공과 계약 조건 협의는 이 공고의 핵심이 아니므로 보조 근거로만 사용한다.
