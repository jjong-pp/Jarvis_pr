# 스타비전 SCM 재고운영·데이터 분석 — 공고 분석

## 종합 판정

**조건부 지원 권고.** 관련 경력 1년 요건을 충족하고, 판매·출고·재고 데이터 운영과 판매상품 월 정산, ERP·자료 취합 개선 경험이 업무와 직접 맞는다. 다만 공고의 `대졸 이상`이 4년제 학사 취득자를 뜻하는지, 졸업예정자를 인정하는지는 확인이 필요하다. 가맹점·PB 상품 자체의 경험과 데이터 자격증은 없지만 필수가 아니다.

## 이 공고가 실제로 찾는 사람

1. 협력사·가맹점·PB 상품의 판매·입고·출고·재고 숫자를 맞추는 운영자
2. ERP와 업무 자료의 수치 차이를 찾고 재고 예외를 관리할 수 있는 사람
3. 협력사와 내부 운영자 사이에서 문제를 확인하고 해결까지 추적할 사람

## 요구–증거 대응

| 공고 요구 | 후보자 근거 | 강도 |
|---|---|---|
| 판매량 집계·분석 | 세일즈 전망과 SCM 출고량 차이를 주·월간 분석(C-105), 판매·출고를 분리해 발주 검토(C-093) | E3 |
| 제품 입·출고량 관리 | 월 약 20개 SKU·4~6만 캔 발주, 월 5~6 B/L 입항, 다채널 출고·재고 운영(N-060·61, C-098) | E3 |
| 재고운영 데이터 분석 | Stock·Supply·Sales·DOS, 3개월 목표재고, FEFO·유통기한·폐기 위험 관리(N-062, C-071·106) | E3 |
| ERP 시스템 | SKU ID·주문·상품 매핑·WMS·통관 API 요건 정의, 테스트 약 100건 및 추적(N-030b) | E2~E3 |
| 판매상품 월 정산 | 인구보건복지협회 특수분유 판매분과 산후조리원 판매상품의 월 정산 직접 수행(N-072) | E3 |
| 정확한 데이터 | 발주 자료 취합 6~12시간 → 1시간 이내, 취합 1회당 데이터 값 오류 2~3건 → 약 3개월 0건(C-080·104) | E3 |
| 커뮤니케이션·문제 해결 | 3PL 비교·계약·이관·CS 조율, 대시보드 사용자 4~5명에게 양식·확인 방법 안내(N-020~027·064) | E3 |
| 데이터 자격증 | 없음 | E0 |

## 서류 전략

- 첫 거론: 재고·입출고 운영 규모와 데이터 정확도
- 대표 사례: 발주 자료 자동취합 대시보드
- 보조 사례: 판매상품 월 정산, ERP 요건·QA, 다채널·3PL 재고 운영
- 축소: 리콜·긴급 항공·3PL 계약 상세는 이 공고의 첫 근거로 쓰지 않음
- 금지: 판매상품 정산을 PB상품·가맹점 고유 정산 경험으로 확장하거나 데이터 자격증을 있는 것처럼 쓰지 않음

## 예상 탈락 사유

1. 가맹점·PB 상품 고유 운영 도메인 부재
2. 데이터 관련 자격증 부재
3. 재고 회전·결품·폐기율 개선치 부재

이 세 가지는 필수 게이트가 아니며, 실제 재고 운영·ERP·데이터 정확도 개선 경험이 더 강하다.
