- `수요 예측` 스킬이 3종 전체에 근거 0
- 미풀이 약어: **TRA**(2장에서 쓰고 끝까지 미해설), SOW, AE
- 이력서에 포트폴리오 링크 없음

### 이 에이전트가 스스로 철회한 것

무결점 성공 서사(실패 회고 3건 실재) / 사용자 접점이 태도 진술뿐(배포 후 요청→요구사항 루프 3건 실재, 2점→3점 상향) / BIGSEE가 학습용 사이드라 감점(트리거는 "4개 역량 전부가 사이드 1건에만 걸린 경우"인데 실무 2건이 주축) / 페르소나 창작(스스로 `가설 페르소나 — 인터뷰 전 단계`, `확정 대상 아님`으로 지위 낮춤) / 정성 성과를 정량으로 위장(관세청 성과란은 정성 그대로 두고 억지 수치 안 만듦) / 도구 나열(고도몰5는 3개 대안 비교로 등장)

## 이미 발견된 에이전트 간 충돌

1. **`420분`** — 에이전트 1은 `산술 오류`(2명×7시간=840분)로 단정. 그러나 **벽시계 시간으로 읽으면 7시간=420분이 맞다.** 오류가 아니라 단위 미표기일 가능성. 판정 필요.
2. **`협력사명은`** — 에이전트 2는 `명백한 오류`로 분류. 그러나 주제격 조사는 한국어에서 서술어와 직접 호응하지 않아도 성립하는 경우가 있다. `명백한 오류`인지 `개선 권고`인지 판정 필요.
3. **`09:00`** — 에이전트 1은 원장 금지 표현이라 주장. 그러나 원장이 금지한 것은 `동수 ERP 09:00 수집` 프레이밍이고, **`고객 주문 마감 09:00`은 정본**일 가능성. 실제 문제는 B 7장의 `10:00 운송장 배정·제출`이 확정 처리창(`11:10~11:50`)과 다른 것일 수 있다. 판정 필요.
4. **C축 15/20(양호) vs 전체 인상** — 에이전트 3은 AI스러움을 비교적 양호하게 봤고, 에이전트 4는 문서 전반을 약하게 봤다. 서로 다른 축이라 모순은 아니나, **최종 통합에서 어느 쪽을 앞에 둘지** 판단 필요.
