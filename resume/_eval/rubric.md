### 미확인 (추정하지 않음)

- **미확인 A**: 원티드 AI 이력서 리뷰 / 사람인 AI 자소서 코칭이 **내부적으로 어떤 피처를 쓰는지**. 공개된 것은 "포지션 맞춤 분석, 8개 내외 항목, 합격 이력서 패턴 학습"이라는 마케팅 수준 서술뿐. 직무 분류 확률·키워드 빈도 비교 여부는 확인 불가. (원티드 기술 블로그 원문은 403으로 접근 실패)
- **미확인 B**: 국내 채용 플랫폼이 **탈락 판정을 자동화하는지**. 확인된 것은 "검토 보조"(프리즘 8초 요약) 수준이고, 자동 탈락 로직의 존재 여부는 미확인.
- **미확인 C**: 한국 기업 중 **몇 %가 실제로 AI 탐지기를 서류전형에 돌리는지**. C1은 "73.0%가 판별하지 않는다"(2023년 조사)이고, 2026년 시점 갱신치는 미확인.
- **미확인 D**: 국내 PM 직군 한정 서류 탈락 사유 통계. PM 특화 국내 조사는 발견하지 못했고, 본 루브릭의 PM 역량 축은 **해외 프레임워크(C11) + 국내 실무자 글**로 보완했음을 명시한다.
- **미확인 E**: 쉼표 방향성 충돌. KatFishNet(C7)은 "AI가 쉼표를 **적게** 쓴다", Pebblous 리포트는 "AI가 접속부사 뒤 쉼표를 **4.8배 많이** 쓴다"고 한다. 측정 대상이 다르므로(총량 vs 특정 위치) 양립 가능하나, **총량 쉼표는 신호로 쓰지 않고 위치 쉼표만 쓴다.**

### 이 조사가 루브릭에 강제한 설계 결정

1. **"AI가 썼다"를 판정하지 않는다.** C5·C6이 오탐률을 보증하지 못한다. 측정 대상은 **"AI가 쓴 것처럼 읽히는가"** — 즉 구체성·고유명사·개인 역할의 부재라는 **결과물의 결함**이다. 이 결함은 사람이 써도 감점 대상이므로 오탐 피해가 구조적으로 작다.
2. **정직성 축을 독립시킨다.** C2·C3에서 서류 탈락의 실질 1순위가 "과대포장"이었다.
3. **문서 품질 축의 배점을 낮게 두되 BLOCK 트리거를 둔다.** C4에서 실무 감점폭은 평균 26.6점으로 크지만, 이는 "실수가 있을 때"의 조건부 수치다. 반복·치명 오류만 큰 감점으로 처리한다.
4. **전략·비전 역량 부재를 감점하지 않는다.** C11·C12.

### A. PM 역량 증거 — 25점

**무엇을 보는가**
Ravi Mehta 프레임워크(C11)를 주니어용으로 잘라, 아래 4개만 본다.

| 하위 역량 | 서류에서 찾을 관찰물 |
|---|---|
| A1. 문제 정의 | "무엇이 문제였는가"가 증상이 아니라 원인 수준으로 서술됐는가. 문제를 **누가 어떻게 발견했는지**가 있는가 |
| A2. 고객/사용자 접점 (Customer Insight) | 인터뷰·설문·CS 로그·세션 기록 등 **1차 데이터를 직접 만진 흔적**. n수·질문 문항·인용된 사용자 발화 |
| A3. 실행 (Product Execution) | 요구사항 문서화, 스펙 결정, 개발/디자인과의 조율, 릴리즈까지 **끝을 본 사이클**이 1건 이상 |
| A4. 우선순위 판단 | **버린 것**이 서술돼 있는가. "A 대신 B를 먼저 한 이유"가 있는가 |

**감점 트리거**
- 문제 정의 없이 "기능 개발을 담당했다"만 있음
- 사용자 언급이 "사용자 중심으로 생각했다" 수준의 태도 진술뿐 (1차 데이터 없음)
- 4개 하위 역량 전부가 같은 프로젝트 1건에만 걸려 있고 그 1건이 학습용 사이드 프로젝트
- 협업이 "원활한 소통", "적극적 커뮤니케이션" 같은 형용사로만 존재
- 도구 나열(Figma, Jira, Amplitude, GA4)만 있고 **그 도구로 내린 결정**이 없음

**가점 트리거**
- **의사결정 1건이 근거·대안·트레이드오프까지 서술**됨 (주니어 서류에서 가장 희소한 신호)
- 실패/중단한 프로젝트와 그 원인 회고
- 요구사항 변경에 대응한 기록 (스펙 드리프트를 어떻게 처리했는지)
- 자기 역할과 팀 역할의 경계가 문장 단위로 구분됨
- 도메인 지식(물류·커머스·핀테크 등)이 **용어가 아니라 제약조건으로** 등장

**주니어 보정 — 아래를 감점하지 않는다**
- 제품 비전·로드맵 수립 경험 없음
- P&L·수익화 책임 없음
- 조직 설계, 채용, 타 PM 관리 경험 없음
- 지표 개선폭이 작음 (크기보다 **측정 설계의 존재**를 본다)

### B. 성과의 검증가능성 — 20점

**무엇을 보는가**
숫자의 크기가 아니라 **숫자가 살아남을 수 있는가**. 판정 3문항(해외 실무 기준, C2와 정합):
1. 실재하는가 (Is it real)
2. 범위가 특정되는가 (모수·기간·비교대상)
3. 면접에서 2분간 설명 가능해 보이는가

**감점 트리거**
- 모수 없는 % ("전환율 30% 개선" — 무엇 대비, 몇 명 중, 며칠간이 없음)
- 비교 기준 없는 절대값 ("MAU 1만 달성" — 시작점 없음)
- **모든 불릿이 동일한 형태의 수치로 끝남** (템플릿 채우기 신호)
- 지나치게 깔끔한 반올림 수치의 반복 (30%, 50%, 2배)
- 팀 성과를 1인칭 단수로 귀속 ("매출을 50% 올렸습니다")
- 개인이 통제할 수 없는 지표를 개인 성과로 제시 (전사 매출, 투자유치)
- 수치의 출처 도구가 없음 (어디서 측정했는가)

**가점 트리거**
- 모수·기간·비교군이 붙은 수치 ("가입 1주차 이탈 42%→33%, 2025.3~5, 신규 가입자 n=1,840")
- **개선되지 않은 지표를 같이 적음** (정직성의 강한 신호)
- 자기 기여분을 축소 서술 ("3인 스쿼드에서 스펙 정의와 QA를 담당")
- 정성 성과를 정량으로 위장하지 않고 정성 그대로 서술
- 지표를 **직접 정의한** 흔적 (그 지표를 왜 골랐는지)

### C. 사람의 흔적 — 20점

**측정 대상은 "AI가 썼는가"가 아니다.** 측정 대상은 **"이 문서에 이 사람만 쓸 수 있는 정보가 얼마나 남아 있는가"**이다.
채점자는 어떤 경우에도 "AI로 작성됨"이라고 판정문을 쓰지 않는다. "AI 초안 문체가 강하게 남아 있음"까지만 쓴다. (근거: C5·C6)

**핵심 지표 — 고유성 밀도**
문서 전체에서 아래를 센다.
- 고유명사 (제품명, 팀명, 도구명, 회사 내부 용어)
- 날짜·기간 (월 단위 이상 구체)
- 인용 (동료·사용자의 실제 발화)
- 숫자 (모수 포함)
- 예상 밖 디테일 (실패, 갈등, 사소하지만 진짜인 사건)

**감점 트리거**
- 4장 체크리스트 히트 개수 (아래 §4)
- 회사명/직무명만 바꾸면 다른 곳에도 그대로 낼 수 있는 문단이 있음
- 무결점 성공 서사 — 문제→소통→해결→성장이 반복
- 문단 간 톤·어휘 수준 불균형 (일부 문단만 고급 어휘 집중 = 이어붙인 흔적)

**가점 트리거**
- 다듬어지지 않았지만 구체적인 문장 (문장은 거칠어도 정보가 있음)
- 자기 판단이 틀렸던 대목의 서술
- 특정 인물·상황에 대한 짧은 인용
- 마무리가 다짐이 아니라 사실로 끝남

### D. 구조·가독성·ATS 적합성 — 15점

**무엇을 보는가**
7.4초(C10) 안에 걸러지는 요소 + 기계 파싱 실패 요소(C9).

**감점 트리거 (ATS)**
- 2단/다단 레이아웃 — 좌우가 뒤섞여 파싱됨
- 표(table)로 만든 경력 레이아웃
- 이름·연락처가 머리글/바닥글에 있음
- 비표준 섹션명 ("나의 여정", "My Career Story") — 표준: 경력, 학력, 스킬, 프로젝트
- 스킬을 그래프·원형 게이지 이미지로 표현 (파서는 OCR을 하지 않음)
- 이미지로 저장된 PDF (스캔본, Canva 이미지 출력)
- 날짜 형식 혼용 (2024.03 / 2024년 3월 / Mar 2024 혼재)
- 장식 불릿·화살표 특수문자 (✔ ► ★ →)
- 미풀이 약어 (풀네임 병기 없음)

**감점 트리거 (7.4초)**
- 첫 화면에 직무·핵심 경험이 없음 (자기소개 문단이 먼저 나옴)
- 시간 역순 정렬 아님
- 경력 공백이 설명 없이 존재
- 1페이지에 담길 분량인데 3페이지 이상으로 늘어져 있음

**가점 트리거**
- 상단 3~5줄 요약이 **직무명 + 핵심 성과 1개 + 도메인**으로 구성
- 프로젝트마다 [기간 / 역할 / 팀 규모 / 결과] 라벨이 일관
- 텍스트 추출 시 순서가 보존되는 단일 컬럼 구조
- 포트폴리오 링크가 살아 있고 접근 권한이 열려 있음

### E. 문서 간 일관성·정직성 — 10점

**무엇을 보는가**
이력서 / 경력기술서 / 자소서 / 포트폴리오 **4개 문서를 교차 대조**한다. C3에 따르면 허위는 자소서 쪽에 2배 몰린다 — 자소서를 기준으로 삼지 말고 **이력서를 기준선**으로 두고 자소서를 검증한다.

**대조 항목**
- 재직 기간 (월 단위까지)
- 직함·소속 팀
- 프로젝트 기간과 순서
- 팀 규모
- 동일 성과의 수치가 문서마다 다른가
- 역할 서술의 강도 (이력서 "참여" vs 자소서 "주도")

**감점 트리거**
- 같은 프로젝트 수치가 문서 간 불일치
- 이력서엔 없는 경력이 자소서에만 등장
- 역할 강도가 문서 간 상향 (참여 → 리드 → 총괄)
- 기간이 겹치는데 설명 없음
- 지원 회사명 오기재 / 타 기업 지원 흔적 (C8에서 각각 13%, 11%로 실측되는 흔한 결함)
- 글자수 미달 (C8: 26%)

**가점 트리거**
- 문서 간 수치·기간이 완전 일치
- 자소서가 이력서보다 **덜 과장**됨
- 한계·범위를 스스로 명시 ("이 지표는 마케팅 캠페인과 동시 진행되어 단독 기여로 보기 어렵습니다")

### F. 한국어 문서 품질 — 10점

**무엇을 보는가**
오류의 **총량이 아니라 유형과 반복성**. (C4: 감점자는 평균 26.6점을 깎지만, 이는 조건부 수치이므로 배점은 낮게 두고 §3 BLOCK으로 상한을 관리)

**감점 트리거 (유형별 가중치 순)**
1. **지원 회사명·직무명 오기** — 최상위 (§3 BLOCK 후보)
2. 비문 — 주술 불일치, 문장 미완결
3. 조사 오용 — 이/가·은/는·을/를·에/에게·로서/로써
4. 띄어쓰기 — "할 수 있다"(의존명사 수), "가능한 한", "~한 적", "~할 때", "V-아/어 보다"
5. 맞춤법 상습 오류 — 되/돼, 안/않, 로서/로써, 왠/웬, 몇 일→며칠, 어떻게/어떡해, 율/률, 든지/던지
6. 번역투 — "~에 대한 ~의", "~을/를 통해", "~에 있어서", "~되어지다", "가지다"(have 직역), "~함에 있어"
7. 문장 부호 — 접속부사 뒤 불필요한 쉼표, 온점 누락, 따옴표 혼용
8. 존댓말/평어체 혼용 — 이력서는 개조체, 자소서는 경어체로 통일돼 있는가
9. 외래어 표기 — 컨텐츠→콘텐츠, 매니져→매니저, 런칭→론칭, 어플리케이션→애플리케이션

**가점 트리거**
- 개조체 어미가 문서 전체에서 통일 (`~함` / `~했음` / 명사종결 중 하나로)
- 문장 평균 길이가 60자 내외이고 **길이 편차가 자연스러움**
- 전문 용어를 처음 등장 시 풀어씀

**참고 실측치**: 자소서 1건당 오탈자·띄어쓰기 등 오류가 평균 32개 발견됐다는 조사가 있다. 즉 **오류 0건은 기대값이 아니다.** 소수의 단순 오탈자는 감점 폭을 작게 잡는다.

## 3. 즉시 탈락(BLOCK) 사유 목록

아래는 **총점과 무관하게 탈락**으로 처리한다. 채점자는 BLOCK 판정 시 근거 문장을 원문 그대로 인용해야 한다.

| ID | 사유 | 판정 근거 |
|---|---|---|
| BL-1 | **지원 회사명 또는 지원 직무명 오기재** (다른 회사명이 남아 있음) | C8에서 회사명 오기재 13% 실측. 재사용 흔적은 즉시 판별되며 회복 불가 |
| BL-2 | **타 기업 지원용 문장이 그대로 남음** ("귀사 OO은행의…") | C8에서 11% |
| BL-3 | **경력 기간·직함이 문서 간 모순**되고 설명이 없음 | C3: 허위 1순위가 경력사항·기간 52.6% |
| BL-4 | **검증 가능한 사실의 허위** (재직하지 않은 회사, 수행하지 않은 프로젝트, 미취득 자격증) | C2: 인사담당자 92.5%가 거짓말이 평가에 악영향이라 응답 |
| BL-5 | **팀·회사 성과의 명백한 개인 귀속**이 반복되고 팀 규모가 어디에도 없음 | C2: 과대포장 49.7%가 서류 의심 1순위 |
| BL-6 | **문서가 기계 판독 불가** (이미지 PDF, 열리지 않는 링크, 권한 잠긴 포트폴리오) | C9·C10 |
| BL-7 | **분량 요건 미달** (지정 글자수 미충족, 필수 항목 공란) | C8: 글자수 미달 26% |
| BL-8 | **마크다운/프롬프트 잔재가 문서에 남음** (`**`, `###`, "물론입니다", "다음은 …입니다", "[회사명]", "[여기에 경험 삽입]") | 검토 자체를 무의미하게 만드는 미완성 제출 |
| BL-9 | **블라인드 채용 공고에서 금지 정보 기재** (사진, 학교명, 가족 직업 등 공고가 금지한 항목) | C8: 블라인드 위반 37% |
| BL-10 | 표절 — 타인의 자소서·블로그 문장을 출처 없이 다량 전재 | C8: 표절률 30% 이상이 47% |

**BLOCK이 아닌 것 (오판 방지용 명시)**
- AI 탐지기 점수가 높게 나옴 → **BLOCK 아님.** C5·C6에 따라 탐지기 단독 판정은 금지한다.
- 문장이 매끄럽다 → BLOCK 아님. 매끄러움 자체는 결함이 아니다.
- 오탈자가 있다 → BLOCK 아님. 평균 32개가 실측 기준선이다.
- 경력이 짧다 / 사이드 프로젝트뿐이다 → BLOCK 아님. 주니어 트랙에서는 A축 점수로 반영한다.

## 4. AI스러움 탐지 체크리스트 (한국어 신호 21개)

**사용법**: 각 항목을 히트/논히트로 세고, 히트 개수를 §2의 C축 판정에 넣는다. **개별 항목 1~2개 히트는 아무 의미도 없다.** 사람도 이렇게 쓴다. 임계는 6개 이상부터다.
**금지**: 이 체크리스트 결과를 "AI 작성 확률"로 환산하지 않는다.

**교정 규칙 (오탐 억제)**
- 지원자가 **비원어민이거나 한국어 문어 훈련이 적을 가능성**이 있으면 1·3·7·8·21번을 감점 근거에서 제외한다. C5에서 저퍼플렉시티 문체가 AI로 오분류되는 편향이 실증됐다.
- **AI로 다듬었으나 내용은 본인 경험**인 경우가 실제로 다수다(C1: 취준생 60%가 사용 경험). 이 경우 §4 히트는 높아도 A·B축은 높게 나온다. **A축과 B축이 4 이상이면 C축 감점을 최대 배점의 50%까지로 제한한다.**

## 5. 이 루브릭의 한계 — 근거가 약한 항목

| 항목 | 신뢰도 | 사유 |
|---|---|---|
| §4의 1~6번 수치 | **中** | 단일 벤더(Pebblous, AI 휴머나이저 사업자) 리포트. 이해상충 가능. 재현 연구 미확인. **수치를 인용하되 절대 임계로 쓰지 말 것** |
| §4의 7~8번 | 中상 | 학술 논문(KatFishNet, arXiv:2503.00032)이나 도메인이 자소서가 아님. 자소서 장르 일반화 미검증 |
| §4의 9~21번 | **低~中** | 실무자 관찰·언론 기사 기반. 정량 근거 없음. 개별 항목은 판정 근거로 쓸 수 없고 **누적 개수로만** 사용 |
| A축 하위 역량 구분 | 中 | 해외 프레임워크(Ravi Mehta) 기반. **국내 PM 서류 심사 실증 데이터는 미확인(미확인 D)** |
| A축 "주니어 보정" 경계선 | **低** | "전략·비전은 시니어 영역"은 해외 프레임워크 해석이며, 국내 기업의 실제 기대치와 다를 수 있음. C12는 국내 "주니어" 공고가 2년 경력을 요구함을 보여준다 — **채용사 공고를 우선한다** |
| D축 ATS 기준 | 中 | 해외 ATS(Workday/Greenhouse/Lever) 기준. **국내 원티드·사람인·잡코리아의 파싱 동작은 미확인(미확인 A)**. 국내 지원이 웹 폼 직접 입력이면 D축의 ATS 항목 배점을 축소하고 가독성 항목으로 대체할 것 |
| F축 오류 개수 구간 | **低** | "8~15건 = 3점" 같은 구간은 실증 기준이 아니라 본 루브릭의 임의 설정. 평균 32개라는 실측치만이 근거 |
| C10(7.4초) | 中 | 2018년 미국 조사. 2026년 한국 적용 여부 미검증. **"첫 화면 우선"의 방향성 근거로만 사용** |
| BLOCK 임계 | 中 | BL-1·2·7·9·10은 실측 결함률 기반이나, "즉시 탈락"이라는 처분 강도는 C3(무조건 탈락 26.9%)·C4(19.8%)의 소수 응답에 기댄 설계 판단 |

**적용 시 반드시 지킬 것**
1. 총점만 보고하지 말고 **축별 점수와 근거 인용문**을 함께 낸다.
2. C축 감점 사유는 문서에서 **실제 문장을 인용**해야 성립한다. 인용 없는 "AI스럽다"는 무효.
3. 동일 서류를 2회 이상 채점할 때 C축 점수가 2점 이상 흔들리면 **C축 판정을 포기하고 A·B축으로만 평가**한다.
