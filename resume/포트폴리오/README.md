# PM 포트폴리오

이 폴더가 포트폴리오 파일의 단일 진입점이다. 현재 PPTX 제출본은 `output/박종혁_PM_포트폴리오_v4.3_제출본.pptx`(22장)이며, 관세청 통관 연동과 산후조리원 전용 B2B 몰 두 프로젝트만 담는다. 디자인 기준은 `../박종혁_PM_포트폴리오_정렬수정.pptx`다. 원본 사진·Noto Sans KR·파랑/초록 프로젝트 구분·표지/본문 프레임을 바탕으로 편집 가능한 텍스트·표·도형을 재구성했다.

`[2026-09-17 정정]` 종전 현재본 v4.2 → v4.3 제출본. v4~v4.2 및 기존 PDF는 STALE 참고본으로 보존하며 함께 제출하지 않는다. 종전 1HBL=1거래정보, 결제수단만 비교하는 혼합주문 설명은 현재 정책으로 재사용하지 않는다. 정정 근거는 `../career_facts.md` C-029·C-034·C-127~132다.

## 제출 안전 규칙

- B2B 원본 캡처는 포인트, 주문번호, 가격, 고객 식별값을 포함하므로 제출본에 원본 파일을 삽입하지 않는다. `submission_safe/`의 평탄화 이미지에 상태 건수까지 제거한 뒤 사용한다.
- 관세청 v4.3은 내부 문서 원본을 캡처로 싣지 않는다. 정책·흐름을 일반화한 편집 가능 도표로 재구성하고, 가상 주문 예시는 시뮬레이션으로 표시한다.
- v4.2에서 사용했던 `current_identifier_contract.png`·`current_state_retry.png`와 종전 `field_mapping_*`는 이력 보존용이며 새 제출본에서 제외했다.
- v4.3 B2B 증빙은 실제 운영 화면(16장)과 개발사 처리결과 문서의 기능 화면(15·17·19·20장)을 구분한다. 후자는 직접 운영 캡처가 아님을 표시하고, 회원수·상품수·고객정보·주문·가격 영역을 제거했다.
- BIGSEE 자료와 v1~v3은 수정 이력 보존용이며 v4와 함께 제출하지 않는다.
- 이력·기간·수치·역할의 정본은 `../career_facts.md`다.

## 재생성

`source/v4/extract_b2b_v4_3.mjs`로 개발사 문서의 증거 영역을 잘라 내부 수치를 제거한 뒤 `source/v4/build_v4_3.mjs`로 PPTX를 생성한다. 기존 운영 안내·주문 상태의 안전 캡처도 재사용한다. 최종 22장 렌더와 검수 자료는 `qa/v4_3/제출본/`, 패키지·글꼴·표·레이아웃 검증 영수증은 `.build/v4_3/validation-제출본.json`이다. 자동 검증은 구조와 배치 검사이며 PowerPoint 앱에서 직접 확인했다는 의미는 아니다.
