## 2. 간단 소개

현업의 막연한 불편을 실제로 쓰이는 시스템으로 만들어 온 기획자 겸 빌더입니다. 수기 엑셀 발주를 커버일수 기반 대시보드로, 구글 폼 수기 주문을 결제-출고 자동화 시스템으로 바꾸며 설계부터 배포, 그리고 현업이 실제로 쓸 때까지의 안착까지 전 과정을 직접 맡아왔습니다. Python/FastAPI/SQL을 기본으로, Claude Code 등 AI 코드 어시스턴트를 페어코딩 도구로 활용해 개발 속도를 높이고 있습니다. 처음 만든 대시보드가 두 달간 현업에서 쓰이지 않았던 경험을 통해, 좋은 시스템은 로직의 완성도가 아니라 사용자의 업무 화면에 얼마나 가까운가로 결정된다는 것을 체감했습니다. 아직 체계가 자리잡지 않은 신생 조직에서 현업과 함께 문제를 정의하고 도구를 골라 끝까지 안착시키는 역할에 제 경험이 맞닿아 있다고 생각해 지원합니다.
