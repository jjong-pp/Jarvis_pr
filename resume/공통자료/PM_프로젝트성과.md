# PM 프로젝트 성과 — B2B 주문몰 · 관세청 통관 연동 · 마켓빅시

PM 역할로 수행한 프로젝트 세 건의 사실·산출물·결과를 모은 정본이다. SCM 실무(발주, 3PL, 대시보드, 리콜, ERP)와 기본 정보는 [SCM_업무성과.md](SCM_업무성과.md)에 있다.

- 이관: 2026-09-23. 종전 `career_facts.md`(2026-09-17 갱신) 3~5절과 11~12절에서 옮겼다. 원본은 휴지통에 있다
- ID는 종전 C-xxx를 그대로 쓴다. 상태는 `확정` / `미확인` / `충돌`이며, 미확인·충돌은 제출문에 쓰지 않는다
- 공통 금지 주장은 [../공고처리_공정.md](../공고처리_공정.md) 8절에 있다
- 역할 표기 [2026-09-26 사용자 확정]: 두 프로젝트에서 **기획부터 조율·QA·운영 전환까지 PM 업무 전체를 수행했다.** 공식 소속 직함은 SCM팀 사원(C-010)이므로 `아이베 SCM팀 사원 / 프로젝트 PM(기획·요건 정의·관계사 조율·QA·운영 전환)`처럼 소속과 역할을 함께 쓴다. 역할을 축소해 `참여`, `보조`로 쓰지 않는다
