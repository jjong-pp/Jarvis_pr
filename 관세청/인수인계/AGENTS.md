# 관세청 인수인계 작업 규칙

이 폴더의 목적은 지윤환(후임 PM·운영)의 인수인계 요청에 회신하는 것이다. 박종혁(현 PM)이 퇴사 전 답한다. 요청 메일은 2통(원 요청 10개 항목 + 추가 요청 2개)이고 전달 기한은 **2026-10-09(금)**이다(추가 요청 메일).
새 대화·다른 PC에서도 이 폴더만 열면 이어서 작업할 수 있게 한다. 이미 확인한 사실을 다시 조사하지 않는다.

## 폴더 구조

```
관세청/
├─ 전달용/                          ← 지윤환에게 보내는 것만
│  ├─ 관세청_통관연동_인수인계.md   인수인계 문서 (요청 항목별 답변, 흐름도 텍스트 포함)
│  ├─ 관세청_통관연동_전체기획서.md 전체 기획서 (예전 기획서·대장·협의 내용을 최신 기준으로 합침)
│  └─ 회신메일_지윤환.txt           회신 메일 본문
├─ documents/                       원본 자료 (키 파일 빼고 같이 보냄)
└─ 인수인계/                        ← 내부 작업용 (보내지 않음)
   ├─ 01_작성자_확인목록.md          박종혁에게 물을 질문 대장 + 요청 메일 원문 2통
   ├─ 최종_전달물_체크리스트.md       보낼 것·같이 할 일·정리할 것 체크리스트
   ├─ AGENTS.md / CLAUDE.md         이 작업 규칙
```

계정·비밀번호·API Key는 박종혁이 별도 계정 정리 txt로 전달한다. 이 폴더들에 값을 쓰지 않는다.
[2026-10-08 정정] 종전 "새 파일 금지, 내부 파일은 확인목록 하나" → 신규: 위 구조의 파일만 둔다. 체크리스트는 사용자 지시로 추가했고, 전체 기획서는 사용자 지시로 전달물에 추가했다(10-08). 그 밖의 새 파일은 만들지 않는다.

## 작성 원칙

- 새 매뉴얼을 만들지 않는다. 기존 자료는 문서명과 위치만 적는다.
- 추측하지 않는다. 표기: 없음 / 미정 / ○○ 확인 필요. 박종혁이 "필요 없다"고 한 항목은 문서에서 정리한다.
- 문서 기록은 2026-09-17 11:40까지, 이후는 박종혁 답변으로만 채운다. 근거는 확인목록과 git에 두고 전달 문서에 출처 표기를 늘어놓지 않는다.
- 전달 문서는 사람이 간단히 쓴 문체로 쓴다. ID(I-xx·Q-xx 등), 표의 # 열, "몇 절" 같은 참조, 수신·작성·작성일 메타 표, "원 요청" 같은 표현, 부록 나열을 넣지 않는다 (사용자 교정 2026-10-08).
- 90건·32건 사건, 테스트 이력 목록, 남은 이슈의 긴 목록은 넣지 않는다. 테스트는 박종혁이 같이 보여주므로 흐름만 적는다 (사용자 지시 2026-10-08).
- [2026-10-08 정정] 종전 "Mermaid 코드" → "PNG 이미지" → "텍스트(ASCII) 흐름도" → 신규: **흐름도는 md 안에 ```mermaid 코드블록으로 넣는다.** 사용자 요구는 "md 파일 하나에 mermaid 코드를 넣고 미리보기에서 실제 그래프로 보이게"(10-08 스크린샷으로 텍스트 흐름도를 거절). PNG는 상대경로라 md 하나만 열면 안 보였다. 이 PC의 VS Code에는 Markdown Preview Enhanced(Mermaid 지원)가 설치돼 있다. 기본 미리보기는 Mermaid 확장이 있어야 그려진다. 고친 뒤에는 mermaid@10으로 렌더링해 오류가 없는지 확인한다. PNG 폴더와 `흐름도_원본.md`는 삭제했다(git `b8af348`에 있음).
- 전체 기획서는 사람 문체를 따르되 장 번호와 표는 쓴다. ID·부록·"몇 절" 참조·출처 나열은 넣지 않는다. 90건·32건, 테스트 이력, 미발송 메일 초안은 넣지 않는다.

## 확정된 사실 (2026-10-06 박종혁)

- 자사몰 신규 방식 가동은 대기. 동수·자이언트 테스트 미완료.
- 자사몰은 08-31부터 결제 단계 통관부호 간편인증에서 오류를 내 고객이 P부호를 직접 입력하는 구조. 전 주문 적용.
- 계정 메일 인계 대상은 유니패스 하나(`https://unipass.customs.go.kr/ecb/index.do`). 다른 화면·URL·계정은 인수인계 불필요.
- NICE·관세청 신청 명의는 아이베 신선일 이사, 현장담당 박종혁. 박종혁이 각 기관에 메일로 인계.
- 키는 재발급하지 않는다. GitHub 저장소는 비공개 전환 예정 — **전환 확인 전 push 금지**(연락처가 문서에 있음).
- 단톡방은 모두 초대 완료. PCCC 대응 메일 초안은 미발송.

## 답변 반영 절차

1. 답을 받으면 `01_작성자_확인목록.md`에서 "답변 완료"로 옮기고 일자를 적는다.
2. 인수인계 문서 해당 부분을 고친다. 정정 이력은 확인목록에 남기고 전달 문서에는 바뀐 내용만 쓴다.
3. 관세청 프로젝트의 새 사실은 `project_state.md` 관세청 절에도 반영한다.
