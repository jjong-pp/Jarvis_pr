## 회신 원칙 (요청 메일에서 도출)

1. 새 매뉴얼을 만들지 않는다. 기존 자료는 문서명과 위치만 적는다.
2. 추측하지 않는다. 표기: `없음` / `미정` / `해당 담당자 확인 필요(회사)`.
3. 계정 ID·비밀번호·API Key 값은 인수인계 문서·메일에 쓰지 않는다. 박종혁이 계정 정리 txt로 별도 전달한다.
4. 퇴사 후 확인이 어려운 것(연락처·계정·진행 이슈·정본·개인 채널)부터 채운다.

## 요청 메일 원문

> 아래는 지윤환이 보낸 인수인계 요청 메일 원문이다. 수정하지 않는다.

안녕하세요. 지윤환 입니다. 

관세청 유니패스 전자상거래 통관플랫폼 연동 건과 관련하여, 향후 PM 및 운영 업무를 이어받기 위해 
현재까지의 진행 현황과 관련 자료에 대한 인수인계를 요청드립니다.

기존 문서와 산출물은 일부 전달받아 확인하고 있으나, 
파일만으로는 현재 진행 상태와 실제 운영 방법, 관계사별 담당 범위 등을 모두 파악하기 어려운 부분이 있어 아래 항목을 기준으로 확인 부탁드립니다.

새로운 문서나 매뉴얼을 별도로 작성해 주실 필요는 없으며, 
기존 자료가 있는 경우 해당 문서명 또는 저장 위치를 알려주시면 됩니다.

또한 확인되지 않은 내용은 추측하여 작성하지 마시고 
“없음 / 미정 / 확인 필요 / 해당 담당자에게 확인 필요” 등으로 명확하게 표시 부탁드립니다.


1. 현재 진행 현황 및 남아 있는 이슈

현재 시점에서 실제로 진행 중이거나 대응이 필요한 사항을 중심으로 부탁드립니다.

* 현재 막혀 있는 사항 및 원인
* 현재 관계사 회신/조치 대기 중인 사항
* 아직 해결되지 않은 개발·운영 이슈
* 운영 전환을 위해 추가로 처리해야 하는 사항
* 각 이슈별 현재 담당자 및 다음 조치
* 마지막 정상 운영 또는 테스트 성공 일자

특히 현재 관세청, 자이언트, 고도몰, GeekStudio, NICE, 동수, 일양, 크로네, 호주 업체 등 관계사에 요청해 놓은 사항이 있다면 현재 어디까지 진행되었는지 부탁드립니다.
행안부 주소 API 등 별도로 연계 중인 외부 서비스가 있다면 함께 기재 부탁드립니다.

자사몰 A유형 신규통관 출고가 정상적으로 처리되지 않았을 때 현재 실제로 하고 있는 조치 기준을 부탁드립니다.

* 재처리 방법

해당 절차가 없다면 “없음”, 아직 결정되지 않았다면 **“미정”**으로 기재 부탁드립니다.
또한 현재 보유 중인 아래 Excel 중 실제 운영 시 사용하는 최종 양식이 무엇인지 지정 부탁드립니다.

현재 보유 중인 `관세청 secret key.txt`의 Key가 현 운영 환경에서 실제 사용하는 유효한 Key인지, 어떤 시스템/API/환경에서 사용하는 Key인지도 확인 부탁드립니다.
또한 개인 계정 또는 본인 명의로 생성하여 사용 중인 계정/서비스가 있다면 퇴사 전 회사 계정으로 이관이 필요한지 반드시 확인 부탁드립니다.

10. 메일·메신저 및 개인 소유 자료 인계

문서 외에도 프로젝트 진행 과정에서 사용한 커뮤니케이션 채널에 대한 인계를 부탁드립니다.

* 현재 회신 대기 중인 이메일 원문 또는 메일 스레드
* 카카오톡/위챗 등에서 진행 중인 주요 협의 내용
* 관련 단체방/채널이 있다면 초대 또는 후임 담당자 연결
* 관계사 담당자와 구두로만 협의되어 문서에 남지 않은 사항
* 본인 계정으로 가입/생성되어 퇴사 전 이관이 필요한 시스템
* 본인만 보유하고 있는 파일 또는 인증정보
* 향후 반드시 후속 연락이 필요한 담당자 및 내용

이번 인수인계의 목적은 새로운 운영 매뉴얼을 작성해 달라는 것이 아니라,
① 현재 무엇이 진행 중이고 막혀 있는지
② 어떤 문서가 현재 정본인지
③ 장애 발생 시 어디를 확인해야 하는지
④ 실제 운영상 어떻게 처리하고 있는지
⑤ 누구에게 연락해야 하는지
⑥ 어떤 계정·권한·커뮤니케이션을 이관받아야 하는지
를 파악하여 기존 업무가 중단되지 않도록 하기 위함입니다.
기존 문서에 내용이 있는 경우에는 문서명 또는 저장 위치만 기재해 주셔도 됩니다.


확인되지 않은 내용은 추측하여 작성하지 마시고 **“없음 / 미정 / 확인 필요”**로 남겨주시기 바랍니다.

퇴사 이후 추가 확인이 어려울 수 있는 관계사 연락처, 계정 및 권한, 진행 중인 이슈, 문서 정본, 개인 계정 및 커뮤니케이션 채널 이관 부분은 우선적으로 확인 부탁드립니다.
