1. 판매유형코드 (elcm_pcd) 상세 [2026-08-10 정정] 종전 문서는 A/B 정의가 서로 뒤바뀌어 있었습니다. 관세청 v1.4.1 기준 A=직접판매, B=구매대행입니다.

코드 유형명 정의 당사 적용
A 직접판매(전자상거래) 해외 사이버몰에서 소비자에게 직접 상품을 판매/발송. 판매자가 상품을 미리 매입하여 소유권/재고 직접 관리 크로네 자사몰

C 배송대행 소비자가 해외에서 직접 구매한 물품을 해외 물류센터에서 대신 수령하여 국내로 배송만 대행 당사 미사용

4. 상품 판매 페이지 URL (prod_sale_pge_url / productPageUrl / orderSiteUrl)

설명: 관세청 TRA001의 prod_sale_pge_url, 자이언트 Item의 productPageUrl, HWB의 orderSiteUrl은 모두 동일한 값을 사용한다. 개별 상품 ID를 포함한 상세 URL이 아닌 스토어별 대표 도메인 URL을 통일 주입한다.

이유: 동수 WMS에서 개별 상품 URL을 관리하지 않으며, 관세청은 상품 판매 출처를 확인할 수 있는 대표 URL만 요구한다.

채널 대표 URL 비고
크로네 자사몰 https://nutriciastore.co.kr/ 자사 쇼핑몰 대표 도메인
네이버 브랜드스토어 https://brand.naver.com/nutricia 네이버 브랜드스토어 대표 도메인
기타 구매대행 채널 (28개) 각 스토어별 대표 URL 지마켓, 옥션, 11번가, 쿠팡, SSG닷컴 등 28개 채널. 상세 목록은 store_url_mapping.csv 참조

이 URL 매핑은 별도 엑셀(CSV) 파일로 관리하며, 채널 추가 시 해당 엑셀에 스토어 코드와 대표 URL을 등록하여 동수 WMS 채널코드 기반 자동 매핑에 활용한다.

5. 판매업체명 기재 규칙 (sale_ents_nm / sellerName) [2026-08-10 신설]

배경: Geek은 자사몰(A유형) 데이터만 보유한다. 반면 동수 EIBE ERP는 자사몰과 입점 채널을 모두 수집하므로 A유형과 B유형을 동시에 대응해야 하는 유일한 주체이다. 따라서 입점 채널의 판매업체명은 동수가 채널코드 기준으로 내려주어야 한다.

규격 차이가 핵심이다. 관세청은 A(직접판매)일 때만 필수지만, 자이언트는 A·B 구분 없이 항상 필수다. 즉 관세청 기준으로는 생략 가능한 B유형도 자이언트에 값이 없으면 HWB 등록이 거부된다.

구분관세청 sale_ents_nm자이언트 items[].sellerName
필수 여부 A 직접판매인 경우 필수 (B·C는 선택) A·B·C 무관 항상 필수 (Y)
값의 정의 A: 상품 판매 페이지에 표시되는 판매업체명
B: 구매대행업자가 상품을 구매한 판매업체명
C: 고객이 입력한 판매업체명		 판매 채널 상호명 (가이드 예시값 TAOBAO SHOP)
규격 String(250) String(300)

5.2 운영 원칙

  • 관세청 sale_ents_nm과 자이언트 sellerName은 동일 값으로 통일한다. 두 값이 다르면 3사 데이터 대사가 불가능해진다.
  • A유형은 Geek이 고정 주입하고, B유형은 10:00 역수집 응답에 동수가 채널코드 기반으로 실어 내려준다. store_url_mapping.csv와 같은 방식으로 채널 → 판매업체명 매핑표를 별도 관리한다.
  • 종전 문서의 "판매업체명·판매업체부호는 선택 항목이므로 전건 Null 통일" 지침은 폐기한다. A유형 관세청 필수 조건과 자이언트 전건 필수 조건을 모두 위반하기 때문이다.
  • 판매업체부호 sale_ents_sgn / sellerCode는 성격이 다르다. 관세청 규격은 "판매업체가 관세청에 전자상거래업자로 등록되어 있는 경우에만 제출"이므로, 등록 부호가 있을 때만 기재하고 없으면 미입력한다. 해외 판매처는 통상 미등록이므로 B유형은 미입력이 원칙이다.

5.3 미확정 사항

  • A유형(자사몰) 판매업체명을 "(주)크로네"로 할지 "뉴트리시아몰"로 할지 확정이 필요하다. 실제 TRA001 전송 JSON에는 제출자명(elcm_ents_nm)이 "뉴트리시아몰"로 들어가 있었다. 관세청 등록 상호와 상품 판매 페이지의 판매자 표기를 확인해 통일한다.
  • B유형 해외 판매업체명의 표기 언어(원문 / 영문 / 한글)와 특수문자 처리 기준을 동수와 합의해야 한다. 상품명에서 이미 * 등 특수문자 이슈가 있었다.
