[현재 핵심 문제]
하나의 MAWB 안에 자사몰 신통관 HBL과 외부 플랫폼 기존통관 HBL이 함께 포함됩니다.
외부 플랫폼은 현재 PER 인증을 처리하지 않으므로 신규 통관에 필요한 정보가 없습니다.
따라서 모든 주문을 신규 GNG V2-1로 보내는 것만으로는 문제를 해결할 수 없습니다.
[사용자 최신 확정]
GNG는 자사몰 주문도 신규 GNG V2-1로 받을 수 있도록 변경했습니다.
자사몰은 PER 인증정보가 있으므로 신규 GNG V2-1과 전자상거래 전용 신규 통관 방식을 사용할 수 있습니다.
Geek V2-2를 계속 사용하는 경우에는 자사몰 통관·인증정보를 보완하는 경로로만 설명합니다.

3. 동수 전달 문안

안녕하세요 과장님. 어제 전달해 주신 내용을 확인했습니다. 먼저 용어를 명확하게 구분하겠습니다. - 판매유형 A는 직접판매입니다. 현재 자사몰 주문이 해당합니다. - 판매유형 B는 구매대행입니다. 현재 외부 플랫폼 주문이 해당합니다. - 기존 GNG API는 관세청 제도 변경 전부터 사용한 API입니다. - 신규 GNG V2-1은 이번에 새로 적용하려는 API입니다. 판매유형 A/B와 기존 GNG API/신규 GNG V2-1은 서로 다른 구분입니다. 현재 자사몰은 주문 API가 연결되어 있습니다. Geek에서 PER 인증도 처리합니다. 따라서 자사몰은 개인통관고유부호, 일회용 개인통관부호, 인증번호 등 신규 통관에 필요한 정보를 확보할 수 있습니다. 또한 GNG가 자사몰 주문도 신규 GNG V2-1로 받을 수 있도록 변경했습니다. 따라서 자사몰 주문은 신규 GNG V2-1과 전자상거래 전용 신규 통관 방식을 사용할 수 있습니다. Geek V2-2가 계속 운영되는 경우에는 자사몰 통관·인증정보를 보완하는 용도로 사용합니다. 자사몰 주문의 기본 전송은 신규 GNG V2-1로 처리할 수 있습니다. 반면 외부 플랫폼 주문은 현재 엑셀 파일로 동수 ERP에 등록됩니다. 외부 플랫폼 주문에는 현재 PER 인증 절차가 연결되어 있지 않습니다. 따라서 외부 플랫폼 주문에는 신규 통관에 필요한 일회용 개인통관부호와 인증번호가 없습니다. 신규 GNG V2-1로 데이터를 보내더라도 없는 PER 정보가 새로 만들어지는 것은 아닙니다. 그러므로 외부 플랫폼 주문은 현재 전자상거래 전용 신규 통관 방식으로 처리할 수 없습니다. 외부 플랫폼의 PER 연동, 신규 엑셀 컬럼, 동수 ERP 매핑과 GNG 테스트가 완료될 때까지 기존 GNG API와 기존 통관 방식을 사용해야 합니다. 현재 문제는 하나의 MAWB 안에 다음 두 종류의 HBL이 함께 포함된다는 점입니다. 1. 자사몰 HBL: 신규 GNG V2-1 사용, 신규 통관 진행 2. 외부 플랫폼 HBL: 기존 GNG API 사용, 기존 통관 진행 모든 주문을 신규 GNG V2-1로 보내는 방법으로는 이 문제를 해결할 수 없습니다. 외부 플랫폼 주문에는 신규 통관 필수정보가 없기 때문입니다. 아래 순서로 해결 방법을 확인하고 싶습니다. 1. 하나의 MAWB를 GNG에 등록한 후, 같은 MAWB에 포함된 HBL을 두 그룹으로 나누어 전송할 수 있는지 확인합니다. 2. 자사몰 HBL은 신규 GNG V2-1로 전송합니다. 3. 외부 플랫폼 HBL은 기존 GNG API로 전송합니다. 4. GNG가 같은 MAWB 아래에서 두 종류의 HBL을 함께 관리할 수 있는지 확인합니다. 만약 이 방법이 불가능하다면 신규 GNG V2-1의 추가 개발이 필요합니다. 신규 GNG V2-1이 모든 HBL을 받은 후 HBL별로 통관 방식을 구분해야 합니다. - PER 정보가 있는 자사몰 HBL은 신규 통관으로 처리합니다. - PER 정보가 없는 외부 플랫폼 HBL은 기존 통관으로 처리합니다. 기존 통관 HBL에는 일회용 개인통관부호와 인증번호를 필수로 요구하지 않아야 합니다. GNG가 위 기능을 지원할 수 없다면 출고 전에 실제 MAWB를 통관 방식에 따라 분리해야 합니다. - 신규 통관 MAWB: 자사몰 주문 - 기존 통관 MAWB: 외부 플랫폼 주문 외부 플랫폼은 2026년 11월경까지 신규 엑셀 컬럼을 순서대로 추가할 예정입니다. 새로운 엑셀 양식을 받을 때마다 동수에서 GNG 필드와 매핑할 수 있는지 확인해야 합니다. PER 정보와 신규 통관 필수정보가 모두 확인되고 GNG 테스트까지 완료된 채널만 신규 GNG V2-1로 변경해야 합니다. 아래 내용을 확인 부탁드립니다. 1. 하나의 MAWB에 기존 GNG API의 HBL과 신규 GNG V2-1의 HBL을 함께 연결할 수 있습니까? 2. 현재 불가능한 이유가 동수 시스템의 제한입니까, GNG 시스템의 제한입니까? 3. 동수 시스템에서 API 선택 기준을 MAWB가 아니라 HBL로 변경할 수 있습니까? 4. 신규 GNG V2-1에서 HBL별로 기존 통관과 신규 통관을 구분할 수 있습니까? 5. PER 정보가 없는 HBL을 신규 GNG V2-1로 받은 후 기존 통관으로 처리할 수 있습니까? 6. 위 방법이 모두 불가능하면 실제 MAWB를 두 개로 분리해야 합니까? 7. 기존 GNG API와 신규 GNG V2-1의 정확한 Method와 전체 URL을 전달해 주실 수 있습니까? 확인 후 개발 방법과 출고 방법을 다시 협의하고 싶습니다. 감사합니다.

6. 확인해야 할 사항

  1. 같은 MAWB에 기존 GNG API HBL과 신규 GNG V2-1 HBL을 함께 연결할 수 있는지 확인합니다.
  2. 제한 주체가 동수인지 GNG인지 확인합니다. 제한이 있다면 오류코드와 정확한 기술 사유를 받습니다.
  3. 동수의 API 선택 단위를 MAWB에서 HBL로 변경할 수 있는지 확인합니다.
  4. 신규 GNG V2-1이 PER 정보가 없는 HBL을 기존 통관으로 처리할 수 있는지 확인합니다.
  5. 위 방법이 불가능하면 실제 MAWB를 통관 방식별로 분리할 수 있는지 확인합니다.
  6. 기존 GNG API와 신규 GNG V2-1을 번호가 아니라 정확한 Method와 전체 URL로 확정합니다.
