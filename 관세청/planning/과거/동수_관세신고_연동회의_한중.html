[2026-08-28 최종 정정] A/B와 수입신고 경로는 서로 다른 판정값입니다.

A/B는 직접판매·구매대행이라는 거래 역할입니다. 기존 수입신고와 전자상거래 전용 수입신고는 주문별 신고 경로입니다.

관세청 회신상 기존 수입신고는 TRA001 거래정보와 일회용 인증번호가 불필요합니다. 따라서 B라고 해서 동수가 개인정보·OTP 전체를 무조건 V2-1로 보내지 않습니다.

核心结论

[2026-08-28 最终更正] A/B类型与进口申报路径是两个独立判断值。

A/B表示直接销售或购买代理的交易角色；传统进口申报与跨境电商专用进口申报是逐订单判断的申报路径。

중요: A/B/C는 API 호출자나 PCCC 인증회사가 아니라 실제 거래 역할로 판정합니다. Geek이 호출하거나 인증한다고 A가 되는 것이 아닙니다.
重要：A/B/C依据实际交易角色判断，不依据API调用方或PCCC认证公司。由Geek调用或认证并不会使订单变成A类。
