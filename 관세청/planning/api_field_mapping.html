[문서 원칙] 관세청 PDF 원본 63개 항목 + 자이언트 API 전수 필드를 하나의 테이블에 통합 나열합니다. 중복 허용하여 빠짐없이 전수 수록합니다.
[분류] 관세청 / 자이언트로 소속 시스템을 구분합니다.
[API 구분] 해당 필드가 속한 API를 표기합니다.
[매핑 코드] 관세청 필드에는 대응하는 자이언트 필드명을, 자이언트 필드에는 대응하는 관세청 필드명을 기재합니다.
