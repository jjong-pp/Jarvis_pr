2. API 문서가 생긴 배경과 목적

이 프로젝트는 단순 주문 연동이 아니라, 주문 시점의 본인확인부터 거래정보 사전 제출, 영문주소 보완, 통관사 HBL/MWB 생성, 오류·CS 처리까지 여러 기관의 데이터 계약을 하나의 운영 흐름으로 묶는 작업이다. 업체별 문서가 따로 생긴 이유는 각 기관의 책임과 데이터 소유권이 다르고, 한 기관의 변경이 다른 기관의 필수값·마감·예외처리에 직접 영향을 주기 때문이다.
