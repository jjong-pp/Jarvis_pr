4. 동수 구현 순서

  1. ERP 스토어명으로 11개 채널 마스터를 정확히 조회합니다.
  2. 주문별 declarationMode를 별도 필드로 수신합니다. 값이 없으면 A/B만으로 추정하지 않습니다.
  3. ecTypeCode, broker*, buyingAgent*는 채널 마스터에서 주입합니다.
  4. LEGACY_IMPORT는 자이언트가 확정한 레거시 endpoint/flag가 나오기 전까지 자동 전송하지 않고 예외 큐로 보냅니다.
  5. ECOMMERCE_DEDICATED는 PCCC·OTP·주문완료일시와 해당 endpoint의 필수 주문자·수하인·물류·상품값이 모두 있을 때만 전송합니다.
  6. 업체부호는 일반 공백·NBSP 등 Unicode 공백을 제거한 뒤 9자로 검증합니다.
  7. 동일 hwbNo + orderNo를 서로 다른 API 버전에 중복 전송하지 않습니다.

5. 자이언트에 즉시 확정할 P0

기존 수입신고 B형 주문은 관세청 회신상 TRA001 거래정보와 일회용 인증번호가 불필요합니다. 그러나 V2-1 POST /api/hwb/bulk-sync 공개 명세는 pccCode·tempAuthNo·orderCompletionDate를 필수로 검증합니다.

확인 요청: 기존 수입신고 A/B 주문을 어느 endpoint 또는 어떤 구분값으로 보내야 하는지, tempAuthNo와 orderCompletionDate를 미전송할 수 있는지, 기본 수하인·PCCC·상품 필수범위는 무엇인지 서면 확정이 필요합니다. 확정 전 임의 OTP, Z99999, 가짜 주문완료일시를 만들지 않습니다.
