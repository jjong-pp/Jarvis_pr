타 판매채널 주문의 PCCC 누락 건을 보완하기 위한 검토 자료

1. 결론

세 방식 모두 적법성 미판정 상태다. 실제 계약, 개인정보처리방침, 관리자 설정, 보유·삭제 방식과 위탁관계를 확인하지 않았다. 판매자가 같거나 문자로 안내한다는 사실만으로 법령 위반이 없다고 확정할 수 없다.
  • 네이버 톡톡: 현재 사용 중이나 계속 사용 가능 여부는 미판정. 판매자 문의 대화 3년 보관과 당사 보유기간이 맞는지 확인 필요.
  • 자사몰 1:1 문의게시판: 사용 가능 여부 미판정. 처리 법인, 회원가입, 비공개, 관리자 권한, 저장·삭제 방식 확인 필요.
  • 전용 임시 서비스: 사용 가능 여부 미판정. 수집 근거, 고지, 위탁, 보안, 파기 요건을 기획과 계약에 반영해야 함.

법무·개인정보·보안 검토에서 사용 가능 또는 조건부 가능으로 판정된 방안만 후보로 남긴다. 이후 주문 건수, 고객 계정 보유율, 운영시간, 구축비를 기준으로 선택한다.

구분내용상태

처리 법인타 채널 판매자 법인과 뉴트리시아몰 개인정보처리자 법인의 일치 여부미확인
일정·금액게시판 설정·개발 범위와 전용 서비스 개발 견적견적 필요

5. 법령상 확인 항목

개인정보는 회사가 보유하더라도 정한 목적 안에서 처리해야 한다. 같은 브랜드나 도메인보다 개인정보 처리를 결정하는 법인이 기준이다. 아래 조문은 가능한 처리 근거와 의무를 보여줄 뿐, 현재 방식의 적법성을 확정하지 않는다.

항목위반 소지가 생기는 경우확인 내용
수집·이용 근거
제15조		계약 이행 또는 동의 등 처리 근거 없이 PCCC 수집원 주문의 통관 보완 범위인지 확인. 동의를 근거로 하면 목적·항목·보유기간·거부권 고지
최소 수집
제16조		통관에 필요하지 않은 회원가입 정보까지 필수 수집주문 확인과 PCCC 제출에 필요한 항목만 사용
목적 제한
제18조		타 채널 주문정보를 자사몰 마케팅·회원 분석에 사용임시 통관정보를 회원·마케팅 DB와 분리
파기
제21조		목적 달성 후 PCCC·대화·게시글·출력파일을 계속 보관업무 보유기간 확정. 플랫폼 보관정책과 충돌 여부 확인
처리위탁
제26조		개발사·호스팅사·플랫폼·관세사 역할을 정리하지 않고 접근 허용수탁자 또는 제3자 여부, 계약, 처리방침 공개, 감독 확인
안전조치
제29조		공용계정, 과도한 권한, 평문 저장·전송, 열람·다운로드 기록 부재개인별 계정, 최소권한, 암호화, 마스킹, 로그 적용
네이버 톡톡 검토점: 판매자 문의 대화를 3년 보관한다는 공식 안내가 있다. PCCC 통관 보완에 필요한 기간과 3년 보관의 정합성, 당사 요청에 따른 개별 삭제 범위를 확인하기 전에는 보유·파기 통제를 완료했다고 볼 수 없다.
자사몰 검토점: 타 채널 판매자와 자사몰 개인정보처리자가 같은 법인이고 통관 목적 안에서 처리해야 한다. 법인이 다르거나 회원가입 정보가 추가 수집되면 법적 근거와 고지를 다시 확인한다.

6. 전용 임시 서비스 기획

범위

  • 담당자가 대상 주문 엑셀 업로드
  • 주문별 1회용 URL과 고객 안내문 생성
  • 알림톡은 별도 시스템에서 수기 발송
  • 고객이 마스킹된 주문정보 확인 후 PCCC 제출
  • 관리자가 제출 건 확인 후 암호화 엑셀 출력
  • 통관 전달과 인수 확인 후 데이터 파기

처리 흐름

대상 취합주문 엑셀
등록누락·중복 확인
안내 생성1회용 URL
발송알림톡 수기 전송
고객 확인주문정보 마스킹
제출PCCC 입력
전달암호화 엑셀
종료인수 확인·파기

입력·출력

구분항목
담당자 입력주문채널, 주문번호, 고객명 또는 수취인명, 회원 ID(없으면 공란), 휴대전화번호, 상품 요약
고객 화면주문채널, 주문번호 뒤 4자리, 마스킹 고객명, 상품 요약, PCCC 입력
관리자 출력주문채널, 주문번호, 고객명, 회원 ID, PCCC, 제출일시

통제

  • 주문번호를 비밀번호로 사용하지 않음
  • 주문별 난수 URL, 유효기간, 제출 후 재사용 차단
  • HTTPS, 관리자 로그인, PCCC 저장 암호화, 화면 마스킹
  • URL과 일반 로그에 주문번호·전화번호·PCCC 원문 미기록
  • 파일 열기 암호가 적용된 XLSX 또는 AES-256 암호화 압축 사용
  • 평문 PCCC 파일 이메일·메신저 전송 금지

제외

고도몰 주문 API, 알림톡 자동 발송, 관세청 OTP, PCCC 진위 확인, 통관대행사 API, 자동 통관 접수·진행 조회는 포함하지 않는다.

7. 선택 기준

법무·개인정보·보안 검토에서 사용 가능 또는 조건부 가능으로 판정되고, 조건 이행이 확인된 방식만 선택한다.
조건선택 후보이유
이번 건만 처리하고 현재 방식의 보유·파기 조건을 법무·개인정보 담당자가 승인네이버 톡톡도입 작업 없음. 건별 운영 필요
타 채널 고객이 자사몰 계정을 보유하고 게시글 권한·삭제·출력 조건 충족자사몰 1:1 문의게시판기존 기능 활용
비회원이 많거나 누락 건이 반복되고 일괄 취합·파기 기록 필요전용 임시 서비스계정 가입 없이 처리하고 데이터 통제 가능
톡톡 직접 수집은 승인되지 않지만 고객 연락 채널로는 사용 가능톡톡으로 전용 URL만 발송PCCC 원문을 톡톡 대화에 남기지 않음

8. 확인 요청

  1. 타 채널 판매자 법인과 뉴트리시아몰 개인정보처리자 법인 대조
  2. 채널별 주문정보 제공 목적과 외부 링크 안내 허용 여부 확인
  3. 네이버 톡톡 대화의 관리자 목록, 개별 삭제 범위, 3년 보관 근거 확인
  4. 고도몰 게시판의 회원·비밀글·권한·암호화·백업·삭제·출력 설정 확인
  5. 개발사·호스팅사·알림톡 운영사·관세사의 위탁 또는 제3자 지위 확인
  6. PCCC 보유기간, 파기 책임자, 출력파일 수령자 확정
  7. 전용 서비스 개발기간·구축비·월 운영비 견적 요청
