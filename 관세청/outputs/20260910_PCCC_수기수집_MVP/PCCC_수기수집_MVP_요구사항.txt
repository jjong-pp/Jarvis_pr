개인통관고유부호(PCCC) 수기 수집 임시 웹서비스 MVP 요구사항

작성일: 2026-09-10

[결론]

주문번호는 여러 곳에 노출될 수 있는 식별자이므로 확인번호로 사용하지 않는다.
고객이 별도 번호를 입력할 필요가 없는 주문별 1회용 보안 URL을 사용한다.

1. 목적과 범위

- 통관정보가 누락된 주문의 PCCC를 고객에게 다시 받아 통관 담당자에게 전달하는 임시 도구다.
- 근본 통관 연동을 수정하거나 외부 시스템을 자동 연결하는 서비스는 아니다.
- 주문정보는 담당자가 엑셀로 취합하며, 알림톡도 담당자가 별도 시스템에서 직접 발송한다.

2. 필요한 기능

가. 주문 등록

- 복잡한 입력 화면 없이 표준 엑셀 업로드를 기본으로 한다.
- 입력 항목: 주문채널, 주문번호, 고객명 또는 수취인명, 회원 ID(없으면 공란), 휴대전화번호, 상품 요약
- 주문채널 + 주문번호를 기준으로 중복과 필수값 누락을 표시한다.

나. 고객 안내 생성

- 정상 등록된 주문마다 1회용 URL과 알림톡 문구를 자동 생성한다.
- 담당자는 문구를 복사하거나 발송용 목록으로 내려받아 알림톡을 수기로 발송한다.
- 발송 후 담당자가 시스템에서 '발송 처리'로 표시한다. 이는 실제 수신 성공 확인은 아니다.

다. 고객 입력

- URL 접속 직후에는 주문정보를 표시하지 않고 '주문 확인 시작' 버튼만 보여준다.
- 버튼을 누르면 주문채널, 주문번호 뒤 4자리, 마스킹 고객명, 상품 요약을 보여준다.
- 고객이 '내 주문이 맞습니다'를 확인한 뒤 PCCC를 입력·저장한다.
- '내 주문이 아님' 또는 '정보가 다름'을 선택하면 입력을 막고 '확인 필요' 상태로 바꾼다.
- PCCC는 형식만 확인하며 진위 또는 명의 일치가 확인됐다고 표시하지 않는다.

라. 관리자 조회와 출력

- 상태: 등록 / 발송 처리 / 고객 제출 완료 / 확인 필요 / 출력 완료 / 파기 완료
- 관리자 목록에서는 PCCC를 마스킹한다.
- 제출 완료 건을 주문채널, 주문번호, 고객명, 회원 ID, PCCC, 제출일시 기준으로 출력한다.
- 파일명 또는 표지에 '대외비·개인정보 포함'을 표시한다.

3. 접근 및 파일 보호

- URL은 추측할 수 없는 난수로 생성하고 주문번호, 전화번호, PCCC를 넣지 않는다.
- 링크 유효시간은 초기 72시간으로 설정하고, PCCC 제출이 끝날 때 1회 사용 완료로 처리한다.
- 제출 완료 또는 재발급 시 기존 링크를 즉시 무효화한다.
- 별도 확인번호가 꼭 필요해질 때만 주문번호 대신 무작위 8자리 '웹 주문확인번호'를 추가한다. 관세청 인증번호와는 다른 값이며 '본인인증'으로 표현하지 않는다.
- 고객·관리자 페이지는 HTTPS를 사용하고, 관리자 기능은 승인된 담당자만 로그인해 사용한다.
- PCCC는 저장 시 암호화하며 URL과 일반 로그에 원문을 남기지 않는다.
- 출력은 파일 열기 암호가 적용된 XLSX를 1순위로 한다. 단순 시트 보호는 인정하지 않는다.
- XLSX 암호화가 어려우면 AES-256 암호화 압축파일 또는 수신자 제한·만료·접근기록이 있는 회사 보안 링크를 사용한다.
- 실 PCCC가 포함된 평문 엑셀은 정상 운영 경로에서 제공하지 않는다. 파일 비밀번호는 파일과 다른 채널로 전달한다.

4. 최종 E2E 흐름

담당자 대상 주문 엑셀 취합
→ 시스템 업로드 및 누락·중복 확인
→ 주문별 1회용 URL·알림톡 문구 자동 생성
→ 담당자 알림톡 수기 발송
→ 고객 URL 접속 및 마스킹 주문정보 확인
→ 개인정보 안내 확인 후 PCCC 제출
→ 관리자 제출 완료 건 확인
→ 암호화 XLSX 또는 보호된 대체 방식으로 출력
→ 통관 담당자에게 파일과 비밀번호를 서로 다른 채널로 전달
→ 인수·업무 완료 확인 후 정해진 기준에 따라 데이터와 파일 파기

5. 알림톡 권고 문안

[브랜드명] 해외배송 주문 통관정보 입력 안내

안녕하세요, 고객님.
고객님의 해외배송 주문은 통관 처리에 필요한 개인통관고유부호(PCCC)가 정상 반영되지 않아 추가 입력이 필요합니다.

- 주문채널: {주문채널}
- 주문번호: 끝 4자리 {주문번호_뒤4자리}

아래 고객 전용 페이지에서 주문정보를 확인한 후 PCCC를 입력해 주세요.
{1회용_URL}

본 링크는 발송 후 72시간 동안 사용할 수 있으며, 제출 완료 후에는 다시 사용할 수 없습니다. 만료된 경우 고객센터로 문의해 주세요.

입력하신 정보는 해당 주문의 통관 처리 목적으로만 이용되며, 입력 화면에 안내된 보유기간 경과 또는 처리 목적 달성 후 안전하게 파기됩니다.

※ 알림톡 회신으로 PCCC를 보내지 마세요.
※ 주민등록번호, 카드정보, 계정 비밀번호 또는 결제를 요구하지 않습니다.
문의: {고객센터_연락처}

6. 이번 MVP에서 제외할 것

- 고도몰 및 주문채널 API 연동
- 알림톡 API 연동과 자동 발송
- 관세청 일회용 인증번호 수집
- PCCC 진위·명의 일치 검증
- 통관대행사 API 연동
- 고객 주문정보 수정
- 자동 통관 접수·진행 조회와 복잡한 통계 화면

7. 출시 전 운영부서가 확정할 값

- 브랜드명과 고객센터 연락처
- 개인정보 수집 법인명, 개인정보처리방침 URL, 보유·파기 기간
- 통관정보 수령 업체의 정확한 법인명·담당자와 개인정보 처리 관계
- 관리자 사용자와 권한 범위
- 보호파일 비밀번호 전달 채널

[문구 주의]

'관세청 서버 오류' 또는 '개인정보보호법 때문에 기존 PCCC가 삭제됐다'는 설명은 공식 확인 전까지 메일·알림톡에 사용하지 않는다.
