제목: [판정 요청] 개인통관고유부호 수집 방식별 법무·개인정보·보안 검토

안녕하세요.

타 판매채널 주문 중 개인통관고유부호(PCCC)가 누락된 건을 고객에게 다시 받아야 합니다.

현재 네이버 톡톡으로 수집하고 있으며, 뉴트리시아 자사몰 1:1 문의게시판과 전용 임시 서비스도 검토하고 있습니다.

세 방식 모두 적법성 검토가 끝나지 않았습니다. 판매자가 같거나 고객에게 문자를 보낸다는 이유만으로 법령 위반이 없다고 판단할 수 없어 서면 검토를 요청드립니다.

1. 네이버 톡톡 사용(현재 방식)

- 즉시 사용 가능
- 신규 개발비 없음
- 네이버 공식 안내상 판매자 문의 대화는 3년 보관
- 당사 보유기간과 맞는지, 개별 삭제가 가능한지 확인되지 않음
- 톡톡 계정 멤버의 열람 범위와 PCCC 수기 취합 과정 확인 필요

확인 요청
- 현재 방식으로 PCCC를 계속 받아도 되는지
- 불가하거나 조건부라면 중단 시점과 필요한 조치가 무엇인지
- 네이버의 역할이 개인정보 처리위탁에 해당하는지, 처리방침 반영이 필요한지

2. 뉴트리시아 자사몰 고도몰 1:1 문의게시판 사용

- 자사몰 계정과 게시판 기능 활용 가능
- 타 채널 판매자와 자사몰 개인정보처리자가 같은 법인인지 확인 필요
- 타 채널 고객의 자사몰 가입이 필요한지 확인 필요
- 게시글 비공개, 관리자 권한, PCCC 저장 방식, 보유기간, 삭제 범위 확인 필요
- 고도몰 운영사와의 개인정보 처리위탁 관계와 처리방침 반영 여부 확인 필요

확인 요청
- 타 채널 주문의 통관 목적으로 자사몰 게시판에서 PCCC를 받아도 되는지
- 별도 동의가 필요한지, 안내만으로 처리할 수 있는지
- 사용 전 바꿔야 할 게시판 설정과 고지 문구가 무엇인지

3. 전용 임시 서비스 개발

- 주문별 링크에서 주문정보 확인 후 PCCC 입력
- 제출 건을 관리자 화면에서 확인하고 암호화 엑셀로 출력
- 링크 만료, 접근권한, 보유기간, 파기 기록 반영 가능
- 개발사·호스팅사의 위탁관계, 수집 근거, 고지 문구, 보안요건 확정 필요
- 개발기간과 구축비는 견적 필요

확인 요청
- 첨부 기획안의 수집 흐름과 보호조치로 진행 가능한지
- 추가 동의·고지·계약·보안조치가 필요한지

- 판단 근거와 충족 조건

- 필요한 개인정보 안내 또는 동의 문구
- 보유기간과 파기 방법
- 처리위탁·제3자 제공 관계
- 관리자 권한과 기록 기준
