제목: [개발 요청] 개인통관고유부호 수기 수집용 임시 웹페이지 구축

안녕하세요.

현재 일부 해외배송 주문에서 개인통관고유부호(PCCC)가 누락되어, 고객에게 정보를 다시 받아 통관을 보완할 수 있는 임시 웹페이지 개발을 요청드립니다.

이번 MVP는 외부 API 연동 없이 운영 담당자가 대상 주문정보를 엑셀로 취합·등록하는 방식입니다. 시스템에서 주문별 고객 안내문과 1회용 보안 URL을 생성하면 담당자가 별도 알림톡 시스템에서 직접 발송하고, 고객은 전용 페이지에서 마스킹된 주문정보를 확인한 뒤 PCCC를 입력합니다. 이후 관리자는 제출 완료 건을 주문번호·고객명·회원 ID·PCCC 기준의 보호된 엑셀 파일로 내려받을 수 있어야 합니다.

전체 흐름은 아래와 같습니다.

대상 주문 엑셀 취합 → 시스템 업로드 → 주문별 안내문·1회용 URL 생성 → 알림톡 수기 발송 → 고객 주문정보 확인 및 PCCC 제출 → 관리자 확인 → 보호된 엑셀 출력·전달 → 업무 완료 후 파기

주문번호는 접근 비밀번호로 사용하지 않고, 별도 번호 입력 없이 주문별 1회용 URL을 사용하는 방향으로 요청드립니다. 이번 범위에서는 고도몰 등 주문 API 연동, 알림톡 자동 발송, PCCC 진위 검증 및 통관 시스템 연동은 제외합니다.

상세 요구사항은 첨부 메모장 파일을 참고 부탁드리며, 가장 빠른 개발 가능 일정과 예상 소요기간을 회신 부탁드립니다.

감사합니다.
