# 본문

안녕하세요, 과장님.

개인통관고유부호가 누락된 주문을 처리하기 위한 임시 웹페이지 개발을 요청드립니다.

전체 진행 방식은 아래와 같습니다.

1. CS팀이 통관부호 누락 주문번호가 정리된 엑셀을 업로드합니다.
2. 엑셀의 주문번호를 기준으로 고도몰 API에서 주문정보와 고객정보를 조회합니다.
3. 주문별 고객 전용 URL과 6자리 접근 인증번호를 자동 생성합니다.
4. 고객에게 보낼 알림톡 문구를 주문정보, URL, 접근 인증번호와 함께 자동 완성합니다. 실제 알림톡 발송은 별도로 진행할 예정입니다.
5. 고객은 URL에 접속해 6자리 인증번호로 본인 주문을 확인한 뒤 개인통관고유부호를 입력하고 저장합니다.
6. 관리자는 입력 완료 결과를 주문번호, 고객명, 회원 ID, 개인통관고유부호가 포함된 엑셀로 다운로드합니다.

알림톡 문구는 아래와 같이 적용하고자 합니다.

> [뉴트리시아몰] 고객님의 주문 건은 통관 연계 과정에서 개인통관고유부호가 정상 반영되지 않아 추가 입력이 필요합니다. 아래 전용 페이지에서 주문정보를 확인한 후 개인통관고유부호를 입력해 주세요.  
> 입력 URL: {고객 전용 URL}  
> 접근 인증번호: {6자리 인증번호}  
> 입력하신 정보는 해당 주문의 통관 처리 목적으로만 사용됩니다.

첨부한 고도몰 API 명세와 현재 CS팀 사용 엑셀을 참고하여, 위 흐름 기준으로 가장 빠른 개발 가능 일정과 예상 공수를 회신 부탁드립니다.

감사합니다.
