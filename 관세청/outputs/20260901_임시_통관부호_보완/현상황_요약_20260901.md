# 개인통관고유부호 누락 현황 요약

기준일: 2026-09-01

## 1. 현재 상황

- 2026-08-28 관세청 신규 통관 연계 오픈 이후 일부 자사몰 주문이 개인통관고유부호 없이 수집되었습니다. 협력사별 연계 적용 시점 차이가 원인으로 파악되고 있으나, 정확한 장애 원인은 현재 확인 중입니다.
- 2026-08-31 CS 엑셀 기준 90개 주문 중 개인통관고유부호 누락 주문은 32건이며, 대상 회원은 31명입니다. 엑셀은 복수 상품행을 포함해 총 91개 행입니다.
- 누락된 32개 주문은 모두 `상품준비` 상태입니다. 주문 자체는 수집되었으나 통관에 필요한 개인통관고유부호가 없어 자동 통관 처리가 지연될 수 있습니다.
- 자사몰 A유형 운영 테스트는 완료됐고, 시스템 측 잔여 확인사항은 Geek 데이터와 동수 데이터가 주문·HBL 기준으로 정확히 합쳐지는지 대사하는 작업입니다.

## 2. 현재 해결 중인 내용

누락 주문은 엑셀을 기준으로 관리하면서 아래 임시 보완 서비스를 개발 요청한 상태입니다.

1. CS 엑셀의 주문번호 업로드
2. 고도몰 API로 해당 주문 및 고객정보 조회
3. 주문별 고객 전용 URL과 6자리 접근 인증번호 생성
4. 주문정보·URL·인증번호가 포함된 알림톡 문구 자동 완성
5. 알림톡은 별도 발송
6. 고객이 전용 페이지에서 주문을 확인하고 개인통관고유부호 입력·저장
7. 관리자가 주문번호, 고객명, 회원 ID, 개인통관고유부호를 엑셀로 다운로드

위 6자리 접근 인증번호는 임시 웹페이지 로그인용 비밀번호이며, 관세청이 발급하는 6자리 일회용 통관 인증번호와는 별개입니다.

## 3. 원복 및 예상 일정

- 관세청 규격에는 장애 복구 후 사후 보완 경로가 있으며, 현재 당사 적용 가능 여부를 확인 중입니다. 확인 전까지 기존 누락 주문은 자동 복구를 전제로 하지 않고 고객 재입력 또는 수기 보완으로 처리할 예정입니다.
- 과거의 `p1` 자동 원복·익일 자동 재수집 방식은 2026-08-26 운영 기준에서 폐기됐습니다. 현재 누락 건은 임시 웹 또는 수기 보완 대상으로 보는 것이 맞습니다.
- 임시 웹페이지 오픈 일정은 개발사의 가능 여부·공수 회신 후 확정됩니다. 현재 확정된 완료일은 없습니다.
- 전체 자동 연계 원복은 협력사별 라이브 적용 완료, 신규 주문 누락 재발 여부 확인, 데이터 병합 대사 완료 후 판단할 수 있습니다. 현재 확정된 정상화 일자는 없습니다.
- `2026-09-27`은 관세청 임시 통관 인증값 허용 종료일이지 시스템 정상화일이나 임시 웹페이지의 확정 마감일이 아닙니다. 다만 이후 인증 미완료 주문 대응이 더 어려워질 수 있으므로 운영상 조기 적용이 필요합니다.

## 4. 현재 판단

- 확인된 엑셀 범위에서는 전체 주문이 아니라 일부 주문의 개인통관고유부호가 누락된 데이터 보완 이슈입니다.
- 단기적으로는 임시 웹페이지를 통해 누락 주문을 해소하고, 중장기적으로는 협력사별 연계 정상화와 신규 주문 재발 방지를 확인해야 합니다.
- 개발 일정과 협력사 정상화 일정이 확정되는 즉시 별도 공유가 필요합니다.
